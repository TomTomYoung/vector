# 直線・ポリライン・ベジェの下書き保存

更新日: 2026-11-17（日本時間）。直線、ポリライン、2次ベジェ、3次ベジェ、n次ベジェの5ツールで、作図途中の入力をSVGへ記録・復元できます。既存9点入力ツールと4数値設定ツールを合わせ、作図入力プリセットは計18ツールに対応します。

## 記録と復元

ツールプロパティの「実装・アルゴリズム」内で「作図入力のプリセット（SVGに保存）」を開き、「現在の入力を図面に記録」を押します。各ツールに1組記録でき、記録後の編集は自動反映しません。「SVG保存」で図形と一緒に保存できます。未確定の線・曲線プレビューと制御点の補助表示は完成図形として出力しません。

読み込みだけでは入力の復元・計算・作図を行いません。対応ツールを選び「記録した入力を下書きへ復元」を押すと、現在の下書きを記録済み入力で置き換えます。既存図形と保存済み入力は維持します。現在選択している計算・描画方式でプレビューを作成し、方式選択、描画設定、色、レイヤー、ブラウザーへの保存設定は書き換えません。入力記録の更新・削除は各1段階のUndo/Redo、復元は図面履歴を増やさない下書き操作です。図形の確定を1段階の履歴にします。

## ツールごとの入力と確定

直線は始点と現在表示している終点を記録します。直交拘束後の終点もその座標で保持します。始点だけを置いた段階では、同じ座標の始点・終点として記録します。復元直後は保存座標をそのままプレビューし、Enterで確定できます。マウスを動かして終点を変更し、クリックで確定することもできます。この変更には現在のスナップ・直交設定を使います。復元した下書きはマウスボタンを離す操作やキャンバス外への移動だけでは確定しません。通常の「ドラッグ／クリック2回」の設定は維持し、復元した直線の終了後は元の操作方法へ戻ります。ドラッグ中のボタン状態やポインター取得は保存しません。

ポリラインはクリック済みの頂点列を順序と重複を含めて保存します。カーソルへの仮の次辺は記録しません。復元後はクリックで追加、Backspaceで末尾点を削除、Enterまたはダブルクリックで確定できます。復元した下書きは別ツールへの切替で取り消します。通常の新規ポリラインで従来からあるツール切替時の確定は維持します。

2次・3次ベジェはクリック済みの制御点、n次ベジェは制御点と次数を保存します。カーソル位置に仮置きする次の制御点は記録しません。必要数までクリックすると確定します。必要数がそろった入力を復元した場合も自動確定せず、Enterで確定します。Backspaceで末尾点を減らし、クリックで置き直せます。必要数に満たないEnterや計算・描画の失敗では入力点を残して理由を表示します。補助点は曲線がまだ計算できない段階でも表示します。n次ベジェの次数欄は整数2〜12へ制限します。サンプル数などの描画設定は入力記録に含めず、復元先の設定を使用します。

5ツールともEscで取消できます。空の入力を記録・復元すると現在の下書きを取り消します。取消・確定後も記録済み入力は残り、繰り返し復元できます。復元した下書きの編集そのものはUndoの対象外です。

## 形式と検証

既存の `metadata[data-vector-document="1"]` のJSONにある `constructionInputs.entries` へ5つの個別形式を追加します。全体と個別入力の版は1です。

```json
{
  "constructionInputs": {
    "version": 1,
    "entries": {
      "line": {"version": 1, "input": {"points": [{"x": 80, "y": 100}, {"x": 180, "y": 90}]}},
      "polyline": {"version": 1, "input": {"points": [{"x": 80, "y": 100}]}},
      "quadraticBezier": {"version": 1, "input": {"points": [{"x": 80, "y": 100}, {"x": 180, "y": 90}]}},
      "cubicBezier": {"version": 1, "input": {"points": []}},
      "nthBezier": {"version": 1, "input": {"points": [{"x": 80, "y": 100}], "degree": 4}}
    }
  }
}
```

各点は有限数の `x` と `y` のみを持ちます。直線の点数は0または2、ポリラインは0〜1000、2次ベジェは0〜3、3次ベジェは0〜4、n次ベジェは0〜次数+1です。n次だけ整数2〜12の `degree` を必須とします。余分なフィールド、欠落、数値文字列、非有限数、過剰な点数を拒否します。幾何学的に重なった点や入力途中の点数は下書きとして保持します。

全体の2000000文字・256記録・12階層・50000検査要素の制限を継承します。既知形式の不正なSVGは図面置換前に全体を拒否し、現在の図形・下書き・選択・履歴を維持します。未知ツールと個別の将来版はデータとして保持し、未対応版の復元を無効にします。旧SVGとの切替、ブラウザー保存拒否時の継続も[共通プリセット](construction-input-presets.md)と同じです。

## 実装・計算・描画

形式検査とコピーは [constructionInputPresets.js](../src/adapters/constructionInputPresets.js) の `constructionDraftTools` と `parseConstructionDraft(name, entry)` が担当します。既存9ツール用の `parseConstructionInput` と4ツール用の数値設定APIは維持します。

コントローラーは [LineTool.js](../src/tools/LineTool.js)、[PolylineTool.js](../src/tools/PolylineTool.js)、[BezierToolBase.js](../src/tools/BezierToolBase.js) の `inputPresetVersion = 1`、`exportInputPreset()`、`restoreInputPreset(entry)` で接続します。必ず全入力とアクティブ状態を検査してから現在の下書きを取り消します。外部コントローラーもこの順序と非確定の契約を守る必要があります。`inputPresetInstructions` で復元後の確定方法をパネルと操作結果へ示せます。

計算は既存の [drawing.js](../src/model/drawing.js) の `line`、`polyline`、`quadraticBezier`、`cubicBezier`、`nthBezier` です。描画はホストの描画レジストリーと [svgGeometry.js](../src/adapters/svgGeometry.js) を使用します。標準の直線・ポリラインはSVG line／polyline、2次・3次ベジェはSVG Q／C、n次ベジェは既存のde Casteljau評価によるSVG折れ線です。ベジェでは登録済みの等分割・Bernstein直接評価・de Casteljau適応分割等を引き続き選択できます。使用した計算・描画方式は確定図形の `data-vector-implementation` へ記録し、プロパティから確認できます。

新しい幾何アルゴリズム、論文、外部ライブラリは追加していません。名前の付いた方式・資料と参照履歴は [algorithms.md](algorithms.md)、換装できる計算・描画の一覧は [implementation-options.md](implementation-options.md) にあります。直線・ポリラインの外部描画は各ツールのSVG要素操作と整合する必要があります。
