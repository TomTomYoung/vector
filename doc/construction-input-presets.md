# 点入力ツールの作図入力プリセット

更新日: 2026-11-17（日本時間）。9つの点入力ツールについて、現在の入力をツールごとに1組、SVG図面内へ記録できます。SVGを開き直した後は、明示的に下書きへ復元し、編集を続けてからEnterで図形を確定します。

数値設定だけを記録するスプライン・フィレット・面取り・オフセットの4ツールも追加しました。[直線・ポリライン・2次／3次／n次ベジェの下書き](linear-bezier-drafts.md)も追加し、対応は計25ツールです。4ツールの保存項目と、点・対象選択を維持する復元の仕様は [drawing-parameter-presets.md](drawing-parameter-presets.md) を参照してください。以下は9つの点入力ツールについての説明です。

## 対象と保存内容

対象はB-spline、NURBS、凸包、多角形三角分割、Delaunay分割、Voronoi分割、直線当てはめ、円当てはめ、最小包含円の9ツールです。各ツールに与えた点列の順序と重複を保持します。多角形の境界順や、計算結果では凸包に現れない内部点も残します。

B-splineとNURBSは次数、周期指定、ノット列の入力文字列も保存し、NURBSは重みの入力文字列も保存します。空欄、未完成の文字列、点数不足も下書きとして記録できます。文字列を記録時に数値へ変換しないため、書きかけの符号、区切り、空白も保持します。周期指定で使われないノット欄の文字列も残し、周期指定を外した後に編集できます。零・負の重みを含む入力も保持します。

Voronoiは母点と、記録時の実際の切り取り矩形を保存します。復元先の図面のviewBoxや寸法が違っても、復元した下書きでは元の矩形を使います。プロパティにその範囲を表示し、「切り取り範囲を図面全体に戻す」で現在の図面へ合わせられます。図形の確定、取消、別ツールへの切替で復元中の範囲指定を終了し、次の新規作図は図面全体を使います。図面内に記録した矩形は自動更新しません。

計算・描画の実装ID、描画分割数、許容差、NURBSの分母除外幅・検査深さは、この入力記録には含めません。これらは[図面の方式プリセット](document-implementation-presets.md)へ別に記録・適用できます。入力復元は現在使用中の方式でプレビューを作り、使用した方式は従来どおり図形確定時に記録します。

## 操作

対応ツールを選択し、クリックで点を入力して必要な曲線設定を指定します。ツールプロパティの「実装・アルゴリズム」内にある「作図入力のプリセット（SVGに保存）」を開き、「現在の入力を図面に記録」を押します。記録済みの場合は「現在の入力で図面の記録を更新」で、そのツールの記録だけを置き換えます。他のツールの記録は維持します。

「SVG保存」で、図形と入力記録を一緒に持ち出せます。未確定のプレビューと補助点はSVGの図形へ含めません。明示的に記録した入力だけをメタデータへ保存します。記録後に点や入力欄を編集しても、自動では記録を更新しません。

SVGを読み込んだだけでは入力の復元や計算を行いません。記録のあるツール名をパネルで確認し、目的のツールを選んで「記録した入力を下書きへ復元」を押します。そのツールの現在の下書きを置き換え、入力点・曲線設定・プレビューを戻します。点の追加、Backspaceによる末尾点の削除、設定欄の変更を続けられます。Enterで図形を確定し、Escで下書きを取り消します。

復元する入力が幾何条件を満たさない場合や、選択した計算実装が失敗した場合も、入力下書きを保持して理由を表示します。点や設定を修正するか計算方式を切り替え、再度プレビュー・確定できます。復元・修正・確定・取消によって、保存した入力記録が書き換わることはありません。

「このツールの入力記録を削除」は図面内の記録だけを削除し、現在の下書き、既存図形、他のツールの記録、方式設定は維持します。記録・更新・削除は各1段階のUndo/Redoに対応します。入力の復元は下書きの変更なので図面履歴へ追加せず、Enterで確定した図形を図面履歴へ追加します。Undo/RedoやSVG読込では、記録だけを戻し、下書きを自動復元しません。

## 互換性と失敗時

この入力記録がない旧SVG・外部SVGを開くと、直前の図面の記録は引き継ぎません。既存の方式プリセットと入力プリセットは別の任意フィールドなので、どちらか一方だけを持つSVGも読み込めます。

文書形式、既知の入力形式、版番号の型、点・設定の型や上限が不正な場合は、SVG全体を図面置換前に拒否します。現在の図形、下書き、選択ツール、レイヤー、履歴、方式設定は維持します。記録時に現在の下書きを検査できない場合も、以前の記録を維持してエラーを表示します。

未知のツールや、個別入力の将来の正整数版は、上限内のデータとしてSVGに保持します。対応する復元コントローラーがなければ実行しません。既知ツールの将来版は復元ボタンを無効にして理由を表示します。再保存とUndo/Redoでも元の記録を維持します。対応ツールで「記録を更新」を押した場合は、そのツールの古い記録を現在の入力で明示的に置き換えます。

ブラウザー保存へアクセスしないため、保存が拒否された環境や `preferences:false` でも使用できます。外部実装コードの自動取得・自動登録、関数の復元は行いません。SVG読込はデータの保持だけですが、入力の明示的な復元後は、選択中の計算・描画実装でプレビューを計算します。

## 保存形式と上限

既存の `metadata[data-vector-document="1"]` のJSONに任意の `constructionInputs` を追加します。最後の記録を削除するとこのフィールドを省略します。全体の版は1で、entriesのキーはツール名です。個別入力にも版番号を持たせます。

```json
{
  "constructionInputs": {
    "version": 1,
    "entries": {
      "nurbsCurve": {
        "version": 1,
        "input": {
          "points": [{"x": 20, "y": 30}, {"x": 90, "y": 80}],
          "degree": 2,
          "periodic": false,
          "knotsText": "",
          "weightsText": "1, -"
        }
      },
      "voronoiCells": {
        "version": 1,
        "input": {
          "points": [{"x": 40, "y": 60}],
          "box": {"x": 0, "y": 0, "width": 800, "height": 600}
        }
      }
    }
  }
}
```

既知のversion 1入力は必要なフィールドだけを受け付けます。全ツールでpointsは必須、最大1000点で、各点は有限数のx・yです。B-splineとNURBSはdegree（整数1〜12）、periodic（真偽値）、knotsText（最大20000文字）が必須で、NURBSだけweightsText（最大20000文字）も必須です。Voronoiだけboxが必須で、有限数のx・y、正の有限数のwidth・height、有限の右端・下端を要求します。

全体のJSONは2000000文字、entriesは256項目、入れ子は12階層、検査要素数は50000までです。文字数はJavaScript文字列のlengthです。ツール名は1〜100文字の英数字・ハイフン・アンダースコアで、プロトタイプ用の予約名は拒否します。関数・非有限数・特殊なオブジェクトを保存しません。未知ツール・将来版も同じ全体上限とデータ型の検査を受けます。

## 実装と換装契約

[constructionInputPresets.js](../src/adapters/constructionInputPresets.js) が形式検査、独立したコピー、ツール別の記録・復元・削除を担当します。`toolManager.inputPresets` の `snapshot()` / `entry(name)` はコピーを返し、`open(value)` は記録だけを置き換えます。`record(name, controller)` / `restore(name, controller)` / `remove(name)` は明示操作で、成功時はtrueを返します。直接APIで記録を変更し図面履歴に残す場合は `host.save()` を呼びます。

コントローラーは `inputPresetVersion`、`exportInputPreset()`、`restoreInputPreset(entry)` を提供します。復元関数は入力全体を検査してから未確定入力を置き換え、既存図形の確定・置換・削除、方式設定やブラウザー保存の変更を行わない契約です。対応する個別版だけを受け付け、外部コントローラーは自分の入力形式と失敗時の現状維持を検査する必要があります。

標準の9ツールの接続は [PointConstructionTool.js](../src/tools/PointConstructionTool.js) です。非アクティブなツールへの復元は拒否します。SVGと履歴への接続は [DrawingDocument.js](../src/core/DrawingDocument.js)、操作欄は [ToolPropertiesPanel.js](../src/ui/ToolPropertiesPanel.js) です。

今回、新しい幾何計算・描画アルゴリズム、論文、外部ライブラリは導入していません。計算は既存のモデル関数、描画はホストの描画レジストリーとSVGアダプターを使用します。実装元・方式・文献は [implementation-options.md](implementation-options.md) と [algorithms.md](algorithms.md) から参照できます。
