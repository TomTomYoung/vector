# 図面ごとの計算・描画方式プリセット

更新日: 2026-11-17（日本時間）。現在の全ツールの計算実装ID、描画実装ID、描画設定を1組のプリセットとしてSVG図面内に記録します。図面を別の環境で開き、その方式で次の作図を続けられます。

## 操作と適用範囲

ツールプロパティの「実装・アルゴリズム」内にある「この図面の方式プリセット（SVGに保存）」を開きます。「現在の方式を図面に記録」で全119演算の現在の選択と対応する描画設定を記録します。既に記録がある場合は「現在の方式で図面の記録を更新」で全体を置き換えます。「SVG保存」で図形と一緒に持ち出せます。

記録済みの計算・描画の項目数と、現在のツールについて記録された実装ID・アルゴリズム・描画設定を表示します。上にある現在使用中の方式表示とは区別します。アルゴリズムの説明は現在登録されている実装情報を参照し、実装IDが未登録ならその旨を表示します。

SVGを読み込んだだけでは方式を切り替えません。「図面の方式を次の作図に適用」で互換性を確認して現在の設定へ適用し、次の作図と未確定の作図プレビューがその方式を使用します。既存図形の再計算や生成記録の変更は行いません。個々の図形を変更する場合は、その図形の再編集操作を使います。

適用はブラウザーの保存設定を書き換えません。後から通常の方式選択を変更した場合は、従来どおり、その時点の全ツールの設定が自動保存されます。「現在の方式設定を保存」も全ツールの現在値をブラウザーに保存します。共通設定へ戻す場合は「保存した方式設定を復元」を使用します。図面プリセットの記録内容は、現在の方式を変更しても自動更新しません。

「図面の方式記録を削除」はSVG内のプリセットだけを削除し、現在使用中の方式と図形は維持します。記録・更新・削除は図面のUndo/Redoの対象で、各操作を1段階で戻せます。適用は作図設定の変更なので、図面のUndoには追加しません。Undo/Redoで別の図面状態へ戻っても、プリセットを自動適用しません。

方式記録がない旧SVGや外部SVGを開いた場合、その図面にはプリセットがない状態になります。直前の図面のプリセットを引き継がず、現在使用中の方式は維持します。

## 互換性・失敗時の扱い

計算実装、描画実装、ツールが未登録の場合や、描画方式が対象ツールに対応しない場合、描画設定が許容範囲外の場合は、その項目を適用せず理由を表示します。他の互換項目は適用します。該当する現在の設定を維持し、別の方式へ自動的に置き換えません。計算と描画はそれぞれ独立した項目です。

未登録IDや適用できなかった描画設定も、図面の記録にはそのまま残ります。再保存、別図面への切替、Undo/Redoで失われず、対応する実装を登録した後に再度適用できます。「記録を更新」を明示した場合は、未登録項目を含む以前の記録全体を現在の有効な選択で置き換えます。

プリセットの形式・版番号・型・大きさが不正なSVGは、図面を置き換える前に読込全体を拒否します。現在の図形、選択、レイヤー、履歴、方式設定は維持します。プリセットの記録に失敗した場合も、以前の記録を維持します。

ブラウザー保存が拒否されている場合や `preferences:false` の埋込みでも、この機能は利用できます。localStorageへアクセスせず、SVGの保存・読込と図面履歴だけに接続します。外部ホストに方式の書出し・復元APIがない場合は対応する操作を無効にしますが、読み込んだプリセットは保持できます。

読込と適用で幾何計算や描画関数を実行することはありません。GUIの適用後は現在のツールへ変更を通知するため、作図中の入力があれば、その未確定プレビューを更新します。外部コードの自動読込、関数の復元、プラグインの導入は行いません。

## SVG内の形式と実装

既存の `metadata[data-vector-document="1"]` のJSONに、任意の `implementationPreset` を追加します。未記録の場合はこのキーを省略します。プリセットは[方式設定の保存と復元](implementation-preferences.md)と同じversion 1形式です。

```json
{
  "layers": [{"id": 1, "name": "レイヤー 1"}],
  "currentLayerId": 1,
  "implementationPreset": {
    "version": 1,
    "calculation": {"spline": "centripetal"},
    "rendering": {"circle": {"id": "cubic", "options": {}}}
  }
}
```

GUIでの記録は全ツールを含みますが、部分的な記録も読み込めます。省略された項目は適用時に現在値を維持します。描画のoptionsはその項目ごとに置き換えます。上限はプリセット全体で256000文字、入れ子12階層、検査要素20000個です。ツール名・実装IDは1〜100文字の英数字・ハイフン・アンダースコアで、プロトタイプ用の予約名、関数、非有限数、特殊なオブジェクトは受け付けません。

[documentImplementationPreset.js](../src/adapters/documentImplementationPreset.js) が記録・形式検査・適用状態を管理します。`toolManager.documentPreset.snapshot()` は独立したコピーを返し、`open(value)` は記録だけを置き換え、`record()` はホストの現在値を記録し、`apply()` はホストの `restorePreferences()` で互換項目を適用し、`clear()` は記録だけを削除します。直接APIを呼んで図面の記録を変更した場合、履歴へ残すには `host.save()` を呼びます。

[DrawingDocument.js](../src/core/DrawingDocument.js) が保存・読込とUndo/Redoのメタデータへ接続し、読込前に形式を検査します。[ToolPropertiesPanel.js](../src/ui/ToolPropertiesPanel.js) が記録された方式の表示と操作を提供します。計算・描画は既存の [editorHost.js](../src/adapters/editorHost.js) と各レジストリーを使用します。

今回、新しい幾何計算・描画アルゴリズム、論文、外部ライブラリは導入していません。使用する方式の実装元と文献は [implementation-options.md](implementation-options.md) と [algorithms.md](algorithms.md) を参照してください。プリセットはIDと設定値の記録であり、外部実装のコード・版・依存環境を同梱して再現性を保証する形式ではありません。

## 検証と未導入範囲

[documentImplementationPreset.test.mjs](../tests/documentImplementationPreset.test.mjs) は独立したコピー、非実行での読込と適用、実計算への方式反映、未登録項目の保持と再試行、不正形式の非適用、非対応ホスト、ブラウザー保存との分離を検証します。[editor.html](../tests/editor.html) は別エディタへのSVG移行、実際の作図、方式表示、描画設定欄、更新・削除のUndo/Redo、旧SVG、読込失敗時の現状維持、保存拒否、SVG保存ボタンの出力を検証します。

[名前付き複数の方式プリセット](named-implementation-presets.md)は実装済みです。従来の1件記録を維持し、保存済みの値を名前付き記録へ複製できます。読込時の自動適用、図形の一括再計算、方式切替そのもののUndo、実装コード・版の同梱、フィレット・面取り・オフセット以外の図形参照を伴う編集入力のプリセット、クラウド同期は未導入です。9つの点入力ツールの制御点・次数・周期・ノット・重み・Voronoiの切り取り矩形は、別の[作図入力プリセット](construction-input-presets.md)で保存・復元できます。

スプラインの接線倍率、フィレット半径、面取りの2距離、オフセット距離・Miter上限比も、[作図パラメーターの記録](drawing-parameter-presets.md)として別途保存できます。

直線・ポリライン・2次／3次／n次ベジェの作図途中の点列も、別の[下書きプリセット](linear-bezier-drafts.md)で保存・復元できます。方式プリセットとは独立しています。

[作図セット](construction-sets.md)では、25ツールの入力と全ツールの計算・描画方式を組にして保存・復元できます。利用できない方式がある場合はセット全体の復元を止めます。入力・方式を単独で保存する従来機能も使用できます。

フィレット・面取りは[選択済みの1本目と寸法の保存・復元](drawing-parameter-presets.md#フィレットと面取りの1本目を含む下書き)にも対応します。 [オフセットの対象図形と寸法](drawing-parameter-presets.md#オフセットの対象を含む下書き)も保存できます。
