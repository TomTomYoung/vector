# 作図セット：入力と計算・描画方式を組にして保存

更新日: 2026-11-18（日本時間）。28の作図ツールについて、1ツールの入力と全ツールの計算・描画方式を1組にして、図面内に名前付きで複数保存できます。同じ点列を求心スプラインで描く設定や、指定した円を3次ベジェ近似で描く設定を、その入力と方式で復元できます。

## 操作と表示

ツールプロパティの「実装・アルゴリズム」にある「作図セット（入力と方式をまとめて保存）」を開きます。セット名を入力し、「現在の入力と方式をセット保存」を押します。作図入力はそのツールの値を、方式は全119演算の計算実装ID・描画実装ID・描画設定をコピーします。委譲先の演算も保存対象です。ツール固有の方式だけを切り替える機能ではありません。

一覧の選択では入力や方式を変更しません。選択したセットの入力概要と、計算・描画の項目数、現在のツールの保存済み実装ID・アルゴリズム名・描画設定を表示します。実際に使用中の方式は上の方式選択欄で確認できます。名前とアルゴリズム情報は文字列として表示します。未登録のIDは、その旨を表示します。

「選択セットの入力と方式を復元」で、保存された方式の利用可否を検証してから、方式、入力の順に適用します。下書き型では現在の下書きを置き換え、復元した方式でプレビューを描きます。数値設定型では入力点や加工対象の選択を維持します。復元では完成図形を作らず、各ツールの通常の確定操作で作図・加工します。例えば円はEnter、文字は確定ボタン、フィレットは2本目の線分の選択を使用します。

スプラインには「現在の数値設定と方式をセット保存」と「現在の下書きと方式をセット保存」があります。前者は接線倍率だけ、後者は通過点と接線倍率を記録します。どちらにも全ツールの方式を含めます。両方を異なる名前で保持でき、更新時も数値設定・下書きのどちらで置き換えるかを選べます。

「選択セットを現在の入力と方式で更新」は入力と方式の両方を現在値に置き換えます。IDと名前を維持します。「選択セットを改名」は名前だけを変更します。「選択セットを別名で複製」は保存済みの入力と方式を新しいIDでコピーします。「選択セットを削除」はセットの記録だけを削除します。変更・複製・削除しても、他のセットや使用中の入力・方式は変わりません。

セット名は前後の空白を除いて1〜100 UTF-16単位、改行・制御文字を含まない文字列です。日本語を使用でき、同じツール内の完全一致の重複名を禁止します。別ツールでは同名を使用できます。新規保存・更新・改名・複製・削除は、それぞれ図面履歴で1段階ずつUndo/Redoできます。同じ保存内容への更新では履歴を増やしません。選択と復元は図面履歴に追加しません。Undo/Redoでセットが戻っても入力と方式を自動適用しません。

## 名前付き記録からの組み合わせ

[名前付き作図入力](named-construction-inputs.md)で現在のツールの入力記録を選択し、[名前付き方式プリセット](named-implementation-presets.md)で方式記録を選択します。作図セット欄に「組み合わせ元」として両方の名前を表示します。セット名を入力し、「選択中の名前付き入力と方式からセット作成」で保存します。

コピー元は選択した記録の保存値です。現在の下書きや現在の方式を変更していても、保存値から組を作ります。元の記録へのID参照ではなく値のコピーなので、元の入力・方式記録を後で更新・削除しても作図セットは変わりません。組の作成自体は入力と方式を適用しません。

従来の1件入力・1件方式記録、名前付き入力、名前付き方式、作図セットは、それぞれ独立した領域です。従来記録は既存の操作で名前付き記録へコピーしてから、組み合わせ元にできます。

## 互換性と失敗時

セット内に未登録の計算・描画実装、未登録ツール、対象ツールに非対応の描画方式、許容範囲外の描画設定が1項目でもあれば、セット全体の復元を止めます。現在の下書き・プレビュー・入力点・対象選択・全ツールの方式を維持し、利用できない項目と理由を表示します。入力だけ、または一部の方式だけを適用して別の組を作ることはありません。従来の方式プリセット単独の適用は、引き続き互換項目だけを適用します。

全ツールの方式を記録しているため、現在のツールから直接使わない項目でも、利用できなければ一括復元を止めます。部分的な方式記録を読み込んだ場合は、記録に含まれる全項目を検証し、省略項目の現在値を維持します。描画optionsは項目ごとに置き換えます。

未知のツール・入力版・実装IDは、形式が有効ならSVG内のデータとして保持します。未知の入力版の復元は無効にし、既知ツールの記録は改名・複製・削除できます。未登録方式は登録後に再試行できます。記録の更新は全体の置換なので、旧記録にのみ存在する項目は更新後のセットから除かれます。未知の集合版や方式設定版は受け付けません。

入力復元関数が例外を出した場合、共通ホストが方式を元に戻し、管理器が直前の入力を復元します。スプラインは数値設定だけを適用する場合も、巻戻し用には点列を含む完全な入力を退避します。巻戻しは入力データの復元なので、元のマウス押下状態・同一プレビューDOM・ドラッグ中の一時状態までは保存しません。外部ホスト・コントローラーが巻戻しにも失敗した場合は、そのエラーも表示します。

計算・描画失敗をツールの `implementationError` へ報告した場合は、入力と方式の復元は完了した状態として扱い、警告を表示します。完成図形を増やさず、復元した入力を維持するため、編集または別セットの復元で再試行できます。全ツールの方式を変更しますが、プレビューは現在のツールだけが更新されます。

不正な名前・ID・入力・方式形式・件数・大きさを含むSVGは、図形・下書き・選択・レイヤー・履歴・他の記録を置き換える前に全体を拒否します。保存や更新に失敗しても、以前の全セットと選択IDを維持します。

## SVG・履歴・ブラウザー設定

SVGを開く操作は、入力や方式を自動復元しません。セット一覧の選択と入力中のセット名は一時状態で、ツール切替では維持し、SVG読込・Undo/Redoではツールごとの先頭記録に戻ります。旧SVGを開くと作図セットは空になり、現在使用中の方式は維持します。

「SVG保存」は完成図形、作図セット、他の既存記録を保存し、未確定プレビューを除外します。作図セットに未対応の旧アプリで再保存すると追加領域が失われます。現在の作図入力や方式を後から変更しても保存済みセットは自動更新しません。

セットの復元はブラウザーの保存設定を書き換えません。通常の方式選択欄を後で変更した場合や「現在の方式設定を保存」を押した場合は、その時点の全ツールの方式が従来どおりブラウザーへ保存されます。ブラウザー保存を拒否された場合や `preferences:false` の埋込みでも、セットのSVG保存・復元は使用できます。

## 形式と接続API

`metadata[data-vector-document="1"]` のJSONへ、任意の兄弟項目 `constructionSets` を追加します。既存の各プリセットの形式は変更しません。最後のセットを削除するとキーを省略します。

```json
{
  "constructionSets": {
    "version": 1,
    "entries": [{
      "id": "set-example",
      "tool": "circle",
      "name": "ベジェ円",
      "input": {"version": 1, "input": {"points": [{"x": 80, "y": 100}, {"x": 180, "y": 180}]}},
      "methods": {"version": 1, "calculation": {"circle": "default"}, "rendering": {"circle": {"id": "cubic", "options": {}}}}
    }]
  }
}
```

集合の版は1、上限は256セット、JSON全体で2000000 UTF-16単位です。IDは集合内で一意、1〜100文字の英数字・ハイフン・アンダースコアで予約名を拒否します。集合と各セットのキーは固定です。入力部分には[名前付き入力と同じ検証](named-construction-inputs.md)を適用し、入力集合の入れ子12階層・50000検査要素と各ツールの点数・文字数等の制約を使います。方式部分には各セットごとに[方式設定](implementation-preferences.md)の256000文字・12階層・20000検査要素の制約を使います。関数・非有限数・危険なプロパティ名・特殊オブジェクトは拒否します。

[constructionSets.js](../src/adapters/constructionSets.js) の `parseConstructionSets(value)` が形式検査と独立コピーを行います。`createConstructionSets(host)` は `snapshot()`、`list(tool)`、`entry(tool,id)`、`selectedId(tool)`、`choose(tool,id)`、`nameDraft(tool)`、`setNameDraft(tool,value)`、`open(value)`、`add(tool,name,input,methods)`、`record(tool,name,controller,{draft})`、`update(tool,id,controller,{draft})`、`rename(tool,id,name)`、`duplicate(tool,id,name)`、`remove(tool,id)`、`restore(tool,id,controller)` を提供します。`entry` のID省略時は選択中の記録を使用します。記録変更を直接呼ぶ場合、履歴へ残すには `host.save()` を呼びます。

[editorHost.js](../src/adapters/editorHost.js) に `restorePreferencesAtomically(value,applyInput)` を追加しました。全項目を検査し、利用できない項目があれば `{applied:[],skipped}` を返してコールバックを呼びません。利用可能なら方式を適用し、同期関数 `applyInput()` を1回呼びます。コールバックが例外を出すと方式を巻き戻して例外を再送出します。入力の退避・巻戻しは作図セット管理器が担当します。`exportPreferences()` がなければ現在値からの保存・更新を、`restorePreferencesAtomically()` がなければ一括復元を無効にします。非対応ホストでも読込済みセットの保持・改名・複製・削除や、保存済み記録同士の組み合わせはできます。

[App.js](../src/core/App.js) がエディタごとに管理器を生成し、[DrawingDocument.js](../src/core/DrawingDocument.js) がSVG・履歴へ接続し、[ToolPropertiesPanel.js](../src/ui/ToolPropertiesPanel.js) が操作と入力・方式表示を提供します。入力の書出し・復元は各コントローラーの既存APIを使用します。

新しい幾何計算・描画アルゴリズム、論文、外部ライブラリは導入していません。各方式の実装元・文献・換装条件は [implementation-options.md](implementation-options.md) と [algorithms.md](algorithms.md) を参照してください。実装コード・版・依存環境、図形のスタイル・レイヤー、マウスの一時状態はセットに含めません。加工対象図形は、各ツールの下書き形式に応じて参照を保存します。

[editor.html](../tests/editor.html) は28ツールの保存・SVG往復・一括復元、円の保存形状と描画方式、スプライン両形式と実計算、各編集のUndo/Redo、名前付き記録からのコピー、未知のツール・入力版、不正SVGと不正名の非更新、旧SVG、未登録方式の復元阻止と再試行、例外時の巻戻し、プレビュー失敗後の再試行、フィレットの対象選択維持と実加工、保存拒否と実SVGダウンロードを検証します。

入力点の座標変換と複数配置、スタイル・レイヤーの保存、入力・方式の自動更新、復元そのもののUndo/Redo、実装コードの同梱、クラウド同期は未導入です。

[別SVGからの選択取り込み](preset-import.md)は実装済みです。記録を新しいIDで追加し、同名には番号を付けます。複数種類の追加も1回でUndo/Redoできます。

[名前付き記録の検索・並べ替え](preset-search-order.md)は実装済みです。記録名とIDで検索し、上下移動や名前順の並びをSVGへ保存できます。

フィレット・面取りは[選択済みの1本目と寸法の保存・復元](drawing-parameter-presets.md#フィレットと面取りの1本目を含む下書き)にも対応します。 [オフセットの対象図形と寸法](drawing-parameter-presets.md#オフセットの対象を含む下書き)も保存できます。 [トリムと延長の境界線](construction-input-presets.md#トリムと延長の境界線)と操作段階も作図セットに保存できます。 [結合する線の選択](construction-input-presets.md#結合する線の選択)も計算・描画方式と一緒に復元できます。
