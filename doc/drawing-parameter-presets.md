# 作図パラメーターの図面保存

更新日: 2026-11-17（日本時間）。スプライン、フィレット、面取り、オフセットの数値設定を、ツールごとに1組、SVGへ記録して復元できます。[点入力プリセット](construction-input-presets.md)と同じ保存先を使い、対応するツールは合計13になりました。

## 保存する設定

スプラインは標準実装の接線倍率 `tension` を保存します。0〜4の有限数で、既定値は0.5です。この値を使うのは標準のCardinal / Catmull–Rom系実装です。一様、求心、弦長など別の選択実装では、それぞれの定義に従います。倍率を復元しても計算実装を切り替えません。

フィレットは `radius` を保存します。0.5〜1000の有限数です。面取りは独立した2距離 `distance1` と `distance2` を保存し、それぞれ0〜1000の有限数です。0の距離もそのまま保持します。入力した2線分で処理可能かどうかの幾何条件は、従来どおり実際の加工時に検査します。

オフセットは `offsetDistance`（0.5〜1000）と `miterLimit`（1〜1000）を保存します。いずれも有限数で、小数も保持します。Miter上限比は対応するMiter実装を選択した場合に使います。距離や半径は既存ツールが計算に渡す数値をそのまま保存し、表示ピクセル数への変換やズームによる補正は行いません。

これらはプロパティ欄で指定する作図設定です。スプラインの入力点、フィレット・面取りの選択線分、オフセット対象の図形参照、マウス位置、選択の強調表示は記録に含めません。計算・描画の実装IDと描画設定は[方式プリセット](document-implementation-presets.md)に別途記録できます。

## 操作と現在の作業への影響

対応ツールを選び、プロパティで数値を指定します。「実装・アルゴリズム」内の「作図入力のプリセット（SVGに保存）」で「現在の入力を図面に記録」を押します。記録済みなら「現在の入力で図面の記録を更新」で、そのツールだけの記録を置き換えます。「SVG保存」で図形と一緒に持ち出せます。記録後に数値を変えても、保存したプリセットを自動更新しません。

SVGを開いただけでは値を適用しません。対応ツールを選び「記録した作図設定を復元」を押すと、設定値と入力欄が更新されます。パネルには記録済みの数値も表示し、通常の入力欄の現在値と比較できます。旧SVGや外部SVGには記録がないため、前の図面の記録を引き継ぎません。

復元は数値設定だけを変更し、現在入力している点や選択中の線・図形を維持します。スプラインに入力途中の点があれば、新しい接線倍率で未確定プレビューを更新します。フィレット・面取りは選択中の1本目を維持し、2本目を選んだときに復元値で加工します。オフセットは対象の選択を維持し、方向をクリックしたときに復元値を使います。既存図形を復元操作だけで加工・再計算することはありません。

スプラインのプレビュー計算が失敗しても、点列と復元した数値を保持して理由を表示します。方式を切り替えるか点を修正してから再度プレビュー・確定できます。フィレット・面取り・オフセットの計算は通常の確定操作まで行いません。これらの数値設定を復元した直後には、前回の計算エラー表示を消し、次の操作で改めて結果を判定します。

「このツールの入力記録を削除」はSVG内の記録だけを削除し、現在の数値と入力・選択は維持します。記録・更新・削除は各1段階のUndo/Redoに対応します。Undo/Redoで記録を戻しても数値を自動適用しません。設定の復元は図面履歴へ追加せず、その後の曲線確定や角の加工・オフセット作成を図面の履歴へ追加します。

ブラウザーの方式保存にはアクセスせず、保存拒否時や `preferences:false` でも使用できます。入力プリセット、方式プリセット、図形の生成方式記録は別に保持します。

## 形式・検査・互換性

既存の `metadata[data-vector-document="1"]` のJSONにある `constructionInputs.entries` へ、次の4形式を追加します。全体と個別入力の版は1です。9つの点入力ツールの既存形式は変更しません。

```json
{
  "constructionInputs": {
    "version": 1,
    "entries": {
      "spline": {"version": 1, "input": {"tension": 2}},
      "fillet": {"version": 1, "input": {"radius": 30}},
      "chamfer": {"version": 1, "input": {"distance1": 0, "distance2": 35}},
      "offset": {"version": 1, "input": {"offsetDistance": 15, "miterLimit": 2}}
    }
  }
}
```

各形式は上記の必須フィールドだけを受け付けます。文字列の数値、NaN、無限大、範囲外の数値、余分な入力点・図形参照、欠けたフィールドは拒否します。上限やフィールドをまとめて検査してから適用するため、面取りの距離1だけ、オフセット距離だけを先に変更することはありません。値の丸め・切り詰め・別の値への自動補正は行いません。

不正な記録を含むSVGは図面置換前に読込全体を拒否し、図形、未確定入力、対象選択、現在値、履歴を維持します。記録時の現在値が不正なら、以前の記録を維持して理由を表示します。将来の個別版はデータとして保持して復元を無効にし、再保存・Undo/Redoで失わないようにします。既知のversion 1は定義済みの形式として検査します。

全体2000000文字、最大256項目、入れ子12階層、検査要素50000個の上限と、予約名・データ型の検査は[入力プリセット共通仕様](construction-input-presets.md)を継承します。

## 実装と換装契約

[constructionInputPresets.js](../src/adapters/constructionInputPresets.js) の `constructionParameterFields` がフィールド名・表示名・範囲を定義します。`exportConstructionParameters(name, controller)` は定義された数値だけをコピーして検査します。`restoreConstructionParameters(name, entry, controller)` は形式全体とアクティブ状態を検査してから、その数値だけを置き換えます。

接続先は [SplineTool.js](../src/tools/SplineTool.js)、[FilletTool.js](../src/tools/FilletTool.js)、[ChamferTool.js](../src/tools/ChamferTool.js)、[OffsetTool.js](../src/tools/OffsetTool.js) です。4ツールとも `inputPresetVersion = 1`、`inputPresetMode = 'parameters'`、`exportInputPreset()`、`restoreInputPreset(entry)` を提供します。modeは復元後の説明を数値設定向けに変えます。コントローラーの復元関数は、数値以外の入力状態や図形参照を置き換えない契約です。

既存の9点入力ツールは下書き全体を復元し、追加4ツールは数値だけを復元します。この違いを [ToolPropertiesPanel.js](../src/ui/ToolPropertiesPanel.js) の操作説明・復元ボタン・保存値表示で区別します。SVG・履歴への接続は既存の共通処理を使用します。

今回、新しい幾何計算・描画アルゴリズム、論文、外部ライブラリは追加していません。スプライン計算、フィレット・面取り、標準・Miterオフセット、SVG描画は既存の選択実装を使用します。実装元・算法・参照資料は [implementation-options.md](implementation-options.md) と [algorithms.md](algorithms.md) を参照してください。
