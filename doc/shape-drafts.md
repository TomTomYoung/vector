# 矩形・円・円弧・多角形の下書き保存

更新日: 2026-11-17（日本時間）。矩形、円、3点円弧、多角形の作図途中の入力をSVGの作図入力プリセットへ記録・復元できます。対応は既存19ツールと合わせて計23ツールです。

## 記録と復元

ツールプロパティの「実装・アルゴリズム」内の「作図入力のプリセット（SVGに保存）」で「現在の入力を図面に記録」を押します。ツールごとに1組記録し、再記録ではそのツールの記録を置き換えます。記録後の編集は自動反映しません。「SVG保存」で図形と入力記録を一緒に保存できます。未確定の図形・入力点の補助表示・仮の辺・補助円は完成図形として出力しません。

読込だけでは計算や下書きの復元をしません。記録したツールを選び「記録した入力を下書きへ復元」を押すと、現在の下書きを記録済み入力で置き換えます。既存図形、他ツールの記録、選択している計算・描画方式を維持します。現在の方式と色・レイヤーでプレビューし、通常の確定操作またはEnterで完成図形にします。使用した計算・描画実装は、完成図形へ従来どおり記録してプロパティから参照できます。

記録・更新・削除、図形の確定は各1段階のUndo/Redoに対応します。復元と未確定の入力編集自体は図面履歴へ追加しません。Esc、ツール切替、空入力の復元で下書きを取り消します。取消・確定でも図面内の記録は残るので繰り返し復元できます。

## ツール別の入力と継続

矩形・円の新規ドラッグ入力は、作図中にSpaceでカーソル追従を一時停止すると、ボタンを離してプロパティへ移動できます。その状態で「現在の入力を図面に記録」を押してください。Spaceをもう一度押すとカーソル追従を再開します。一度停止した下書きはEnterまたはクリックで明示確定します。

矩形は入力の始点と現在の対角終点を保存します。逆方向にドラッグした場合も入力順を保持します。復元はドラッグ中のボタン状態を再現せず、保存された2点からプレビューします。Enterでそのまま確定、マウス移動で対角終点を調整してクリックで確定できます。マウスボタンを離す操作やキャンバス外への移動だけでは復元した矩形を確定しません。

円は中心と現在の円周上の入力点を保存します。標準実装は2点間の距離から半径を計算します。復元後はEnterで保存入力のまま確定、または円周上の点を変更してクリックで確定できます。復元した円もマウスボタンを離しただけでは確定しません。矩形・円の通常の新規作図は、従来のドラッグして離す操作を維持します。

矩形の幅・高さはそれぞれ2以上、円の半径は1以上という既存の確定条件を維持します。復元した入力がこの条件を満たさない場合は入力を残して理由を表示し、終点を動かして修正できます。始点または中心だけを設定した段階は、同じ座標の2点として記録できます。下書きは零寸法・零半径でも保存できます。

円弧は始点・通過点・終点の順で、クリック済みの0〜3点を保存します。1点・2点だけの記録も復元して続きを入力できます。カーソルに仮置きした3点目や補助円の半径は保存しません。通常は3点目のクリックで確定します。3点を復元した場合は自動確定せず、Enterで確定できます。クリックすると終点を変更して確定します。Backspaceで最後の点を削除し、通過点から指定し直すこともできます。一直線など円弧を作れない3点や計算失敗では入力を保持し、修正できます。

多角形はクリック済みの頂点を順序・重複を含めて保存します。カーソルへの仮の次辺は含めません。復元後はクリックで追加、Backspaceで末尾を削除、3点以上でEnterまたはダブルクリックにより確定できます。点数不足での確定操作では入力を残し、理由を表示します。多角形の下書き保存は、境界の単純性検査や自己交差の修復を追加するものではありません。

## 形式と互換性

既存の `metadata[data-vector-document="1"]` 内のJSONにある `constructionInputs.entries` を使います。全体と各個別入力の版は1です。以下は4ツールを同時に記録した例です。

```json
{
  "constructionInputs": {
    "version": 1,
    "entries": {
      "rectangle": {"version": 1, "input": {"points": [{"x": 80, "y": 100}, {"x": 180, "y": 180}]}},
      "circle": {"version": 1, "input": {"points": [{"x": 80, "y": 100}, {"x": 180, "y": 180}]}},
      "arc": {"version": 1, "input": {"points": [{"x": 80, "y": 100}, {"x": 180, "y": 180}]}},
      "polygon": {"version": 1, "input": {"points": [{"x": 80, "y": 100}, {"x": 180, "y": 180}, {"x": 280, "y": 100}]}}
    }
  }
}
```

各点は有限数のx・yのみを持ちます。矩形・円の点数は0または2、円弧は0〜3、多角形は0〜1000です。空入力や重複座標は下書きとして保持します。余分なフィールド、欠落、数値文字列、非有限数、過剰点数を拒否します。全体の2000000文字・256記録・12階層・50000検査要素の制限は[共通仕様](construction-input-presets.md)と同じです。

不正な既知形式のSVGは図面置換前に全体を拒否し、現在の図形・下書き・選択・履歴を維持します。記録時の不正な入力も以前の記録を置き換えません。未知ツールと個別版2以降はデータとして保持し、対応しない復元を無効にします。旧SVGを開くと以前の図面の記録を引き継ぎません。ブラウザーへの保存が拒否される環境でもSVG内の記録は使用できます。

## 実装・計算・描画

[constructionInputPresets.js](../src/adapters/constructionInputPresets.js) の `constructionShapeTools` と `parseShapeDraft(name, entry)` が検査と独立したコピーを担当します。[RectangleTool.js](../src/tools/RectangleTool.js)、[CircleTool.js](../src/tools/CircleTool.js)、[ArcTool.js](../src/tools/ArcTool.js)、[PolygonTool.js](../src/tools/PolygonTool.js) は `inputPresetVersion = 1`、`exportInputPreset()`、`restoreInputPreset(entry)` で接続します。全入力とアクティブ状態を検査してから現在の下書きを置き換えます。

計算は既存の [drawing.js](../src/model/drawing.js) の矩形・円・3点円弧・多角形と計算レジストリー、描画はホストの描画レジストリーと [svgGeometry.js](../src/adapters/svgGeometry.js) です。標準では矩形はSVG rect、円はSVG circle、円弧はSVG A、多角形はSVG polygonになります。円・円弧は既存の折れ線近似・三次ベジェ近似の描画も使えます。矩形・多角形の外部描画は、それぞれの管理UIが扱うSVG要素操作と整合する必要があります。

新しい幾何アルゴリズム、論文、外部ライブラリは導入していません。既存の名前付き方式・文献・参照履歴は [algorithms.md](algorithms.md)、換装契約とメインシステムに統合する条件は [implementation-options.md](implementation-options.md) にあります。
