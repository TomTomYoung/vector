# 円の元データ編集と描画方式の切替

更新日: 2026-11-16（日本時間）。標準SVGの円、折れ線で描いた円、三次ベジェで描いた円を、保存した中心・半径から再編集できます。新しい計算機能やツールボタンは追加せず、既存の選択ツールと計算・描画レジストリーへ接続しています。

## 操作

選択ツールで円を1個選び、ツールプロパティの「円の元データを編集」から「円を再編集」を押します。中心X・Y、半径、再描画の分割数、登録された計算・描画実装を変更し、「プレビュー」「適用」「取消」を操作できます。ツール変更、選択変更でも編集を取り消します。Escはドラッグ中ならその移動だけを、移動していない場合は再編集全体を取り消します。

座標は図形のローカル座標です。親グループと図形自身の移動・回転・反転・縦横別拡縮を保持します。プレビューはキャンバスの座標へ変換して青い破線で表示し、SVG保存には含めません。適用はUndo/Redoの1段階です。半径は正の有限値、分割数は2〜10000の整数です。分割数は等分割描画で使用し、標準SVG・三次ベジェでは使用しません。

「再描画実装」の `default` はSVG `circle`、`sampled` は円の媒介変数を等分割した閉じた `M/L` パス、`cubic` は4区間の三次ベジェ近似です。標準円とパス間の切替ではSVG要素を置換しますが、ID、外観、変換、レイヤー、親内の順序、子のtitle等を引き継ぎ、選択先も更新します。同じ種類のSVG要素へ適用する場合は要素自体を維持します。次の作図に使う方式設定と、その保存内容は変更しません。

## 中心・半径ハンドル

「円を再編集」を開くと、入力中心と円周上の半径ハンドルを表示します。中心のドラッグは半径を保持し、半径のドラッグは中心を保持します。半径ハンドルはドラッグした方向へ移動します。これらは計算実装に渡す入力を表し、独自の計算実装が中心・半径を変更して出力する場合は、出力プレビューと位置が異なることがあります。

ハンドルは画面上で一定サイズで、親グループの回転、反転、縦横別拡縮、ズーム、パンに追従します。グリッドスナップ後にShift・直交モードの拘束を図面座標で適用し、半径は図形のローカル座標に戻して中心からの距離を求めます。中心の移動ではドラッグ開始時の中心、半径の変更では中心を直交拘束の基準にします。つかんだ位置のずれを保持し、クリックだけではスナップしません。

ドラッグは数値欄とプレビューを更新し、「適用」まで元図形・保存内容・Undo履歴を変更しません。画面外でポインターを離した場合も最後の位置を反映します。Esc、pointercancel、ポインター取得の喪失、ウィンドウのフォーカス喪失では、そのドラッグ前の入力へ戻します。ドラッグ前に行った数値変更や別のドラッグの結果は保持します。Spaceによるパンを優先し、別のポインターには反応しません。

ロック、元形状の変更、削除、非可逆な変換ではドラッグを拒否し、補助表示を外します。変換や数値入力が有効に戻るとハンドルを復元します。半径0や有限範囲を超える値は適用せず、中心が極端に大きく半径ハンドルを浮動小数点で表せない場合は数値編集を使います。小さい円でハンドルが重なる場合はズームまたは数値欄で編集できます。

## 計算・描画と参照元

計算は [drawing.js](../src/model/drawing.js) の `circle` です。作図では中心から入力点までのユークリッド距離を半径とし、今回の再編集では中心と明示半径を使います。中心が大きいときに `中心 + 半径 - 中心` の丸めで半径が失われないよう、標準実装は明示半径をそのまま保持します。

描画は既存の [renderStrategies.js](../src/adapters/renderStrategies.js)、[curveAnalysis.js](../src/model/curveAnalysis.js) の `arcToCubics`、[svgGeometry.js](../src/adapters/svgGeometry.js) を再利用します。円の媒介変数表示、90度以下の区間と接線方向の係数 `4/3 tan(Δθ/4)` による三次ベジェ近似、SVG仕様については [algorithms.md](algorithms.md) の円・円弧と描画の節、[文献と参照履歴](algorithms.md#references)を参照してください。追加したのは元モデルの保存・照合と編集UIで、新しい論文のアルゴリズムを導入したものではありません。三次ベジェ・折れ線は近似であり、SVG `circle` と同じ幾何表現ではありません。画素化はブラウザーに委ねます。

ハンドル入力は [circleControlGeometry.js](../src/adapters/circleControlGeometry.js) で計算します。既存の [splineControlGeometry.js](../src/adapters/splineControlGeometry.js) のアフィン変換・逆変換、つかみ位置保持、図面座標でのスナップと直交拘束を再利用し、半径をローカル座標でのユークリッド距離から求めます。[CircleControlHandles.js](../src/ui/CircleControlHandles.js) がポインターの取得・取消、数値欄との同期、表示更新を担当します。

円当てはめ `fitCircle` や最小包含円などが返した円も、中心・半径から編集できます。点群への当てはめをやり直す操作ではありません。適用後の記録は `tool: circle` と実際に使った計算・描画実装になり、元の生成方式を `circleEdit.origin` に残してプロパティに表示します。元の点群や当てはめ残差は再編集モデルに含めません。

## 保存形式と実装契約

[editorHost.js](../src/adapters/editorHost.js) が `kind: circle` をSVG `circle` または `path` に描画したとき、`data-vector-circle` に `version: 1`、`model: {kind: circle, center: {x, y}, radius}`、出力形状の照合情報 `geometry` を保存します。`geometry` はネイティブ円なら `tag/cx/cy/r`、パスなら `tag/d` です。SVG保存・読込とUndo/Redoで同じ属性を維持します。

[circleSource.js](../src/adapters/circleSource.js) がモデルと照合情報を検査し、[CircleEditor.js](../src/ui/CircleEditor.js) が編集を処理します。輪郭や保存された元モデル・方式記録が編集中に変わった場合、ロック・非表示・削除・選択変更、入力不正、未登録実装では、元図形への適用を拒否します。未登録IDは選択欄に残し、利用者が明示的に登録済み実装を選び直せます。

旧データ・外部SVGのネイティブ `circle` は、有限の数値として読める `cx/cy/r` から編集できます。`cx/cy` の省略は0として扱います。元データを持たないパスから中心・半径を推定する機能はありません。属性が百分率・単位付きの場合、CSSの幾何プロパティやアニメーションで形状が制御される場合は対象外です。

計算実装の換装では、再編集用入力 `{center, radius, point}` の `radius` を明示半径として扱い、有限の中心と正の半径を持つ `kind: circle` を返してください。互換用の `point` は `{x: center.x + radius, y: center.y}` です。旧実装がこの点との距離しか使わない場合、非常に大きい座標では丸めの影響を受けます。描画実装は `supports('circle')` を満たし、同じローカル座標系の単一SVG `circle` または `path` を返すものが再編集対象です。グループ・線分・独自座標系の出力、外部 `execute` 全体の置換によって方式選択APIを持たないホストは対象外です。

既存の円専用一覧は引き続きネイティブ円を扱います。そちらの中心・半径編集とアフィン変換の形状への焼込みは古い元モデルを無効化し、属性編集として方式を記録します。選択ツールから再び編集すると実際の属性を使います。従来の焼込みは縦横別拡縮でも半径方向の1点から円へ近似するため、その性質を方式表示にも明記します。通常の選択ツールによるアフィン変換は変換属性を保持します。
