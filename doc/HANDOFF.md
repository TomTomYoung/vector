# vector 開発ハンドオフ

更新日: 2026-11-17（日本時間）。この文書は作業再開用です。前回の実装・公開確認の基準は [24acea3](https://github.com/TomTomYoung/vector/commit/24acea3bb11717fe46cfcaeb840c7b57fda0bfd9)（PR #86）です。今回は周期B-spline・同符号重みの周期NURBSへ許容差付きノット削除を接続しました。

## 現在の到達点

リポジトリは [TomTomYoung/vector](https://github.com/TomTomYoung/vector)、開発・公開の基準ブランチは `master` です。[エディタ](https://tomtomyoung.github.io/vector/)と[演算室](https://tomtomyoung.github.io/vector/geometry.html)を GitHub Pages で公開しています。

計算は120機能、GUIは31ツールです。幾何計算をJavaScriptの独立関数に分離し、ホストを介して入力・演算・図形変換・SVG出力・保存を接続しています。SVGの画素化はブラウザーが担当します。

直近の依頼は、計算と描画のアルゴリズム・論文・実装元をdocから追えるようにすること、実装可能な代替方式を選択・換装できるようにすること、別ツールにする方が適したものは追加すること、ツールプロパティに使用方式を表示すること、現行システムと相性が悪い方式も統合条件とともに記録することでした。この範囲は下記PRで実装・統合・公開済みです。

[PR #49](https://github.com/TomTomYoung/vector/pull/49)で領域境界の復元、制約付き三角分割、ベジェ交点、寸法拘束の計算を追加しました。[PR #50](https://github.com/TomTomYoung/vector/pull/50)で各機能の計算・描画方式と文献・参照履歴を記録し、[PR #51](https://github.com/TomTomYoung/vector/pull/51)で方式選択・換装API、9作図ツール、使用方式の表示・保存を追加しました。

## 2026-11-16の追加実装

B-spline・NURBSの内部不連続ノット、零・負の重み、一様ノットの周期曲線を実装しました。分母のBernstein係数の範囲を使って区間を再分割し、分母零付近や処理上限で未確定の区間を描画から外して別サブパスにします。プロパティに周期指定・分母の除外幅・検査深さを追加し、元のスプラインモデルと省略区間をSVGに保存します。機能数119・GUI31は変わりません。

詳細、入力例、参照した一次資料は [spline-branches.md](spline-branches.md)です。[PR #53](https://github.com/TomTomYoung/vector/pull/53)の実装コミット `5ba9944` に対する[CI](https://github.com/TomTomYoung/vector/actions/runs/43730176808)で、数値回帰66件・ブラウザー操作22件が全て成功しました。以下に残した旧CIの成功記録はPR #51時点の結果です。

## 保存スプラインの再編集

選択ツールでB-spline・NURBSを1個選び、ツールプロパティの「曲線の元データを編集」から編集できます。制御点座標、次数、ノット、周期、重み、描画設定、登録済みの計算・描画実装を変更し、プレビュー・適用・取消を操作できます。同じSVG要素を更新して変換・外観・レイヤーを保持し、1回のUndo/Redoで戻せます。部分描画では塗りをなしにします。

保存形式に出力パスの照合情報を追加し、旧形式は標準描画で照合します。古くなった元モデル、入力エラー、編集中の形状変更、ロック対象は適用を拒否します。トリム・分割・延長で輪郭を直接変えた場合は元モデルを無効化します。詳細と残る制約は [spline-editing.md](spline-editing.md)です。

[PR #54](https://github.com/TomTomYoung/vector/pull/54) の実装コミット `e42e9a7` に対する[CI](https://github.com/TomTomYoung/vector/actions/runs/43742784799)で、数値・モデル・編集テスト73件とブラウザー操作26件が全て成功しました。親グループの回転・拡縮を含むプレビュー、保存済みモデルの再編集、1回のUndo/Redo、取消・入力エラー・ロック・形状不一致、周期制御点の循環解除、実装選択の独立性を確認済みです。

## 方式設定の保存・復元

GUIで選んだ計算・描画実装と描画設定をブラウザーへ自動保存し、起動時に復元します。全ツールの保存・復元・初期化、JSON書出し・読込をツールプロパティに追加しました。B-spline・NURBSの描画分割数と分母検査設定も保存します。既存図形の形状・方式記録と、一時的な曲線再編集の方式選択は変更しません。

未登録実装・非対応描画・範囲外設定は理由を表示して読み飛ばし、不正な形式は適用しません。保存機能が使えない場合もエディタの起動と作図を継続します。明示的な起動設定を優先でき、埋込先では保存先の分離・無効化が可能です。仕様・API・保存対象・残る範囲は [implementation-preferences.md](implementation-preferences.md)に記録しています。

## スプライン制御点のドラッグ

## 円の元モデル再編集

標準円・折れ線・三次ベジェで描いた円の中心・半径を保存し、選択ツールから再編集できます。描画方式の切替では外観・変形・レイヤー・親内順序を保持し、選択を新しいSVG要素へ引き継ぎます。プレビュー・適用・取消、SVG保存・読込、Undo/Redo、古い元モデルの照合を接続しました。

円当てはめ等の元の生成方法を履歴として表示し、中心・半径による再編集とは区別します。旧ネイティブ円と従来の円属性編集にも対応し、次の作図の方式設定は変更しません。仕様・換装契約・残る制約は [circle-editing.md](circle-editing.md) です。[PR #57](https://github.com/TomTomYoung/vector/pull/57)の実装コミット `1aad74f` に対する[CI](https://github.com/TomTomYoung/vector/actions/runs/43773702764)で、数値・モデル・編集91件と実Chromeのブラウザー操作40件が全て成功しました。最初のCIで見つけた既存の円の変形焼込みの不具合も修正しました。SVGの変換リストをブラウザーのSVG行列から読み取ります。

## 円弧の元データ保存・再編集

3点円弧の始点・通過点・終点を保存し、選択ツールから数値欄・名前付きハンドルで再編集できます。向き・大きい弧・小さい弧を再計算し、標準SVG円弧・折れ線・三次ベジェの描画を切り替えられます。実際の通過点を保持し、元の生成方式と現在の計算・描画実装をプロパティに表示します。

[algorithms.md](algorithms.md)は既存機能の計算と描画の対応、名前の付いたアルゴリズム、論文・一次資料、参照履歴です。この文書の117機能・22ツールの一覧はPR #51より前の標準実装を対象とし、追加方式と現在の120機能・31ツールへの差分は `implementation-options.md` にあります。[文章.md](文章.md)は数式と入出力、[model/README.md](../src/model/README.md)は計算関数の利用方法です。

GUIでは、ツールを選択するとツールプロパティに「実装・アルゴリズム」が表示されます。代替実装がある場合は「計算の実装」「描画の実装」を選択できます。選択図形に記録された方式は、次の作図に使う設定と分けて表示します。演算室でも計算方式を選択し、入力例を編集してWorkerで実行できます。

グリッド表示は、スタイル操作欄の「表示・補助」内の「グリッド」です。同じ場所に「グリッドスナップ」と「直交モード」があります。表示とスナップは別設定で、初期値はいずれもOFF、間隔は20図面単位です。実装は [GridManager.js](../src/ui/GridManager.js)、初期値は [App.js](../src/core/App.js)にあります。

## 実装済みの切替方式と追加ツール

計算の代替方式は、`spline` の一様・求心・弦長 Catmull–Rom、`offset` のmiter、`convexHull` のJarvis marchとBigInt厳密符号版Andrew、`clipSegmentToBox` のCohen–Sutherland、`delaunayTriangles` のBigInt厳密符号版です。各ツールの標準方式は引き続き選択できます。120機能すべてに方式の説明がありますが、すべてに複数の代替実装があるわけではありません。

描画の代替方式は、等分割de Casteljau・円の媒介変数表示、Bernstein直接評価、de Casteljau適応分割、円弧の三次ベジェ近似です。対応するツールだけに選択肢を出します。標準のSVG `Q` / `C` / `A` / `circle` 等も残しています。

追加GUIは `bSplineCurve`、`nurbsCurve`、`convexHull`、`triangulatePolygon`、`delaunayTriangles`、`voronoiCells`、`fitLine`、`fitCircle`、`minimumEnclosingCircle` の9種類です。クリックで点を追加し、Enterで確定、Backspaceで最後の点を削除、Escで取消します。B-spline・NURBSには次数、ノット列、描画分割数、NURBSには重みの入力があります。新しい計算エントリーは前2件で、後7件は既存計算をGUIへ接続しました。

## コードの所在と変更時の接続先

計算の入口は [tools.js](../src/model/tools.js)の `createToolset()` です。[implementationRegistry.js](../src/model/implementationRegistry.js)が登録・選択・実行・委譲履歴を扱い、[toolMetadata.js](../src/model/toolMetadata.js)が120機能の名称・アルゴリズム・実装元を持ちます。代替計算は [alternatives.js](../src/model/alternatives.js)、厳密な符号判定は [exactPredicates.js](../src/model/exactPredicates.js)、追加スプライン図形の検証とサンプリングは [splineCurves.js](../src/model/splineCurves.js)です。

描画方式の登録と図形変換は [renderStrategies.js](../src/adapters/renderStrategies.js)、SVG要素・パスへの出力は [svgGeometry.js](../src/adapters/svgGeometry.js)です。[editorHost.js](../src/adapters/editorHost.js)が計算と描画をつなぎ、使用方式を図形へ記録します。

元モデル再編集は [SplineEditor.js](../src/ui/SplineEditor.js)、保存データの読込と照合は [splineSource.js](../src/adapters/splineSource.js)です。

GUI登録は [App.js](../src/core/App.js)、共通の作図・輪郭編集接続は [BaseTool.js](../src/core/BaseTool.js)、追加9ツールの共通コントローラーは [PointConstructionTool.js](../src/tools/PointConstructionTool.js)です。プロパティ表示と方式選択は [ToolPropertiesPanel.js](../src/ui/ToolPropertiesPanel.js)にあります。新しい通常スクリプトを使う場合は [index.html](../index.html)の読込順も更新します。

演算室の入力例は [geometryExamples.js](../src/ui/geometryExamples.js)、選択UIは [GeometryWorkbench.js](../src/ui/GeometryWorkbench.js)、実行と結果分類は [geometryWorker.js](../src/ui/geometryWorker.js)です。計算エントリーを追加した場合は入力例も追加し、登録数と全例の実行が一致するようにします。

保存と読込は [DrawingDocument.js](../src/core/DrawingDocument.js)、Undo/Redoは [HistoryManager.js](../src/ui/HistoryManager.js)です。`data-vector-implementation` のJSONに計算・描画の実装ID、説明、ソース、委譲先、描画設定、許容差未達の警告等を記録します。描画途中のプレビュー、グリッド、選択ハンドルは保存対象から除きます。履歴保存はイベント完了後のマイクロタスクでまとめる仕組みです。

## 維持する契約と既知の制約

`createToolset()` は従来どおり関数として呼べます。追加APIは `register`、`select`、`list`、`describe`、`selection`、`trace`。実装関数の引数は `(input, operations, execute)` です。第3引数の `execute` を使う委譲先には方式選択が伝わりますが、内部で直接importした関数へは波及しません。変更対象の戻り値と利用側の契約を確認します。

設定はエディタごとに独立し、初期設定には `window.vectorEditorOptions` を使います。`tools` や `render` を外部実装へ差し替えた場合、既定実装のアルゴリズム名を流用しません。関数内容を自動判定する機能はなく、計算の説明を指定する場合は `metadata` を渡します。

保存された方式情報は、図形の生成・輪郭編集時の記録です。入力点・全計算パラメーター・編集履歴を網羅する再計算モデルではありません。既存図形を選択して作図用方式を変更しても、その図形を自動で再計算しません。B-spline・NURBSは専用の再編集欄で元モデルから再計算し、適用した時点で更新します。作図用方式選択と描画設定はブラウザー保存・起動時復元に対応しました。個別図形の生成記録から作図設定を自動で変更することはありません。SVGを読み込んで任意の実装コードを自動実行する仕組みにはしていません。

円を折れ線や三次ベジェで描くと、出力要素が `circle` から `path` になります。通常の選択・アフィン変換はできますが、円専用の半径編集一覧には入りません。タグ変更を伴う `render` 呼出しでは、返された新しい要素を保持する必要があります。外部描画実装は、対象コントローラーのSVG操作と整合する範囲を `supports` で指定します。

BigInt版は、binary64入力に対する向き・外接円の行列式の符号を厳密に計算します。Shewchukの適応的展開算術ではなく、交点座標の厳密構成でもありません。`orientation` の大きさを補間比 `f/(f-g)` に使う処理へ、-1/0/1の符号関数を一律に差し替えないでください。今回の接続先は凸包と非拘束Delaunayです。

B-spline・NURBSは次数1〜12、入力制御点は最大1000点、内部ノットの重複度は次数+1までです。零・負の有限な重みを受け付け、全重み零は拒否します。周期指定は一様・非一様ノットと次数以下の循環重複に対応しています。`data-vector-spline` に元のモデルを保存し、`data-vector-implementation.sampling` に省略区間・処理上限・枝数を保存します。描画は分離したSVG折れ線で、元のモデルからの再編集UIを実装済みです。制御点は座標欄と画面上のドラッグの両方で編集できます。

描画の等分割はパラメータ方向で、弧長の等分割ではありません。適応分割の許容差は図面単位です。上限に達して許容差を満たさなかった場合は警告を保持します。既存の交点探索の `complete`、拘束計算の `converged` も結果表示で区別し、計算打切りを成功扱いしない設計を維持します。

資料は「実装時参照」「文書化時照合」「仕様参照」を区別します。名前が同じという理由で論文の全手順・性能・保証を実装済みとしません。実装や選択肢を追加・変更した場合は、コード、表示メタデータ、入力例、方式文書の対応も更新します。
