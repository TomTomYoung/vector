# 名前付きの計算・描画方式プリセット

更新日: 2026-11-17（日本時間）。全ツールの計算実装ID・描画実装ID・描画設定を1組として、1図面に複数の名前付き記録を保存できます。例えば、スプラインの求心版と円の3次ベジェ描画を組み合わせた設定、一様版と標準円描画を組み合わせた設定を、別名で保持できます。

## 操作と表示

ツールプロパティの「実装・アルゴリズム」から「名前付きの計算・描画方式（SVGに複数保存）」を開きます。「記録名」を入力し、「現在の全ツールの方式を名前付き保存」で追加します。標準ホストでは全119演算の計算選択と対応する描画設定を記録します。現在のツールだけを保存する機能ではありません。

一覧で名前を選ぶと、記録された計算・描画の項目数と、現在のツールの実装ID・アルゴリズム名・描画設定を表示します。現在使用中の方式は、その上の方式選択欄に表示します。アルゴリズム名は現在の実装レジストリーから取得し、未登録IDは「この環境では未登録」と表示します。名前や外部の実装情報は文字列として表示します。

「選択した方式を次の作図に適用」で互換性のある項目を適用します。名前の選択とSVGの読込だけでは方式を切り替えません。現在の下書きがあれば、その点列・数値設定・文字内容を保持して、選択中ツールの未確定プレビューを更新します。完成済み図形とその使用方式記録は変更しません。

「選択記録を現在の方式で更新」は、その記録全体を全ツールの現在値で置き換えます。「選択記録を改名」は名前だけを変更し、IDと方式を維持します。「選択記録を別名で複製」は保存済みの方式を新しいIDで複製し、複製元を維持します。「選択記録を削除」は選択した記録だけを削除し、使用中の方式は維持します。新規保存と複製の後は新しい記録が選択されます。

記録名は前後の空白を除いて1〜100 UTF-16単位とし、改行・制御文字は受け付けません。日本語を使用できます。同じ図面内の名前は完全一致で重複を禁止します。新規保存・更新・改名・複製・削除は、それぞれ図面のUndo/Redoで1段階ずつ戻せます。同じ内容を再記録して図面データが変化しなかった場合は履歴を増やしません。名前の選択と方式の適用は図面履歴に追加しません。Undo/Redoによる記録の復元も方式を自動適用しません。

## 保存範囲と互換性

「SVG保存」で完成図形と全ての名前付き方式を保存します。一覧選択と入力中の記録名は画面内の一時状態です。ツール切替では維持しますが、SVG読込とUndo/Redoでは先頭の記録に戻ります。方式の適用状態をそのまま保存する場合は、現在の方式を新規記録するか、既存の記録を更新してからSVGを保存します。

従来の[図面に1組の方式記録](document-implementation-presets.md)があれば、「従来の図面記録を名前付きで複製」を使用できます。保存済みの従来記録をコピーするので、現在の方式を変えていても元の保存値を取り込みます。従来の記録と名前付き記録は別領域で、一方の更新・削除は他方へ影響しません。[名前付き作図入力](named-construction-inputs.md)と従来の作図入力記録も独立しています。

適用はブラウザーの保存設定を書き換えません。通常の方式選択欄を後で変更した場合や「現在の方式設定を保存」を押した場合は、その時点の全ツールの方式が従来どおりブラウザーへ保存されます。保存済みのブラウザー設定へ戻すには「保存した方式設定を復元」を使用します。ブラウザー保存が拒否されていても、また `preferences:false` の埋込みでも、SVG内の名前付き記録は使用できます。

未登録ツール・実装、対象ツールに非対応の描画方式、範囲外の描画設定は適用せず、項目と理由を表示します。互換性のある項目は適用します。計算と描画は独立項目です。部分的な記録では省略項目の現在値を維持し、描画optionsは記録された項目ごとに置き換えます。外部renderの復元非対応も既存のホスト契約に従って報告します。

未登録ID・適用できなかった設定も記録に残り、再保存・改名・複製・Undo/Redoで保持します。対応実装の登録後に再度適用できます。ただし「現在の方式で更新」は以前の記録全体を置き換えるため、現在のホストが書き出さない項目は更新後の記録から除かれます。実装コードやライブラリはSVGに含めず、自動取得・実行もしません。

不正な形式・版・重複ID・重複名・上限超過を含むSVGは、図形・現在の下書き・選択・レイヤー・履歴・各プリセットを置き換える前に全体を拒否します。保存や更新の失敗でも、以前の全記録と選択IDを維持します。計算に失敗したプレビューは各ツールのエラー表示を使用し、入力を維持したまま別の方式を適用して再試行できます。

記録のない旧SVGを開くと、名前付き方式の記録は空になります。現在使用中の方式は維持します。旧アプリは従来の図形と従来の方式記録を読めますが、名前付き方式に未対応の旧アプリで再保存すると追加領域は失われます。

## データ形式と実装

`metadata[data-vector-document="1"]` のJSONに、任意の兄弟項目 `namedImplementationPresets` を追加します。従来の `implementationPreset`、`constructionInputs`、`namedConstructionInputs` の形式は変更しません。最後の名前付き方式記録を削除した場合は、このキーを省略します。

```json
{
  "namedImplementationPresets": {
    "version": 1,
    "entries": [
      {
        "id": "methods-example",
        "name": "求心スプラインとベジェ円",
        "preset": {
          "version": 1,
          "calculation": {"spline": "centripetal"},
          "rendering": {"circle": {"id": "cubic", "options": {}}}
        }
      }
    ]
  }
}
```

集合は版1、最大256記録、JSON全体で2000000 UTF-16単位です。IDは集合内で一意、1〜100文字の英数字・ハイフン・アンダースコアで、プロトタイプ用の予約名は拒否します。集合と各記録のキーは固定です。各 `preset` は[方式設定のversion 1](implementation-preferences.md)を使用し、それぞれ256000文字、入れ子12階層、検査要素20000個の上限があります。非有限数・関数・特殊オブジェクト・危険なプロパティ名を拒否します。未知の集合版・方式設定版も拒否します。未知の実装IDをデータとして保持することとは区別します。

[namedImplementationPresets.js](../src/adapters/namedImplementationPresets.js) の `parseNamedImplementationPresets(value)` が形式検査と独立コピーを行います。`createNamedImplementationPresets(host)` は `snapshot()`、`list()`、`entry(id)`、`selectedId()`、`choose(id)`、`nameDraft()`、`setNameDraft(value)`、`open(value)`、`add(name,preset)`、`record(name)`、`update(id)`、`rename(id,name)`、`duplicate(id,name)`、`remove(id)`、`apply(id)` を提供します。`apply` のID省略時は選択中の記録を使います。`open(undefined)` は記録を消去します。

各変更はコピーを検証した後で確定します。ホストの `exportPreferences()` と `restorePreferences()` を利用し、`canRecord` と `canApply` で対応状況を示します。非対応の外部ホストでは方式の記録・更新・適用を無効にし、既存記録の保持・改名・複製・削除は可能です。直接APIで記録を変更して履歴へ残す場合は `host.save()` を呼びます。適用API自体は描画を実行せず、GUIが現在のコントローラーへ `onImplementationChanged()` を通知します。

[App.js](../src/core/App.js) がエディタごとに管理器を生成し、[DrawingDocument.js](../src/core/DrawingDocument.js) がSVGと履歴に接続し、[ToolPropertiesPanel.js](../src/ui/ToolPropertiesPanel.js) が操作と記録方式の表示を提供します。表示処理は従来の1件方式記録と共通化しています。

新しい幾何計算・描画アルゴリズム、論文、外部ライブラリは導入していません。各方式の実装元・文献・換装契約は [implementation-options.md](implementation-options.md) と [algorithms.md](algorithms.md) を参照してください。実装の版・依存環境を固定して再現性を保証する仕組みは含みません。
