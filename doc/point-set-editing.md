# 点群の保存と再編集

更新日: 2026-11-16（日本時間）。対象は `fitLine`（直線当てはめ）、`fitCircle`（円当てはめ）、`minimumEnclosingCircle`（最小包含円）、`convexHull`（凸包）、`delaunayTriangles`（Delaunay三角分割）です。三角分割のグループ編集・インデックス契約は [delaunay-editing.md](delaunay-editing.md) を参照してください。凸包の操作・方式切替・保存形式の詳細は [convex-hull-editing.md](convex-hull-editing.md) を参照してください。

## 画面操作

各ツールで点をクリックしてEnterで確定すると、入力した点の順序・重複、計算結果、描画後の形状を図形に保存します。直線当てはめは2〜1000点、円当てはめは3〜1000点、最小包含円は1〜1000点です。最小包含円の1点入力は半径0の円として保存し、選択後に点群を増やして再計算できます。

選択ツールで図形を選び、ツールプロパティの「元の点群から再計算」から「点群を再編集」を押します。座標欄の1行を1点として扱い、行を追加・削除できます。座標は図形のローカル座標です。番号付きハンドルはドラッグで移動できます。親グループ・図形のアフィン変換・ズームを反映し、ハンドルの大きさは画面上で一定です。グリッドスナップとShift・直交モードは図面座標で作用します。

計算実装と描画実装を選んでプレビューし、「適用」で元図形を更新します。各選択肢のアルゴリズムを表示します。描画実装は直線が標準SVG線分、円が標準SVG円・折れ線・三次ベジェです。登録済みの外部実装も契約を満たす場合に選べます。直線・円の計算実装は各方式1つで、別の当てはめ法を新規実装したものではありません。凸包はAndrew・Jarvis・BigInt厳密符号版の既存3方式、Delaunayは標準・BigInt厳密符号版の2方式から選択できます。点群の処理方法そのもの（直線・円・最小包含円・凸包・Delaunay）は生成時のものを維持します。

ドラッグ中のEsc・ポインター取消・フォーカス喪失はその移動だけを戻します。それ以外のEsc・取消は再編集全体を終了します。元図形は適用まで変えず、補助表示をSVG保存へ含めません。適用1回をUndoの1段階にし、Redo・SVG保存と読込にも点群を引き継ぎます。外観・変形・レイヤー・親内順序・子要素・選択を保持します。計算不能な一直線の円当てはめ等では、有限な点のハンドルを残して修正できます。

円の中心・半径編集と点群編集は一方を開始すると他方の未適用ドラフトを取り消します。中心・半径編集を適用した場合、点群への関連は解除され、`circle` の再計算として記録します。輪郭の分割など直接編集でも関連を解除します。数値属性やパスが外部から変更された場合、保存時の形状と照合して不一致を拒否します。元データのない過去のSVGから入力点を推定しません。

## 計算・描画と文献

直線当てはめは点群の共分散行列の主軸を用いるTLSです。図形の描画は、元の各点を結果の直線へ投影し、その最小・最大位置を端点とする線分です。外部実装の方向ベクトルは描画範囲の計算時に正規化します。保存する結果には実装が返した方向を保持します。

円当てはめは中心化した座標によるKåsa型代数的最小二乗です。`rms` は当てはめ後の幾何距離から測った値で、最適化する代数的目的関数とは区別します。最小包含円は入力順の逐次追加と1点・2点・3点の支点の更新です。入力をランダム化せず、Welzl法や期待線形時間の実装とは記載しません。計算本体は [pointSets.js](../src/model/pointSets.js) を使用しています。

論文・一次資料・参照履歴は [algorithms.mdの点群](algorithms.md)、[R11](algorithms.md#r11)、[R12](algorithms.md#r12) にあります。既存実装と文献の照合結果を継承したもので、今回の編集UIに新しい計算論文を適用したわけではありません。円の描画方式は [implementation-options.md](implementation-options.md) を参照してください。

## 保存形式と換装契約

`data-vector-pointset` のJSONは `version: 1`、`method`、`input.points`、`result`、`geometry` を持ちます。`result` は直線の `kind: line / point / direction`、円の `kind: circle / center / radius` と任意の `rms`、凸包の外周頂点配列、またはDelaunayの三角形インデックス配列です。`geometry` は実際に出力したSVGのタグと幾何属性の文字列です。元の点の重複を除去したり並べ替えたりしません。

`data-vector-implementation` には実際の計算・描画ID、アルゴリズム、実装元、委譲履歴、描画設定、`parameters.pointCount` と任意の `parameters.rms` を記録します。再編集後の `pointSetEdit.origin` は最初の生成方式を保持し、履歴を入れ子に蓄積しません。円の中心・半径編集も可能にするため、円の出力には既存の `data-vector-circle` も保存します。

計算登録は既存の `registerImplementation(method, {id, label, algorithm, run})` を使用し、入力は `{points}`、出力は上記の直線・円・凸包・Delaunayの契約です。座標・半径・RMSと描画範囲は有限、方向は零でないことが必要です。円の半径は0以上、RMSは0以上です。計算が `null` を返す場合は適用しません。実装を選んだ再計算が失敗しても、元の計算選択へ戻します。再編集用の選択・分割数は次の作図用設定へ保存しません。

`editorHost.render(shape, target, options)` に `sourceInput: {points}` と `sourceResult` を渡すと点群を記録します。`shape` への変換は `pointSetGeometry(method, input, result)` を使います。この2つの予約オプションは描画実装の設定に渡さず、図形の再計算用データにだけ使います。元入力のない既存の呼出しには架空の点群を追加しません。再編集で受け付けるSVG表現は直線が `line` または `path`、円が `circle` または `path`、凸包が `polygon` または閉じた `path`、Delaunayが各面を直下に並べた `g` です。

保存・照合・投影は [pointSetSource.js](../src/adapters/pointSetSource.js)、UIは [PointSetEditor.js](../src/ui/PointSetEditor.js)、ドラッグは既存の [SplineControlHandles.js](../src/ui/SplineControlHandles.js)、作図は [PointConstructionTool.js](../src/tools/PointConstructionTool.js) です。

## 残る範囲

重み付き・ロバスト当てはめ、最小二乗円の幾何距離最適化、観測誤差・信頼区間の表示、点群のファイル入出力、全図形に共通する入力モデル、任意の外部SVGからの点群復元は未導入です。各点と別の図形との継続的な拘束も保持しません。近い退化配置や極端な大きさの入力について、新たな数値精度保証を追加したものではありません。有限性・点数・描画分割数を検査し、計算不能・不一致・未登録実装を表示します。
