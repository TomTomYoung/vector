# 名前付き記録の検索と並べ替え

更新日: 2026-11-17（日本時間）。名前付き入力、名前付き計算・描画方式、作図セットの各欄に、検索と並べ替えを追加しました。

## 検索

「記録を検索」へ記録名またはIDの一部を入力します。Unicode NFKC正規化と日本語ロケールでの小文字化を行うため、全角・半角の英数字や英字の大小をそろえて照合します。空白で区切った複数語は全て含む記録を表示します。検索語が空なら全件を表示します。入力とセットは現在のツール、方式は図面全体の記録が対象です。

検索だけでは記録の選択、下書き、使用方式、履歴を変更しません。現在選択中の記録が検索に一致しない場合も「選択中・検索対象外」と明示して一覧に残します。検索結果件数は一致した記録だけを数えます。入力欄のフォーカスを維持するので続けて文字を入力できます。

検索語は各欄・各ツールごとに画面内で保持します。プロパティの再表示やツール切替では維持し、SVG全体の読込・Undo/Redoでは消去します。SVGやブラウザー保存領域へは記録しません。並べ替えは検索で隠れている記録も含めた全体に適用します。

## 順序の変更

記録を選択して「上へ」「下へ」を押すと、その記録を同じ一覧の前後の記録と入れ替えます。先頭・末尾では移動できない方向を無効にします。「名前順に並べ替え」は日本語ロケールの文字列比較と数値比較を使います。例えば円1、円2、円10の順になります。

入力とセットは同じツール内だけを並べ替え、他のツールの記録が入っている位置を維持します。方式は図面全体を並べ替えます。ID・名前・保存値を変更せず、現在選択中のIDと入力中の記録名も維持します。未知の入力版や未登録方式を持つ記録も、内容を実行せず順序だけ変更できます。

変更した順序はSVGのentries配列へ保存し、別の画面でも同じ順序で表示します。各並べ替えは1段階のUndo/Redoに対応します。既に同じ並びの場合は履歴を増やしません。Undo/Redoは従来どおり図面状態を読み込むため、検索語と一時的な選択状態はリセットされます。順序を戻す操作で入力や方式を自動適用しません。

## 実装と検証

[presetOrder.js](../src/adapters/presetOrder.js) に `filterPresets(entries,query)`、`movePreset(entries,id,direction,tool)`、`sortPresets(entries,tool)` を追加しました。検索はデータを変更せず、並べ替えは各管理器が作成した検証用コピー上で行います。各管理器の `move` と `sort` は記録集合を検証してから置き換えます。移動方向は上が-1、下が1です。IDが不正なら元の記録を維持します。

文字列の並べ替えはJavaScriptの `localeCompare` に `ja` と `{numeric:true,sensitivity:'variant'}` を指定し、同順位の記録順は維持します。検索は `normalize('NFKC')` と `toLocaleLowerCase('ja')` を使います。ブラウザーの国際化データの版によって、一部文字の比較結果が異なる可能性はあります。保存済みのentries順は、読み込み時に自動で再ソートしません。

[presetOrder.test.mjs](../tests/presetOrder.test.mjs) は他ツールの位置・値の維持、境界と不正な移動、名前の数値順と安定性、Unicode正規化検索、3管理器の選択ID・入力名・保存順を検証します。[editor.html](../tests/editor.html) は入力フォーカス、検索対象外の現在選択、履歴・下書き・方式の非変更、上下移動・名前順・SVG往復・Undo/Redo、未知版、境界の無効化、同順序時の履歴非追加を検証します。

幾何計算・描画アルゴリズムは追加していません。文献と実装元は [algorithms.md](algorithms.md)、換装仕様は [implementation-options.md](implementation-options.md) にあります。記録のフォルダー分け、検索結果だけの一括削除、ドラッグによる並べ替えは未導入です。
