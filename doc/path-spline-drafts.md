# パス・スプラインの下書き保存

更新日: 2026-11-17（日本時間）。パスの入力点と直線／ベジェモード、スプラインの通過点と接線倍率をSVG内の作図入力プリセットに保存できます。スプラインの従来の数値設定だけの記録も維持します。対応するツールは計25種類です。

## 操作と保存範囲

パスでは入力点を置き、ツール固有プロパティの「描画モード」を選びます。「実装・アルゴリズム」内の「作図入力のプリセット（SVGに保存）」で「現在の入力を図面に記録」を押します。クリック済みの点列と現在のモードを記録し、カーソルへの仮の次辺は含めません。点の順序と重複、点数不足の下書きも保持します。

スプラインでは同じ欄で保存対象を選べます。「現在の数値設定だけを図面に記録」は従来どおり接線倍率だけを保存します。「現在の入力点と数値設定を下書きとして記録」はクリック済みの通過点と接線倍率を一緒に保存します。1ツールに記録するのは1組で、どちらの操作も既存のスプライン記録を明示的に置き換えます。カーソルへの仮の通過点は保存しません。

「SVG保存」で図形と記録を持ち出せます。未確定の曲線・仮の次辺・入力点の補助表示は完成図形として出力しません。記録後の入力変更は自動では保存されません。図面を開くだけでは入力を復元せず、計算や作図もしません。

## 復元と継続入力

記録したツールを選択し、復元ボタンを押します。パスの記録とスプラインの下書き記録は、現在の下書きを保存した点列・設定で置き換えます。スプラインの数値だけの記録は、現在の入力点の配列・選択対象を維持して接線倍率だけを戻します。記録済みの点数・モード・数値と復元方法をパネルで区別して表示します。

復元した下書きへクリックで点を追加し、Backspaceで最後の点を削除できます。パスのモード変更は点列を維持します。両ツールとも2点以上でEnterまたはダブルクリックにより確定できます。点数不足で確定操作をした場合は点を残して理由を表示します。Esc、最後の点の削除、空の下書きの復元で下書きを取り消します。復元・修正・取消・確定で、図面に記録した入力を自動更新しません。

復元したスプラインの下書きは、別ツールへの切替や別図面の読込で確定せず取り消します。従来の新規スプラインでツール切替時に確定する動作は維持します。数値だけの記録を復元した場合は、その時点の下書きが通常入力か復元した入力かも維持します。パスは従来どおりツール切替で下書きを取り消します。計算に失敗した通常入力もツール切替後に残しません。

計算・描画に失敗した場合は理由を表示し、点列と設定を残します。入力の修正、方式の切替、再度の復元から再試行できます。古いプレビューや一部の図形を完成図形として確定せず、失敗によって履歴を増やしません。記録の更新・削除と図形の確定は、それぞれ1段階のUndo/Redoに対応します。下書きの復元・入力修正そのものは図面のUndo対象ではありません。

## 保存形式と旧形式

既存の `metadata[data-vector-document="1"]` のJSONにある `constructionInputs.entries` を使います。全体の版は1です。パスは個別版1、スプラインの下書きは個別版2とし、接線倍率のみの個別版1を変更しません。

```json
{
  "constructionInputs": {
    "version": 1,
    "entries": {
      "path": {"version": 1, "input": {"points": [{"x": 80, "y": 100}, {"x": 180, "y": 90}], "pathMode": "bezier"}},
      "spline": {"version": 2, "input": {"points": [{"x": 80, "y": 100}, {"x": 180, "y": 90}], "tension": 2}}
    }
  }
}
```

スプラインの数値設定だけの記録は `{"version":1,"input":{"tension":2}}` のままです。版1に点列を加える形式は不正として拒否します。版2は点列と接線倍率の両方が必須です。

点列は0〜1000点で、各点は有限数のx・yだけを持ちます。パスの `pathMode` は `line` または `bezier`、スプラインの `tension` は0〜4の有限数です。余分なフィールド、欠落、数値文字列、非有限数、過剰点数を拒否します。全体の2000000文字・256記録・12階層・50000検査要素の上限を継承します。

既知形式の不正なSVGは図面置換前に全体を拒否し、現在の図形・入力・選択・履歴を維持します。未知ツールや将来の個別版はデータとして保持し、対応する復元処理がない場合は復元ボタンを無効にします。パスの版2以降、スプラインの版3以降は現時点で未対応です。旧エディタはスプライン版2を将来版として保存し、復元は行いません。記録がない旧SVGを開くと直前の図面の記録を引き継ぎません。ブラウザー保存が拒否されてもSVG内の記録を利用できます。

## 実装・計算・描画と換装

[constructionInputPresets.js](../src/adapters/constructionInputPresets.js) の `parseCurveDraft(name, entry)` がパス版1・スプライン版2を検査し、独立したコピーを返します。既存の数値設定検査は変更しません。コントローラーは [PathTool.js](../src/tools/PathTool.js) と [SplineTool.js](../src/tools/SplineTool.js) です。必ず全入力とアクティブ状態を検査した後に、現在の下書きを置き換えます。

複数版を復元するコントローラーは `inputPresetVersions` で対応版を列挙します。スプラインは `[1,2]` です。未指定なら従来の単一 `inputPresetVersion` を使います。`supportsConstructionInput(controller, entry)` が復元可能な版を照合し、`constructionInputMode(controller, entry)` は任意の `inputPresetModeForEntry(entry)` から復元の意味を取得します。スプラインは版1を `parameters`、版2を `draft` として扱います。

`record(name, controller)` は従来の `exportInputPreset()` を呼びます。`record(name, controller, {draft:true})` は任意の `exportInputDraftPreset()` を呼びます。スプラインは前者が数値版1、後者が下書き版2です。外部コントローラーも、宣言した対応版を復元処理で検査し、復元だけで既存図形や方式選択を変更しない契約を守る必要があります。

計算は既存の [drawing.js](../src/model/drawing.js) と計算レジストリー、描画はホストの描画レジストリーと [svgGeometry.js](../src/adapters/svgGeometry.js) を使用します。パスの直線モードはSVG M/L、ベジェモードは始点に続く3点ごとを三次ベジェの制御点2個・終点としてSVG Cへ変換し、末尾の余った点は線分にします。スプラインの標準計算は既存の接線倍率付きCardinal／Catmull–Rom系で、uniform・centripetal・chordal等の選択も維持します。接線倍率を使わない代替実装では、その実装の接線規約を維持します。

下書き復元は現在選択している計算・描画方式を使います。分割数・許容差・色・レイヤーは入力記録に含めず、復元先の現在設定を使います。計算実装ID・描画実装IDは確定図形へ従来どおり記録し、プロパティで参照できます。名前の付いた方式・論文・参照履歴は [algorithms.md](algorithms.md)、換装と統合条件は [implementation-options.md](implementation-options.md) にあります。今回、新しい幾何アルゴリズム・論文・ライブラリは導入していません。

## 検証と残る範囲

[curveDrafts.test.mjs](../tests/curveDrafts.test.mjs) は2形式とスプライン旧版、境界値、重複・空入力、形式不正の非適用、版交渉、記録の分離、実コントローラーの検査順・点の維持／置換、点数制限を検証します。[editor.html](../tests/editor.html) はクリック入力・記録・別画面へのSVG移行・実作図、旧版と下書き版の復元の違い、継続入力・修正・取消、更新・削除・確定のUndo/Redo、不正SVG・将来版、計算／描画失敗からの復旧、ツール切替・保存拒否・実際のSVGダウンロードを検証します。

[矩形・円・円弧・多角形の未確定入力](shape-drafts.md)の保存は実装済みです。[寸法種別・文字入力の下書き保存](annotation-drafts.md)は実装済みです。図形参照、ドラッグ途中のボタン状態・ポインター取得、名前付き複数入力、自動更新、下書き編集のUndo/Redoは未導入です。完成済みパス・スプラインからクリック時の点列を逆算する機能も今回の対象には含めません。

[寸法・文字の下書き保存](annotation-drafts.md)も実装済みです。文字はプロパティで編集・明示確定でき、寸法描画は共通の換装経路に対応します。
