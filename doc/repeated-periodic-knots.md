# 重複する周期ノット

2026-11-17に、B-spline・NURBSの周期ノットを重複度が次数以下の範囲で拡張しました。同じノットを重ねると、その接続点の滑らかさを変えられます。次数回重ねると位置の連続性を保った角を作れます。新規作図、元モデル再編集、制御点ドラッグ、SVG、作図入力の記録・取り込みで同じ計算を使います。

## 入力と継ぎ目

「周期曲線」をONにし、「周期ノット（制御点数+1個、空欄で一様）」に有限な数を減少しない順に入力します。重複を含めて元の制御点数+1個が必要です。空欄は従来の一様構成です。値を重ねる操作だけで曲線形状を保持する機能ではありません。

次数3、制御点4個なら `0, 1, 1, 2, 3` は内部の1が2重です。`0.1, 0.1, 1, 2, 2` は先頭と末尾がそれぞれ2個ずつですが、周期の継ぎ目は3重になります。先頭と末尾の区切りは同じ周期位置を表すため、継ぎ目の重複度は「先頭の同値数＋末尾の同値数−1」で数えます。

`0, 0, 0, 2, 2` は継ぎ目が4重になるので、次数3では拒否します。内部も含めて次数を超える重複、全て同じ値の周期、減少する列、非有限値、数値精度上延長できない列を拒否します。再編集時に次数だけを下げた場合も、新しい次数で検証します。失敗時は元図形を変更せず、入力を修正できます。

APIは従来の `periodicKnots` を使います。

```json
{"points":[{"x":80,"y":100},{"x":150,"y":220},{"x":240,"y":110},{"x":300,"y":190}],"degree":3,"periodic":true,"periodicKnots":[0.1,0.1,1,2,2]}
```

NURBSは元の制御点ごとの `weights` を追加できます。重複度はノットの個数で決まり、制御点・重みの値とは別です。

## 計算と描画

[splineCurves.js](../src/model/splineCurves.js)で、1周期の最後の端点コピーを除き、終端と同じ値のノットを始端へ対応付けて重複度を数えます。次数p、重複度mの接続は、分母が零でない範囲で少なくともp−m階まで連続です。今回の上限m≤pにより、周期内と継ぎ目の位置の連続性を保ちます。

[非一様周期ノット](nonuniform-periodic-knots.md)と同じ周期延長を使います。左側へ移した終端のコピーは元の始端の値、右側へ移した始端のコピーは元の終端の値をそのまま使用します。小数の減算・加算の丸めによって、意図した重複が分離することを防ぎます。入力の零幅区間は延長後も零幅、正の幅の区間は延長後も正であることを照合します。異なるノットが数値精度で同じ値に潰れる場合は拒否します。

零幅の区間は描画せず、非零幅の区間を既存の極形式de Boorでベジェ化して評価します。重複ノットに対応する区間端点を保持し、角を平滑化しません。全区間を描画できる1本の枝だけを閉じます。NURBSの零・負の重みでは既存の分母検査を行い、極の付近を省略して別サブパスとし、部分描画を閉じたり塗りで接続したりしません。

通常の非周期ノットは従来どおり次数+1重による不連続も扱います。周期曲線では次数+1重の不連続は今回の対象外です。

## 保存と互換性

元モデルの保存版1、作図下書きの個別版1・2は変更しません。ノット入力は既に文字列として保持していたため、新しい形式は必要ありません。旧エディタでも図形はSVGとして表示できます。重複周期ノットに非対応の旧計算実装では、この元モデルからの再編集や下書きの確定はできません。

SVGから元モデルを再編集するときは、中央の1周期から再構築して延長部分も照合します。継ぎ目の破損や循環制御点の不一致を拒否します。入力の単一記録・名前付き記録・作図セットと別SVGからの選択的取り込みでも、同じ文字列と設定を保持します。

## 実装時の参照と検証

2026-11-17に[Open CASCADE Technologyの公式 `Geom_BSplineCurve` 資料](https://www.occt3d.com/dev/doc/refman/html/class_geom___b_spline_curve.html)で、周期ノットの反復、周期曲線の重複度上限、重複度と連続性の関係を照合しました。独立したJavaScript実装で、Open CASCADEのコード転用・組み込みはありません。1周期の配列形式、循環重複度の数え方、端点値の固定と数値検証はこのリポジトリの設計です。極形式de Boorと分母検査の参照履歴は[spline-branches.md](spline-branches.md)にあります。

[repeatedPeriodic.test.mjs](../tests/repeatedPeriodic.test.mjs)では、次数2〜12の各重複度と両端への分配、位置・必要な接線の連続性、NURBSによる真円、角の保持、重複度超過、小数の継ぎ目、入力の非破壊性、SVG元モデルの往復・破損検出、負重みの枝分離を検証します。[editor.html](../tests/editor.html)では、両ツールの作図、SVG読込、再編集・次数変更の拒否・修正・ドラッグ・Undo/Redo、部分描画、3種類の入力記録と作図セットの取り込みを操作します。

形状を保つノット挿入・削除、次数昇降、継ぎ目位置の変更専用操作、位置が不連続になる周期構成、厳密算術は未実装です。
