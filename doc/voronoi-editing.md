# Voronoi図の元入力保存・再編集

更新日: 2026-11-16（日本時間）。`voronoiCells` の母点と矩形の切り取り範囲を保存し、領域全体を再計算できます。

## 操作

Voronoi分割ツールで1〜1000点をクリックし、Enterで確定します。初回の切り取り範囲は図面のviewBox、viewBoxがない場合は図面の幅・高さです。母点の入力順と重複、切り取り矩形、計算したセルをSVGに保存します。1点なら矩形全体を1セルとし、2点や一直線上の母点も扱います。

選択ツールでいずれかのセルをクリックするとVoronoi図全体を選択します。ツールプロパティの「元の点群から再計算」から「点群を再編集」を押します。座標欄で母点を追加・削除し、番号付きハンドルで移動できます。切り取り範囲のX・Y・幅・高さも数値欄で変更できます。矩形は保存したローカル座標を使用し、図面サイズやviewBoxを後から変えても自動では変更しません。

プレビューは青い破線で全セルを表示し、適用時に全体を一括更新します。グループ本体、外観・変形・レイヤー・親内順序・選択、直下のtitle・desc・metadataを保持します。適用1回をUndoの1段階とし、RedoとSVG保存・読込にも対応します。補助表示は保存しません。

母点の重複は初出の点を代表とし、元の入力には重複も残します。矩形との交差が空のセルも結果に記録し、描画する面だけを省きます。その母点を移動したり矩形を広げたりすれば、保存済みの母点から領域を再計算できます。セルと入力番号の対応は結果のindexとsiteに記録します。

回転・反転・せん断・縦横別拡縮、ズームを反映した母点ドラッグに対応します。ハンドルは画面上で一定の大きさです。計算はローカル座標のユークリッド距離で行うため、非一様な拡縮やせん断をした画面上の距離で再計算する機能ではありません。グリッド・Shift・直交モードは図面座標で作用します。ドラッグ中のEsc・ポインター取消・取得喪失・フォーカス喪失はその移動だけを戻し、それ以外の取消・ツール変更・選択変更は再編集を終了します。

## 計算・描画・参照履歴

計算は既存の [regions.js](../src/model/regions.js) の `voronoiCells` を使用します。各母点について、他の全母点との垂直二等分線の近い側を半平面とし、矩形を [clipCell.js](../src/model/clipCell.js) で順次切り取ります。重複座標を初出順にまとめ、各母点について空のセルも返します。

関連する名前付き方式はVoronoi分割とSutherland–Hodgman型の逐次クリッピングです。文献と既存実装の照合履歴は [algorithms.md](algorithms.md)、[R6](algorithms.md#r6) を継承します。今回の保存・編集機能に新しい計算法・論文・外部ライブラリを導入していません。Fortuneの走査線、Delaunayの双対からの構築、厳密な交点構成は未採用です。標準クリッピングはbinary64の補間を使い、セル径に基づく面積しきい値以下の細い領域を省略します。近い退化配置や極端な座標の精度を保証するものではありません。

標準描画は非空セルをSVG g直下のpolygonへ変換し、画素化はブラウザーが行います。曲線分割数は使用しません。プロパティには実際の計算・描画実装、アルゴリズム、実装元、委譲先、母点数・セル数・表示セル数・矩形、最初の生成方式を表示します。計算の組込み実装はdefaultの1方式で、登録された外部実装を再編集欄から選択できます。

## 保存形式と換装契約

`data-vector-pointset` version 1に `method: voronoiCells`、`input: {sites, box}`、`result: [{index, site, points}]`、`geometry: {tag: g, faces: [...]}` を保存します。boxは `{x, y, width, height}`、indexは元の母点配列に対する0始まり番号です。空セルのpointsは空配列です。元入力・計算結果は描画実装のオプションへ混ぜません。`data-vector-implementation.parameters` にpointCount・cellCount・visibleCellCount・boxを記録します。

計算は `registerImplementation('voronoiCells', {id, label, algorithm, run})` で換装します。入力は有限な1〜1000個のsitesと、有限な座標・正の幅と高さを持つboxです。右端と下端が非有限になる矩形や、丸めによって幅・高さが座標上で消える矩形は拒否します。作図・再編集から渡す入力は点・配列・矩形を含めて読み取り専用のコピーです。並べ替え等が必要な実装は内部でコピーしてください。

出力は異なる母点ごとに1セル、初出順で、重複の代表は最初の入力番号です。index・site・個数・順序を照合します。空セルも省かず返してください。非空セルは有限な3〜2000頂点、全セル合計は12000頂点までとし、全セルが空の場合は適用を拒否します。頂点の同一点・一直線の退化を既存のBigInt向き符号で確認し、矩形外の頂点を検出します。範囲判定では境界の丸めに64×Number.EPSILON×座標規模の許容差を設けます。最近点性、凸性、自己交差、セル同士の重複や矩形全体の被覆を独立に証明する検査ではありません。

描画は `registerRenderer` で `supports('voronoiCells')` を持つ実装を登録します。計算結果の非空セル順で、各セルをg直下のpolygonまたは閉じたpathにします。polygonは有限な3〜2000頂点が必要です。空セルは描画しません。面数不一致、単独polygon、入れ子のg、開いたpath、面自身の子要素は拒否します。外部描画の輪郭と計算結果の幾何学的な一致までは証明しません。

各面の全属性・順序・個数を保存時と照合し、個別の着色・変形・輪郭編集、追加・削除・並べ替えを検出した場合は再編集を拒否します。面ごとの編集を消す上書きや、新セルへの個別スタイル対応は行いません。グループ全体の外観変更は保持します。グループ・面のロック、非表示、元データ変更、未登録実装、計算失敗、非対応描画では元図形を一部だけ変更しません。

入力・結果の検査は [voronoiSource.js](../src/adapters/voronoiSource.js)、保存の接続は [pointSetSource.js](../src/adapters/pointSetSource.js)、面の照合と一括置換は [meshSource.js](../src/adapters/meshSource.js)、数値欄・矩形編集は [PointSetEditor.js](../src/ui/PointSetEditor.js)、母点ドラッグは [SplineControlHandles.js](../src/ui/SplineControlHandles.js) です。

## 残る範囲

重み付きVoronoi・power diagram、非ユークリッド距離、線分や曲線を母体とする分割、周期境界、非矩形や穴付き領域の切取り、矩形のドラッグハンドル、増分更新、セル個別ID・スタイルの継続対応、他図形との拘束、任意の外部SVGからの母点推定は未導入です。これらは母点の属性・距離定義・境界モデル・セル対応の契約を拡張して接続する必要があります。一般の多角形三角分割の元入力保存・再編集も未導入です。
