# 周期曲線の許容差付きノット削除

2026-11-17に、周期B-spline・同符号重みの周期NURBSへノット削除を接続しました。一様・非一様・重複周期ノットの内部値と継ぎ目を1個ずつ削除できます。継ぎ目の最後の1個では、周期を保って始端を次のノットへ移します。周期を再構成した候補について、削除直前の1周期全体に対する偏差上限を推定し、許容差内の場合だけ下書きを更新します。計算120機能・GUI31ツールは変わりません。

## 操作と対象

周期曲線を選んで再編集を開始し、「削除するノット値」「ノット削除の許容差」「ノット削除の実装」を指定します。「許容差内でノットを削除」で元制御点と1周期のノットを各1個減らし、重み・ハンドル・プレビューを更新します。元図形は適用まで保持し、複数回の削除や続く制御点編集を最後の適用で1回のUndo/Redoへまとめます。取消・不正入力・計算失敗・偏差超過では元図形を保持します。

次数1〜12、元制御点数1000以下で、削除後も元制御点数が次数より多いことが必要です。NURBSの重みは全て正、または全て負を対象にします。零・正負混在は未対応です。許容差の既定値は1e-7、範囲は0〜1000000で、図形のローカル座標における距離です。各操作の直前の曲線と比較し、編集開始時からの累積偏差を制限する設定ではありません。

先頭と末尾の値は同じ継ぎ目として扱います。先頭側に重複があればその1個を、先頭側が単純なら末尾側の重複を1個減らします。重複が残る場合は先頭・末尾の値と周期を変えません。継ぎ目の最後の1個を消す場合は、始端を次のノットへ移し、終端を新しい始端＋元の周期にします。削除後の区間を成功メッセージと選択図形のプロパティに表示します。

たとえば次数3、元制御点7個、周期ノット `0.1, 0.1, 0.3, 0.7, 1, 1.4, 1.7, 2` の曲線では、削除候補の偏差が許容差内なら `0.7` と `2` の順で削除して、元制御点5個、周期ノット `0.1, 0.3, 1, 1.4, 1.7, 2` にできます。前後に同じ値があるだけでは削除可能とは限りません。元の曲線が、より少ない制御点で許容差内に表せる必要があります。

## 継ぎ目の最後のノットと区間移動

単純な継ぎ目を削除すると、その位置は新しいノット列からなくなります。元の周期ノットを `U[0] … U[N]`、周期を `T = U[N] − U[0]` とすると、新しい列は `U[1] … U[N−1], U[1]+T`、新しい区間は `[U[1], U[1]+T]` です。次のノットに重複があれば、その重複を全て保持して新しい継ぎ目にします。入力の先頭値・末尾値のどちらを指定しても同じ候補を計算します。

たとえば、次数3、元制御点6個、周期ノット `0.5, 1, 3, 4, 6, 8, 8.5` の曲線から `0.5` または `8.5` を削除すると、許容差内なら元制御点5個、周期ノット `1, 3, 4, 6, 8, 9` になります。周期8を保持し、パラメータ区間は `0.5〜8.5 → 1〜9` に変わります。このノット列だけで削除可能と決まるわけではなく、制御点と重みも検証します。

曲線の座標を平行移動する操作ではありません。同じ周期曲線を別の始端から1周する表現へ変更します。重なる区間では同じパラメータ値を比較し、元区間を超えた部分は元の曲線の周期コピーと比較します。再描画されるSVGの開始位置も変わるため、破線の開始位相やパス開始点に依存する表示は変わる場合があります。任意位置への継ぎ目移動だけを行う専用操作は未導入です。

## 計算と検証

周期処理は [periodicSplineRemoval.js](../src/adapters/periodicSplineRemoval.js)、操作の入出力検証は [splineRemoval.js](../src/adapters/splineRemoval.js)です。単一ノットの削除には既存の [splineKnotRemoval.js](../src/model/splineKnotRemoval.js) のBoehm挿入の両側逆算を使います。周期展開は挿入と共有する [periodicSplineExpansion.js](../src/model/periodicSplineExpansion.js)、共通基底上の偏差推定は [splineDeviation.js](../src/model/splineDeviation.js)へ分離しました。

元制御点数N、次数p、周期T、始端a、終端bの曲線を前後にも展開し、3N+p個の制御点を持つ非周期評価用配列を作ります。内部値tではt−T、t、t+Tを、継ぎ目ではa、bを順に削除します。各削除の出力は次数・ノット列・制御点数・有限値・同符号重み・偏差を検査し、換装実装が申告する偏差値は使いません。

新しい1周期のノット列から標準モデルと同じ評価用ノット列を作り、一時結果の対応部分と一致することを確認して中央のN−1個の制御点と重みを抽出します。その元制御点から標準モデルで周期コピーを作り直します。途中配列の末尾をそのまま接続するのではなく、実際に保存・描画する周期モデルを検証対象にします。

継ぎ目を移す場合は、削除前のモデルの制御点・重みを1個分循環させ、ノット列を次の始端から並べた比較用モデルも作ります。周期がbinary64の値として元と一致し、前後の評価用ノット列が元の無限周期列の対応部分と全て一致する場合だけ続行します。この検査は換装実装を呼ぶ前に行います。丸めによって周期や支持ノットが変わる入力は、許容差を大きくしても通しません。たとえば `0.1, 0.3, 1, 1.4, 1.7, 2` の最後の継ぎ目では、`0.3 + (2 − 0.1)` で新終端を作った後の周期が元の値と一致しないため拒否します。

検証では、候補の周期モデルへ削除値を標準のBoehm挿入で戻します。継ぎ目を移した場合は、元の終端bを新しい区間内の内部値として戻し、移動済みの比較用モデルと同じ基底へ揃えます。NURBSは重みの共通符号・最大絶対値を使って正規化してから挿入し、元の重みスケールへ戻します。この検証用の挿入は固定で、作図用や再編集用に選択した別の挿入実装を呼びません。

継ぎ目の重複を先頭側・末尾側のどちらに書くかにより、同じ曲線でも配列の開始位置が異なることがあります。照合時には末尾側の重複を先頭へ移し、その個数だけ制御点・重みを逆方向へ循環して、両モデルを同じ表現へ揃えます。この重複の整列自体は内部の検証専用です。最後の継ぎ目を削除する区間移動とは区別し、比較する両モデルに同じ区間を使います。

揃えたモデルの評価用ノット列・次数・個数が一致することを確認し、同じB-spline基底の制御点から偏差上限を推定します。多項式曲線は対応制御点の最大距離、同符号重みのNURBSは共通正規化後の同次座標差・重み差・候補の制御点半径・元重みの最小値を使います。数式と成立条件は [spline-knot-removal.md](spline-knot-removal.md#計算と描画) にあります。

各一時削除が許容差内でも、周期を再構成した最終結果の偏差が許容差を超えれば拒否します。2回目・3回目の換装呼出しや最後の再挿入照合で失敗しても、元下書き・元図形・既存プレビューを更新しません。数値はbinary64で計算する推定値で、丸めを包含した区間演算による保証ではありません。周期展開でノット間隔が潰れる場合、オーバーフロー、重みの正規化で必要な値を表せない場合も拒否します。

描画は既存の極形式de Boorによる区間ベジェ化、分母検査、SVG折れ線化です。ノット変更で標本位置が変わるため、元の数学的な形状と一致する場合もSVGのパス文字列や折れ線長は完全一致しないことがあります。削除の偏差推定と描画の近似は別です。

## 換装と保存

`removeEditableSplineKnot(method,input,t,tolerance,remove)` は周期入力も受け付けます。`method` は標準の `bSplineCurve` または `nurbsCurve`、入力は元の1周期の点列と `periodic:true`、任意の `periodicKnots` と重みです。結果には削除後の元点列・周期ノットと `removal` を返します。外部ホストや標準以外の曲線定義への自動適用は行いません。

換装する `removeSplineKnot` 自体は非周期の単一削除の契約を維持します。各呼出しで通常の点列・次数・評価用ノット列・任意の重み・削除値・許容差を受け取り、制御点と指定ノットを1個減らした結果を返してください。内部値では3回、継ぎ目では2回呼び出します。一時制御点は最大3012個です。低水準の `removeSplineKnot` と非周期評価用の検証関数はこの上限を受け付けるようにしました。通常の作図・再編集の元制御点上限1000個は変更していません。

選択図形のプロパティには単一削除の実装名・アルゴリズム、周期処理名、削除値・周期値、許容差、最終の推定偏差上限、検証方式を表示します。SVGの `data-vector-implementation.refinement` にも保存します。`periodic` の中には周期処理名、ソース、正規化した値 `t`、単一削除の呼出し回数 `copies` を記録します。区間を移した場合は `periodic.domainShift` に旧区間 `from: [a,b]`、新区間 `to: [U[1],U[1]+T]`、元の周期 `period` を追加します。`t` は元の区間で正規化した継ぎ目値aのままです。`copies` は削除処理の回数で、検証用の再挿入回数を含みません。SVG保存再読込と後の再編集でも保持します。保存形式のバージョン変更はありません。
