# 多角形三角分割の元入力保存・再編集

更新日: 2026-11-16（日本時間）。`triangulatePolygon` の境界頂点列を保存し、単純多角形の三角分割全体を再編集できます。

## 操作

多角形三角分割ツールで境界をたどる順に3〜1000点をクリックし、Enterで確定します。末尾から先頭へ閉じます。時計回り・反時計回り、凸・凹の単純多角形を扱います。点群の凸包を作る機能とは異なり、凹部を含む入力境界を使用します。

入力した順序、連続する重複点、先頭を末尾に繰り返した閉じ点、辺上の共線点を元データに残します。計算側では連続重複と閉じ点を整理し、耳切り中に共線点を除去する場合がありますが、その計算用整理で元入力を減らしません。境界内の同一点への再訪、交差、辺の重なりを含む非単純な入力や面積0の入力は適用できません。

選択ツールでいずれかの三角形をクリックすると、分割全体を選択します。ツールプロパティの「元の点群から再計算」から「点群を再編集」を押します。座標欄の行を追加・削除・並べ替えたり、番号付きハンドルをドラッグしたりして頂点列を変更します。灰色の補助線は入力順の閉じた境界、青い破線は再計算した三角形群です。

プレビューでは元図形と履歴を変更せず、「適用」で全ての面と元データを一括更新します。グループ本体、外観・変形・レイヤー・親内順序・選択、直下のtitle・desc・metadataを保持します。適用1回をUndoの1段階にし、RedoとSVG保存・読込にも対応します。補助表示は保存しません。面の数や接続は変わるため、個々の三角形のDOM同一性を引き継ぐ仕組みはありません。

回転・反転・せん断・縦横別拡縮とズームを反映し、ハンドルは画面上で一定サイズです。座標と計算は図形のローカル座標、グリッド・Shift・直交モードは図面座標を使います。3点以上の有限な入力なら、自己交差や面積0で分割できなくてもハンドルを残して修正できます。重複点・閉じ点も別々の入力行として保持するため、同じ位置のハンドルは重なります。必要に応じて座標欄で編集し、同じ座標の行を自動で連動させることはありません。

ドラッグ中のEsc・ポインター取消・取得喪失・フォーカス喪失はその移動だけを戻します。それ以外の取消・選択変更・ツール変更は再編集全体を終了します。非可逆変換では補助表示を除去し、変換を戻すと操作を復帰できます。

## 計算・描画・参照履歴

計算は既存の [polygons.js](../src/model/polygons.js) のear clipping（耳切り法）です。入力境界の単純性と向きを調べ、凸の角が作る三角形の内部・境界に他の頂点がない耳を順に切り取ります。共線の角は三角形を追加せず頂点を除く場合があります。候補ごとに残る頂点を走査する素朴な実装です。

関連文献と既存実装との照合履歴は [algorithms.md](algorithms.md)、[耳切り法 R7](algorithms.md#r7) にあります。今回の保存・編集UIに新しい三角分割法・論文・外部ライブラリを導入していません。R7に記載された最適化や計算量をそのまま現行実装の保証とは扱いません。境界の交差判定・面積・耳の判定は既存のbinary64計算を使うため、近い退化配置や極端な座標での完全な位相保証はありません。

標準描画は三角形の座標配列をSVG g直下のpolygonへ変換し、画素化はブラウザーが担当します。曲線分割数は使いません。標準計算の組込み方式はdefaultの1種類です。登録した外部の計算・描画実装を再編集欄から選択でき、実際の実装ID、アルゴリズム、実装元、委譲先、入力点数・三角形数、最初の生成方式をプロパティに表示します。

## 保存形式と換装契約

`data-vector-pointset` version 1に `method: triangulatePolygon`、`input: {points}`、`result: [[{x,y},{x,y},{x,y}], ...]`、`geometry: {tag: g, faces: [...]}` を保存します。結果は三角形の座標配列です。Delaunayの入力インデックス配列とは異なります。`data-vector-implementation.parameters` にpointCountとtriangleCountを記録します。元入力・結果を描画オプションへ混ぜず、再編集時の方式選択も次の作図用設定へ保存しません。

計算は `registerImplementation('triangulatePolygon', {id, label, algorithm, run})` で換装します。入力は有限な3〜1000頂点の `{points}` で、境界順を保持します。作図・再編集から渡す頂点と配列は読み取り専用のコピーです。内部で並べ替え・削除する実装は別の配列を作成してください。出力は1〜2000個の三角形で、各三角形は元入力と同じ座標を持つ有限な3頂点です。追加頂点を生成する出力は現行の再編集契約では拒否します。

元境界の有限で非零の面積と既存の単純性判定、頂点の入力への所属、同じ頂点集合の三角形の重複、零面積を検査します。三角形の零面積検査には既存のBigInt向き符号を使用します。外部実装の三角形が元境界を完全に被覆すること、凹部を横切らないこと、面同士の内部が重ならないことまでを独立に証明する検査ではありません。

描画は `registerRenderer` で `supports('triangulatePolygon')` を指定し、計算結果と同数のpolygonまたは閉じたpathをg直下に並べます。polygonには有限な3頂点が必要です。単独polygon、入れ子のg、面数不一致、開いたpath、面自身の子要素は拒否します。外部描画と計算三角形の幾何学的な一致までは独立に証明しません。

各面の全属性・順序・個数を保存時と照合します。個別の輪郭編集・着色・変形、追加・削除・並べ替えがある場合は再編集を拒否し、その変更を消す上書きはしません。グループ全体の外観変更は保持します。グループ・面のロックや非表示、編集中の元データ変更、未登録実装、計算失敗、非対応描画では一部だけの更新を防ぎます。入力を持たない旧SVGの三角形群から境界を推定する機能はありません。

入力と三角形の照合は [polygonTriangulationSource.js](../src/adapters/polygonTriangulationSource.js)、保存の接続は [pointSetSource.js](../src/adapters/pointSetSource.js)、面の照合・一括置換は [meshSource.js](../src/adapters/meshSource.js)、再編集は [PointSetEditor.js](../src/ui/PointSetEditor.js)、ドラッグと閉じた補助線は [SplineControlHandles.js](../src/ui/SplineControlHandles.js) です。

## 残る範囲

穴付き・複数境界・自己交差多角形の入力モデル、制約辺と穴を持つ三角分割の編集、Steiner点を追加する品質改善、境界線分・曲線の細分化、増分更新、各面のID・スタイル対応、継続的な他図形との拘束、任意の外部SVGからの境界復元は未導入です。

既存の制約付きDelaunay計算や [implementation-options.mdの外部方式](implementation-options.md) をこのUIへ接続する場合、外周と穴の複数リング、制約辺、生成頂点と元頂点の対応、品質条件・停止条件を保存するモデルが必要です。単純な頂点列と元頂点のみの三角形出力へそのまま差し替える対象にはしていません。
