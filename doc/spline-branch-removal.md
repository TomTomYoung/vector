# 極を含むNURBSの枝でノットを1個削除する

NURBSの分母が零になると、描かれる曲線が複数の枝に分かれることがあります。極から離れた場所の制御点を減らすには、選択したNURBSの「曲線を再編集」で「削除するノット値」と「ノット削除の許容差」を入力し、「指定ノットがある枝だけを編集」にチェックして「許容差内でノットを削除」を押します。対象の枝は指定したノット値から決まります。下書きでパラメータの検査範囲と推定偏差上限を確認し、「適用」で確定します。「取消」で元の図形に戻ります。

例えば、ノット値7.5の削除がパラメータ6〜9の範囲に影響するとき、その範囲の分母と偏差を調べ、外側の元データは区間ごとに照合します。別の場所に極があっても削除できます。6〜9の中で分母が零に近づき、区間全体の上限を確認できないときは下書きを保ちます。許容差の単位は図形のローカル座標です。

## 比較する区間

次数を $p$ とすると、正の幅を持つ元の区間 $[U_i,U_{i+1}]$ の計算は、制御点番号 $i-p$ から $i$ と、ノット番号 $i-p+1$ から $i+p$ に依存します。このノット列に削除対象の値が現れる区間をすべて検査します。連続性が完全に切れたノット自体を指定したときは、編集する枝を一つに決められないため拒否します。

各影響区間で元の曲線と削除候補をそれぞれの基底から同じパラメータ区間の同次ベジェ係数に変換します。正負混在の重みでも、再分割して両分母の絶対値の下限を求め、全ての小区間で偏差上限を検査します。分母の除外幅は各モデルの最大絶対重みの $10^{-12}$、深さは18、合計32768ノードまでです。許容差や計算上限を超えた候補は受け付けません。描画のサンプル数には依存しません。偏差はbinary64で求めた推定上限です。[分母と偏差の式](signed-knot-removal.md)

影響外の各区間では、実際に使うノット・制御点の元の座標・元の重みを完全一致で照合します。極での除算を行わず、既存の極の位置とその両側の曲線を保てます。換装実装が偏差0を返していても、影響外の点や重みを一つでも変えた候補は拒否します。既存の極を消したり、分母と分子の共通因子を相殺したりする操作は含みません。

周期曲線では同じノットの各コピーを削除し、抽出した最終曲線を改めて1周期全体で照合します。対象区間が継ぎ目をまたぐ場合は範囲を2つ表示します。最後の継ぎ目を削除して開始位置が移る場合は、移動したパラメータ区間も記録します。

## 演算室・保存・対象範囲

演算室では既存の `removeSplineKnot` のNURBS入力に `"scope": "branch"` を指定します。標準では全区間の分母を検証し、`scope` を省略した既存の呼び出しは同じ結果になります。演算室の単一削除は非周期の入力を扱い、編集画面では周期曲線にも対応します。

SVGの方式記録には `refinement.branch` として検査範囲 `ranges`、検査区間数 `checkedSpans`、影響外で一致した区間数 `protectedSpans` を保存します。`denominator` の下限とノード数は影響区間の集計です。SVGを開き直すと、結果の曲線と検査範囲を確認できます。Undo・Redoで図形と方式記録が一緒に戻ります。

この指定はノット1個の削除に適用します。複数のノットには[枝を選ぶ一括簡約](spline-knot-simplification.md#極を含むnurbsの枝を選ぶ)を使えます。固定基準との比較は全区間を検査します。ノットが影響する範囲そのものに極がある場合や、極を含む曲線に対して固定基準を設定する場合は、今回の枝検査の対象外です。

実装は [枝の検証](../src/model/splineBranchRemoval.js)、[両側からの削除](../src/model/splineKnotRemoval.js)、[周期モデル](../src/adapters/periodicSplineRemoval.js) です。局所支持は [Shene, B-spline Basis Functions: Important Properties](https://pages.mtu.edu/~shene/COURSES/cs3621/NOTES/spline/bspline-property.html)、de Boor評価とノットの挿入・削除は [MIT Hyperbook §1.4.3](https://web.mit.edu/hyperbook/Patrikalakis-Maekawa-Cho/node18.html) を参照してください。
