# 演算室の入力・計算方式の保存と復元

更新日: 2026-11-16（日本時間）。[演算室](../geometry.html)の119演算について、演算ごとの入力JSONの下書き、計算実装のID、最後に選んだ演算を保存します。

## 操作

入力・演算・計算方式を変更すると、このブラウザーへ自動保存します。別の演算に切り替えても、それまでの入力と方式を記憶します。再読み込み後は最後に選んだ演算から再開し、画面のアルゴリズム・実装元も復元した方式に合わせます。

入力は文字列として保存するため、書きかけでJSONとして不正な内容や空欄も下書きに残します。復元しただけでは計算しません。「実行」を押した時点でJSONを解析し、選択した実装IDをWorkerへ渡します。出力JSON、完了・失敗状態、実行履歴は保存しません。

「入力例に戻す」は現在の演算の入力だけを例に戻し、その演算の計算方式と他の演算の下書きは保持します。下部の「入力・計算方式の保存と復元」には、現在の作業の保存、保存内容の復元、JSON書出し・読込、全演算の初期化と保存内容の削除があります。全演算の初期化では選択をsegmentContactへ戻し、全入力と方式を起動時の初期値へ戻します。

「作業JSONを書き出す」で `vector-workbench-session.json` を取得できます。全演算の下書きと方式を含むので、別のブラウザーへの移行にも使えます。「作業JSONを読み込む」は、ファイルに含まれる互換性のある演算だけを更新し、含まれない演算は現在の内容を維持します。読み込めた内容は、このブラウザーにも保存します。

計算中に入力・演算・方式を変更した場合、Workerを終了し、古い結果を表示しません。入力例へのリセット、保存内容・ファイルの正常な復元、全演算の初期化でも実行を止めます。終了したWorkerから遅れて届いた結果は無視します。ファイル読込中に別の編集をした場合や別のファイルを選んだ場合も、古い読込結果で後の作業を上書きしません。

## 互換性と保存失敗

未登録の演算や未登録の計算実装は、その項目を理由付きで読み飛ばします。既知の演算でも実装IDが不明なら、その演算の現在の入力と方式を両方保持し、別方式へ黙って切り替えません。ファイルの選択中の演算が不明なら、現在の選択を維持します。読み込めた他の項目は反映します。

JSON外側の破損、不正なversion、項目型・名前・サイズの不正では、ファイル全体を適用しません。破損したブラウザー保存データを読み込んだ場合も、画面の状態を維持し、その保存値を自動削除しません。復元操作だけでは計算関数を実行せず、関数や外部コードを読み込みません。

ブラウザー保存の拒否、容量不足、データの上限超過では、保存できない理由を表示します。画面内の切替・計算は続けられ、上限を満たす内容はJSONへ書き出せます。JSON読込後のブラウザー保存が失敗しても、読み込めた内容は画面内で使用できます。初期化時の保存削除が失敗した場合は、画面を初期値へ戻したうえで、次の再読み込みでは以前の内容が戻る可能性を表示します。

1演算のinputTextは200000文字まで、保存・書出しデータ全体は整形後のJSONで2000000文字まで、読込ファイルは8000000バイトまでです。文字数はJavaScript文字列のlengthです。上限を超える画面内の下書きも切り捨てず保持しますが、その間は保存・書出しできず、単一入力200000文字を超える実行も拒否します。保存済みの以前の値は、保存失敗によって置き換えません。

## 保存形式と配置先

保存形式はversion 1です。全演算を書き出しますが、読込では次のような一部の演算だけを持つファイルも使えます。

```json
{
  "version": 1,
  "activeTool": "spline",
  "entries": {
    "spline": {
      "implementation": "centripetal",
      "inputText": "{\n  \"points\": ["
    }
  }
}
```

activeToolとentriesの演算名、implementationは1〜100文字の英数字・ハイフン・アンダースコアです。予約名 `__proto__`・`prototype`・`constructor` を拒否します。entriesは256項目までで、各項目はimplementationとinputText、最上位はversion・activeTool・entriesだけを受け付けます。inputTextの中身は下書きの文字列として保持します。

既定のlocalStorageキーは `vector.geometry-workbench.v1` です。作図エディタの方式設定、SVG内の図形生成記録とは別に管理します。同じオリジンで演算室を複数配置する場合は、モジュールの読込前に `window.vectorWorkbenchOptions = {storageKey: '任意の保存先'}` を設定して分離できます。`window.vectorWorkbenchOptions = {storage: false}` ではブラウザー保存へのアクセスと自動復元を無効にし、画面内の記憶とJSON入出力を維持します。

同じ保存先を使う複数タブ間では自動マージや即時同期をせず、最後に保存したタブの内容を保持します。各タブの画面内の作業を勝手に置き換えません。別タブで保存した内容を使う場合は「保存内容を復元」を操作します。

## 実装・計算方式との関係

形式検査、演算別の下書き、互換性の判定、保存と復元は [workbenchSession.js](../src/adapters/workbenchSession.js) です。ストレージは注入した関数から必要時だけ取得するため、保存が使えない環境や保存無効の埋込みでも起動できます。

画面への復元、実方式の説明、Workerの終了と遅延応答の除外、ファイル読込の競合検出は [GeometryWorkbench.js](../src/ui/GeometryWorkbench.js) にあります。実際の演算は従来どおり [geometryWorker.js](../src/ui/geometryWorker.js) が `createToolset()` を通して選択IDの実装を呼び出します。この画面の描画は計算結果のJSON表示です。

今回、幾何計算や描画アルゴリズム、新しい論文・外部ライブラリは追加していません。使用する計算方式、実装元、文献との関係は [implementation-options.md](implementation-options.md) と [algorithms.md](algorithms.md) を継承します。作図エディタの保存は [implementation-preferences.md](implementation-preferences.md) を参照してください。
