# 非一様周期ノットのB-spline・NURBS

2026-11-17に、B-spline・NURBSへ非一様な単純ノットの周期曲線を追加しました。同日、[次数以下の重複周期ノット](repeated-periodic-knots.md)にも拡張しました。新規作図、SVG保存・読込、元モデルの再編集、制御点ドラッグ、入力プリセット・作図セット、別SVGからの記録取り込みで利用できます。計算119機能・GUI31ツールは変わりません。

## 操作と入力

B-splineまたはNURBSを選び、「周期曲線」をONにします。「周期ノット（制御点数+1個、空欄で一様）」へ、カンマまたは空白区切りで減少しない値を指定します。例えば制御点4個、次数3なら `2, 3, 5, 8, 12` が使えます。最初の制御点を末尾へ追加する必要はありません。空欄では従来どおり一様ノットを生成します。

通常の開いた曲線のノット欄と周期ノット欄は別に保持します。周期を切り替えても、隠れている欄を別の意味に読み替えません。点数を変更した場合は周期ノットの個数を合わせてください。点数は次数より多く最大1000、次数は1〜12です。

選択ツールで保存曲線を選び、「曲線を再編集」から周期ノットを変更できます。「ノットを自動生成」は現在のモードのノット欄を空にします。プレビュー、適用、取消、Undo/Redo、制御点ドラッグは従来の再編集契約を使います。入力エラー時は元図形を保持します。

演算室またはAPIでは次を入力します。

```json
{"points":[{"x":100,"y":100},{"x":250,"y":100},{"x":250,"y":250},{"x":100,"y":250}],"degree":3,"periodic":true,"periodicKnots":[2,3,5,8,12]}
```

NURBSには、元の制御点ごとの `weights` を追加できます。零・負の重みと分母零付近の省略は[既存の有理スプライン処理](spline-branches.md)に従います。`periodicKnots` は周期指定時のみ、`knots` は非周期時のみ指定できます。同時指定やモードとの不一致は拒否します。

## 計算と描画

元の制御点数をN、次数をp、入力する1周期のノットをU₀〜Uₙ、周期幅をT = Uₙ − U₀とします。全ノットは有限数で減少しない順です。継ぎ目を含む重複度は次数以下です。継ぎ目の数え方と小数端点の扱いは[重複周期ノット](repeated-periodic-knots.md)を参照してください。評価用のノットは、左に `U[N-p]−T` から `U[N-1]−T`、右に `U[1]+T` から `U[p]+T` を追加します。先頭p個の制御点・重みを末尾へ循環させ、評価範囲をU₀〜Uₙとします。

この構成で、ノット間隔と制御点が同じ周期で繰り返されます。単純ノットの継ぎ目は、分母が零にならない範囲で次数p−1まで連続です。描画は既存の極形式de Boorによる区間ベジェ化、同次座標での分母検査、de Casteljau分割、SVG折れ線出力を再利用します。全区間が描画できる1本の枝だけを閉じます。外部レンダラーの登録・選択の契約は維持します。

実装は [splineCurves.js](../src/model/splineCurves.js)です。入力と延長後のノット列を検証し、期間幅のオーバーフロー、延長時の非有限値、浮動小数点の丸めで異なるノットが同じ値になる入力も拒否します。既存の一様ノットの出力は変更しません。

## 保存と互換性

生成済み曲線は従来と同じ `data-vector-spline` の版1で、延長済みノット、循環済み制御点・重み、元の制御点数を保存します。[splineSource.js](../src/adapters/splineSource.js)は1周期を取り出して再構築し、保存済みの延長部分と完全一致することを確認します。再編集のたびに循環点が増えることはありません。従来の自動一様ノットは入力欄を空欄に戻します。一様でも、原点や期間幅が既定と異なる場合は明示値を保持します。

作図下書きは、B-spline・NURBSの個別入力版2に `periodicKnotsText` を追加します。この欄に文字列があるときだけ版2で保存し、空欄の従来入力は版1を維持します。周期OFF時の非表示の文字列や、未完成の数値文字列も版2に残します。版1の復元時は周期ノット欄を空にします。外側の文書・入力コレクションの版は変更しません。

従来の単一入力、名前付き入力、作図セット、選択的取り込みで同じ検証を使います。旧エディタは版2を未知の入力として保持し、対応していない復元を実行しません。生成済みの非一様周期曲線は旧エディタで表示できますが、旧再編集機能は対応しません。

## 実装時の参照履歴

2026-11-17に [Open CASCADE Technology公式 `Geom_BSplineCurve` 資料](https://www.occt3d.com/dev/doc/refman/html/class_geom___b_spline_curve.html)の周期ノット・制御点の反復関係と、重複度と連続性の関係を照合しました。周期延長の数式を参考にした独立したJavaScript実装であり、Open CASCADEのコードやデータ構造を移植・組み込みしたものではありません。

既存の一様周期構成は [C.-K. Shene, B-spline Curves: Closed Curves](https://pages.mtu.edu/~shene/COURSES/cs3621/NOTES/spline/B-spline/bspline-curve-closed.html)を参照していました。今回も制御点の循環の説明を確認しました。区間評価と分母検査の参照履歴は [spline-branches.md](spline-branches.md)です。今回の1周期入力形式、検証上限、下書き版2、SVGからの復元契約はこのリポジトリの設計です。

## 検証と残る制約

[nonuniformPeriodic.test.mjs](../tests/nonuniformPeriodic.test.mjs)で次数2〜12の継ぎ目の位置・接線、既存de Boor評価との一致、一様構成との互換、パラメータの平行移動・拡大に対する形状不変性、不正ノット、負重みの枝分離、保存モデルの往復と破損検出、入力版1・2と実コントローラーを検証します。[editor.html](../tests/editor.html)では作図、SVG読込、再編集、ドラッグ、Undo/Redo、記録3種、別SVGからの取り込み、エラー後の修正を操作します。

次数を超える重複周期ノット、継ぎ目の位置変更専用操作、ノット削除、次数昇降は未実装です。非周期曲線の[ノット挿入](spline-knot-insertion.md)と、周期曲線の[形状保持ノット挿入](periodic-knot-insertion.md)は再編集画面へ接続済みです。binary64による計算で、厳密な算術や曲線近似誤差の保証はありません。無限遠を含む射影曲線編集、可除特異点の相殺、厳密な分母根分離も従来どおり未実装です。
