# 寸法・文字の下書き保存と寸法描画の換装

更新日: 2026-11-17（日本時間）。長さ寸法・角度寸法の種別と入力点、文字列と配置位置をSVG内に記録・復元できます。作図入力プリセットは計25ツールに対応します。

## 記録と復元

ツールプロパティの「実装・アルゴリズム」内にある「作図入力のプリセット（SVGに保存）」で現在の入力を記録します。ツールごとに1組保存し、更新はそのツールの記録だけを置き換えます。「SVG保存」で完成図形と入力記録を持ち出せます。未確定の文字、寸法、補助線、入力点のハンドルは完成図形に含めません。

SVGを開くだけでは作図や計算を実行しません。ツールを選び「記録した入力を下書きへ復元」を押すと、記録済み入力で現在の下書きを置き換えます。既存図形、他ツールの記録、計算・描画の選択方式は維持します。現在の実装でプレビューし、明示的に確定して完成図形にします。

記録・更新・削除と図形の確定は、それぞれUndo/Redoの1段階です。未確定の入力編集と復元は図面履歴へ追加しません。確定・取消でも図面内の記録は残ります。ツール切替とSVG読込で現在の下書きを取り消します。

## 寸法

左パネルの「寸法タイプ」で長さ寸法・角度寸法を選びます。長さ寸法は始点と終点、角度寸法は第一辺の端点・頂点・第二辺の端点を順番にクリックします。通常の入力は必要な点数のクリックで確定します。途中で記録した下書きは残る点のクリックから続けられます。

長さ寸法は0〜2点、角度寸法は0〜3点を保存でき、空入力でも選んだ種別を残します。必要な点がそろった記録を復元した場合は自動確定せず、Enterで確定します。クリックすると最後の点を置き換えて確定します。Backspaceで末尾点を削除、Escで下書きを取り消します。種別を切り替えると現在の点列だけを消し、保存済みの記録は維持します。カーソルへ伸びる仮の補助線は保存しません。

点数不足、角度の頂点と辺の端点が同じ位置、計算失敗・描画失敗・標準描画が受け取る結果の不正では入力を保持して理由を表示します。Backspaceや最後の点の置換、方式の変更で修正してから再試行できます。長さ0の線形寸法は従来どおり0.0として扱います。

## 文字

通常のキャンバスクリックでは従来の入力ダイアログを使い、OKで直ちに確定します。キャンセルでは図形も履歴も追加しません。空白だけの入力は未確定の下書きとして保持します。

保存したい文字は、ツールプロパティの「文字の下書き」に入力します。または「下書きを開始」を押して、位置から先に指定できます。下書き中のキャンバスクリックは配置位置を指定・変更し、文字は自動確定しません。「下書きを確定」、または文字欄の外でEnterを押すと完成図形にします。文字欄のEnter・Backspace・Escは文字編集側に渡し、下書き全体の確定・取消に使いません。「下書きを取消」または文字欄の外でEscを押すと通常のダイアログ入力へ戻ります。

配置位置が未指定の文字、文字が空の配置位置、空白だけの文字も保存できます。確定には配置位置と空白以外の文字が必要です。文字列は最大20000 UTF-16コード単位で、前後の空白、改行、日本語、記号をそのまま保存します。マークアップとして解釈せず、SVGのtextContentへ渡します。標準描画の改行・空白の見え方はSVG textとブラウザーの通常の文字配置に従います。複数行レイアウト、自動折返し、字形アウトライン化を追加する機能ではありません。

## 保存形式と互換性

既存の `metadata[data-vector-document="1"]` 内にあるJSONの `constructionInputs.entries` に記録します。今回の2形式は個別版1です。

```json
{
  "constructionInputs": {
    "version": 1,
    "entries": {
      "dimension": {"version": 1, "input": {"dimensionType": "angular", "points": [{"x": 220, "y": 120}, {"x": 140, "y": 120}]}},
      "text": {"version": 1, "input": {"point": null, "content": "配置位置は後で指定"}}
    }
  }
}
```

寸法の種別は `linear` / `angular`、各点は有限数のx・yだけを持ちます。文字の `point` は同じ点形式またはnull、`content` は文字列です。過剰点数、数値文字列、非有限数、欠落・余分なフィールド、過長文字列を拒否します。入力全体の上限は[共通仕様](construction-input-presets.md)と同じです。

既知形式が不正なSVGは、図面・現在の下書き・選択・履歴を置き換える前に拒否します。不正な記録操作も以前の記録を残します。未知ツールや個別版2以降はデータとして保持し、未対応の復元を無効にします。旧SVGでは前の図面の記録を引き継ぎません。ブラウザー保存が拒否される環境でもSVGへ記録できます。

## 計算・描画と換装契約

形式検査と独立したコピーは [constructionInputPresets.js](../src/adapters/constructionInputPresets.js) の `parseAnnotationDraft(name, entry)`、入力操作は [DimensionTool.js](../src/tools/DimensionTool.js) と [TextTool.js](../src/tools/TextTool.js) の `inputPresetVersion = 1`、`exportInputPreset()`、`restoreInputPreset(entry)` で接続します。検証とアクティブ状態の確認を済ませてから現在の下書きを置き換えます。

寸法の計算は既存の [drawing.js](../src/model/drawing.js) の `dimension({points, mode})` です。長さは距離・中点・atan2、角度は2方向の偏角差を一周内に正規化します。計算結果のAPIは変更しません。標準の長さ寸法は `{start,end,angle,middle,length}`、角度寸法は `{vertex,startAngle,endAngle,turn}` を返します。

寸法描画は今回、コントローラー内でSVGを直接組み立てる処理から共通ホストへ移しました。描画レジストリーは `{kind:'dimension', mode:'linear'|'angular', result:計算結果}` を受け取ります。外部の `registerRenderer` はこの記述を受け、共通SVG描画が扱える図形へ変換できます。外部の `render` 差し替えはこの記述自体を扱います。外部renderを既に使用している場合は寸法への対応も必要です。

標準の [dimensionSvg.js](../src/adapters/dimensionSvg.js) は線・矢印・文字をSVG gにまとめ、角度寸法はSVG Aで描画します。従来の赤色、線幅1.5、矢印長8、文字サイズ14、角度円弧の半径30、文字の半径45を維持します。長さは小数1桁、角度は度へ換算して小数1桁で表示します。標準描画は必要な座標・計算値の有限性等を検査してから要素を更新します。

文字の計算は既存の `text({point,content})` で、空白以外の入力を `{kind:'text',point,content}` にします。描画は既存の [svgGeometry.js](../src/adapters/svgGeometry.js) と描画レジストリーです。標準のフォントはArial、サイズ16px、色は現在の塗り色または線色です。寸法・文字とも選択した実装でプレビューと確定を行い、実際の計算・描画の識別子とアルゴリズム説明を完成図形へ記録します。ツールプロパティと選択図形の方式表示で確認できます。

新たな論文・数値アルゴリズム・外部ライブラリは導入していません。既存方式の参照履歴は [algorithms.md](algorithms.md)、SVGの表現・文字仕様は同文書の [S1](algorithms.md#s1)、外部方式の統合条件は [implementation-options.md](implementation-options.md) を参照してください。
