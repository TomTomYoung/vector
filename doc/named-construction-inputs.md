# 名前付き作図入力の複数保存

更新日: 2026-11-17（日本時間）。作図入力プリセットに対応する25ツールで、1ツールの入力を複数の名前でSVG図面へ保存できます。従来の1件記録も引き続き使用できます。

## 操作

ツールプロパティの「実装・アルゴリズム」にある「名前付きの作図入力（SVGに複数保存）」を開きます。「記録名」に名前を入力し、「現在の入力を名前付き保存」を押すと、その時点の作図入力を新しい記録として追加します。保存後の入力編集は自動反映しません。

一覧から記録を選んでも現在の下書きは変わりません。「選択した入力を下書きへ復元」を押すと、そのツールの現在の下書きを記録した入力で置き換えます。図形は通常の確定操作で作成します。復元や記録の選択では、計算・描画方式、他ツールの入力記録、完成図形を変更しません。使用する計算・描画実装は同じプロパティ内の方式欄で確認できます。

「選択記録を現在の入力で更新」は、選択した1件の内容だけを現在の入力で置き換えます。記録名を変更して「選択記録を改名」を押すと、その記録の名前だけを変更します。「選択記録を別名で複製」は現在の下書きではなく、選択した保存済み入力を新しい記録としてコピーします。「選択記録を削除」はその1件だけを削除します。改名・複製・更新・削除は現在の下書きを変更しません。

同じツール内では記録名を重複させられません。別ツールで同じ名前を使うことはできます。名前の前後の空白は作成・改名時に取り除き、空の名前・改行・制御文字・100 UTF-16コード単位を超える名前は拒否します。日本語や記号は名前として使え、HTMLとして解釈しません。入力中の名前と選択記録はパネル再描画・ツール切替で維持します。

新規保存・更新・改名・複製・削除は、実際にデータが変わった場合、それぞれUndo/Redoの1段階になります。選択・復元・記録名の編集中状態は図面履歴に追加しません。未確定の作図入力そのもののUndo/Redoは従来どおり未対応です。

## 数値設定と下書きの区別

スプラインは「現在の数値設定を名前付き保存」と「現在の下書きを名前付き保存」を使い分けます。数値設定だけの個別版1と、通過点を含む個別版2を、異なる名前で同時に保持できます。数値設定だけの復元は現在の点列を維持し、下書きの復元は点列も置き換えます。更新も数値設定・下書きのどちらで置き換えるかを明示します。

フィレット・面取り・オフセットは従来と同じ数値設定だけの保存です。対象図形の参照や選択状態は保存しません。各ツールの保存内容と継続操作は [construction-input-presets.md](construction-input-presets.md)、[drawing-parameter-presets.md](drawing-parameter-presets.md)、[linear-bezier-drafts.md](linear-bezier-drafts.md)、[path-spline-drafts.md](path-spline-drafts.md)、[shape-drafts.md](shape-drafts.md)、[annotation-drafts.md](annotation-drafts.md) にあります。

## 従来の記録とSVG互換性

従来の「作図入力のプリセット（SVGに保存）」と、名前付き記録は別の保存領域です。従来の1件記録があれば、「従来の1件記録を名前付きで複製」で保存済み入力を複製できます。現在の下書きと元の記録は維持します。一方を更新・削除しても他方は変わりません。

「SVG保存」は両方の記録と完成図形を保存し、未確定のプレビューを除外します。SVGを開くだけでは入力の復元や計算を実行しません。旧SVGを開くと、名前付き記録は空になります。SVG読込とUndo/Redoでは一時的な一覧選択・入力中の記録名をリセットし、各ツールの先頭の記録を表示します。表示するだけで下書きは復元しません。

現行版は従来のSVGを読めます。名前付き記録に未対応の旧アプリは完成図形と従来の1件記録を読み込めますが、旧アプリで再保存すると追加の名前付き記録は失われます。名前付き記録を維持する保存には現行版を使用してください。ブラウザーの保存領域を使用できない場合でもSVG内へ記録できます。

## 保存形式と上限

`metadata[data-vector-document="1"]` 内のJSONへ、従来の `constructionInputs` を変更せず、兄弟項目 `namedConstructionInputs` を追加します。名前付き記録の集合の版は1です。

```json
{
  "namedConstructionInputs": {
    "version": 1,
    "entries": [
      {"id": "preset-example-a", "tool": "circle", "name": "小円", "entry": {"version": 1, "input": {"points": [{"x": 100, "y": 100}, {"x": 140, "y": 100}]}}},
      {"id": "preset-example-b", "tool": "circle", "name": "大円", "entry": {"version": 1, "input": {"points": [{"x": 100, "y": 100}, {"x": 200, "y": 100}]}}}
    ]
  }
}
```

`id` は作成時に生成し、改名・更新でも変えません。複製には新しいIDを割り当てます。IDは図面全体で一意、記録名はツール内で一意です。記録は配列の順序で表示します。`entry` は既存の各ツールの入力形式をそのまま使います。

集合全体は最大256記録、JSON化後2000000 UTF-16コード単位、深さ12、検査要素50000です。文字列として受け取る場合はJSON解析前にも長さを検査します。従来の記録とは別に上限を適用します。IDとツール名は英数字・ハイフン・アンダースコアの1〜100文字で、予約キーを拒否します。名前、形式の版、既知ツールの入力、余分なフィールド、重複ID・同名、数値の有限性等を検証します。

不正な名前付き記録を含むSVGは、完成図形・現在の下書き・選択・履歴・従来の記録を置き換える前に全体を拒否します。新規保存や更新に失敗しても、以前の全記録と選択IDを維持します。未知のツールや未知の個別入力版はデータとして保持します。対応しない復元は無効にし、利用できるツールの未知版記録は改名・複製・削除できます。未登録ツールの記録はSVG内に保持し、そのコントローラーを導入するまで復元しません。

## 実装と換装

[namedConstructionInputs.js](../src/adapters/namedConstructionInputs.js) の `parseNamedConstructionInputs` が集合の検査とコピー、`createNamedConstructionInputs` が管理を担当します。共通の入力構造の上限検査と既知ツールの検証は [constructionInputPresets.js](../src/adapters/constructionInputPresets.js) を使います。現在の下書き・保存値・返したコピーは独立しています。

管理APIは `snapshot()`、`list(tool)`、`entry(tool,id)`、`selectedId(tool)`、`choose(tool,id)`、`open(value)`、`record(tool,name,controller,{draft})`、`add(tool,name,entry)`、`update(tool,id,controller,{draft})`、`rename(tool,id,name)`、`duplicate(tool,id,name)`、`remove(tool,id)`、`restore(tool,id,controller)` です。`nameDraft` と `setNameDraft` は記録名の編集中状態だけを扱います。データ変更を行うAPIは成功時true・失敗時falseと理由を返し、`open` の不正形式は変更前に例外とします。履歴保存はUIが成功した変更操作に対して実行します。

外部コントローラーも既存の `exportInputPreset`・`restoreInputPreset`・`inputPresetVersion` または `inputPresetVersions` で接続できます。複数の保存モードは `exportInputDraftPreset` と `inputPresetModeForEntry` を使います。名前付き記録は計算・描画実装を直接呼び出さず、明示的な復元時にコントローラーへ保存入力のコピーを渡します。計算・描画・使用方式の記録は各ツールの既存経路を使います。

新たな幾何アルゴリズム、論文、外部ライブラリは導入していません。名前付き方式と参照履歴は [algorithms.md](algorithms.md)、計算・描画の換装と相性の異なる外部方式の統合条件は [implementation-options.md](implementation-options.md) を参照してください。
