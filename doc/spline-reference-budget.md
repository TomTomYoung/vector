# 再編集をまたいで基準曲線からの変化を制限する

B-spline または NURBS を選択して「曲線を再編集」を開きます。「基準曲線からの許容差」に図形のローカル座標で距離を入力し、「現在の下書きを基準にする」を押します。プレビューは基準からの推定偏差上限と残りの許容差を表示します。「適用」で基準曲線・許容差・編集結果を同じSVG要素へ保存します。SVGを開き直した後も同じ基準を使います。基準の設定・解除だけを行った場合も、図面へ反映するには「適用」を押してください。

たとえば許容差を5にして曲線全体を上へ3移動して適用すると、残りは2です。そこからさらに上へ3動かすと元の曲線から6離れるため、適用は止まります。数値入力や制御点ドラッグは手元の下書きで修正できます。ノット挿入・削除・一括簡約、次数上げ・次数下げ・一括次数下げでは、候補の検査を通ったときだけ下書きを置き換えます。「許容差を更新」で同じ基準に対する許容差を変更できます。基準を取り直すには「基準を解除」してから新たに設定します。

## 適用ごとの変化を累積する

「適用ごとの変化も累積する」を基準設定前に選ぶと、確定した曲線間の推定偏差上限を順に上向き加算します。上へ3動かして適用し、そこから下へ1戻すと、基準からの距離は2、累積上限は約4です。固定した基準からの上限と累積上限の両方を許容差内に収めます。チェックを外した既定の方式は、固定した基準との距離を検査します。

累積する単位は「適用」です。プレビューの回数や、ドラッグ中に通過した位置は回数に含めません。曲線形状の変化がゼロと評価された適用でも記録は増えません。Undo・Redoは基準と履歴も戻します。SVGには合計値だけを記録せず、受け入れた曲線入力を保持し、再編集の開始時に各区間を検証し直します。累積記録は128回・基準を含む合計16000制御点までです。検査上限に達した候補は反映されません。

## 比較方法と数値の意味

曲線の形状モデルを同じパラメータの位置で比較します。開曲線はパラメータの始端・終端が一致する必要があります。周期曲線は同じ周期を取り、継ぎ目が移っていても区間を折り返して1周期全体を比較します。周期移動で区間幅が浮動小数点の丸めによって変わる場合は検査を中止します。両方のノットで区間を分け、不連続ノットの左右を独立に扱います。

各区間を同次ベジェ係数へ変換し、次数の低い側を同じ次数まで上げます。多項式では係数差のユークリッドノルムの最大値が、その区間の偏差の上限です。NURBS は同次分子を $H_A,H_B$、分母を $W_A,W_B$ とすると、差の分子が $(H_A-H_B)W_B-H_B(W_A-W_B)$ となります。次数 $p$ のBernstein多項式の積では、係数 $i,j$ の寄与を $k=i+j$ に重み $\binom pi\binom pj/\binom{2p}k$ で加えます。分子係数ノルムの最大値を、両分母の絶対値の下限の積で割ります。正負混在の重みでは、分母の符号が定まるまでde Casteljau法で同時に二分割します。重みを最大絶対値で正規化した後の分母下限は $10^{-12}$、最大深さは18、検査する区間は32768までです。

表示値はbinary64で計算したモデル曲線の推定上限です。画面上のピクセル距離・SVGパス描画の近似誤差・Hausdorff距離は含みません。上限が許容差を超える場合は保守的に編集を止めます。極を含むNURBSの枝ごとの比較と、異なるパラメータ区間の自動対応付けは残る課題です。

比較実装は [splineReferenceBudget.js](../src/model/splineReferenceBudget.js)、上向き加算は [splineReductionPlan.js](../src/model/splineReductionPlan.js)、SVG読み込みは [splineSource.js](../src/adapters/splineSource.js) です。ベジェ区間の分割と次数上げの式は [MIT Hyperbook, Algorithms for Bézier curves](https://web.mit.edu/hyperbook/Patrikalakis-Maekawa-Cho/node13.html) を参照してください。操作ごとの許容差については [一括次数下げ](spline-reduction-budget.md) と [ノット一括簡約](spline-knot-simplification.md) に記載しています。
