# 周期B-spline・NURBSの形状保持ノット挿入

2026-11-17に、一様・非一様・重複周期ノットを持つ標準曲線の再編集へノット挿入を接続しました。周期を保ったまま、元の制御点と1周期のノットを各1個増やします。次数は変更しません。通常のノット列の手入力と異なり、制御点と重みも形状保持に必要な値へ更新します。

## 操作と保存

選択ツールでB-spline・NURBSを選択し、曲線の再編集を開始します。標準の曲線計算を選び、「挿入するノット値」と「ノット挿入の実装」を指定して「形状を保ってノットを挿入」を押します。周期ノットの先頭から末尾までの値を受け付けます。末尾は先頭と同じ継ぎ目として処理します。既存ノットへの挿入は重複度を1増やし、継ぎ目では先頭側と末尾側の重複を合算します。挿入後の循環重複度は次数以下、元の制御点数は1000以下です。

たとえば次数3、制御点4個、周期ノット `2, 3, 5, 8, 12` の曲線へ `5.2`、続いて `12` を挿入すると、制御点6個、周期ノット `2, 2, 3, 5, 5.2, 8, 12` になります。制御点座標とNURBSの重みも同時に更新されます。

挿入後は番号付きハンドルとプレビューが更新され、追加後の制御点もドラッグできます。複数回の挿入や続く編集を、最後の「適用」で1回のUndo/Redoにまとめます。適用前は元図形を保持し、「取消」で下書きを破棄します。換装実装が2回目・3回目の呼出しで失敗しても、元の下書きと既存プレビューを保持します。

SVG元モデルには従来どおり評価用の周期コピーと `controlCount` を記録し、再編集時には元の1周期の制御点へ戻します。保存形式のバージョン変更はありません。最後の挿入実装ID・アルゴリズム・ソース・入力値に加えて、`data-vector-implementation.refinement.periodic` に周期処理名、ソース、正規化した挿入値 `t`、単一挿入の呼出し回数 `copies` を保存します。選択図形のプロパティにも周期処理名と周期値を表示します。全編集履歴を記録するものではありません。

## 計算と換装の契約

[periodicSplineRefinement.js](../src/adapters/periodicSplineRefinement.js) は3周期展開・同値ノット挿入・中央周期抽出を行います。[splineRefinement.js](../src/adapters/splineRefinement.js) が各挿入の入出力を検査し、標準の局所更新には既存の [splines.js](../src/model/splines.js) のBoehm系 `insertSplineKnot` を使用します。新たな119機能目以降の演算を登録したものではなく、既存演算を周期編集へ接続するアダプターです。

元制御点数をN、次数をp、周期ノットをU、始端をa、終端をb、周期をT=b−aとします。制御点と重みをN個ごとに繰り返し、ノットをTずつ平行移動して、中央の前後にも1周期ずつ展開します。一時曲線は挿入前に3N+p個の制御点を持ち、有効範囲はa−Tからb+Tです。

内部値tに対してt−T、t、t+Tを順に挿入します。継ぎ目の場合はbをaへ正規化し、aとbへ挿入します。外側の有効範囲端への挿入は行いません。N>pなので、中央周期とその評価に必要な周辺制御点をこの展開から取得できます。新しい1周期のノット列から標準モデルと同じ前後延長を生成し、一時曲線の対応部分と厳密な数値一致を確認して、N+1個の元制御点と重みを抽出します。残るp個の周期コピーの座標・重みが先頭側と整合することも確認します。

換装対象は単一ノット挿入です。`host.registerImplementation('insertSplineKnot', ...)` の選択実装に、通常の非周期評価用の `points`、`degree`、`knots`、任意の `weights`、挿入値 `t` を渡します。周期情報を持つ入力を直接処理する必要はありません。1操作で内部値なら3回、継ぎ目なら2回呼び出します。各呼出しで制御点1個・ノット1個を増やし、次数と数学的形状を保持してください。一時曲線の制御点数は最大3012個です。編集用の元制御点上限1000個を、一時配列の上限と取り違えないでください。

呼出しごとの配列は複製し、結果の個数・次数・ノット列・有限座標・重みを検査します。選択は呼出し単位で指定し、作図や演算室の方式設定は変更しません。全て成功した後にだけ下書きを更新します。構造検査と継ぎ目照合は任意の外部コードの形状保持を証明するものではありません。

## 有限精度と描画の制約

端点の反復値を同じ値へ固定してから周期を展開します。もともと正のノット間隔や新しい挿入値の区間内位置が丸めで潰れる場合、展開範囲がオーバーフローする場合は拒否します。周期コピーの各成分x、yの照合は `|x−y| <= 1e-11 * max(1, |x|, |y|)` です。この値はコピーの整合検査で、曲線全体の近似誤差保証ではありません。採用した元制御点から標準モデルが周期コピーを再生成します。

零・負の重みも扱いますが、既存単一挿入が新しい零重みを生成する場合や、有限座標へ戻せない場合は保守的に拒否します。NURBSの分母零をまたぐ枝は引き続き分離して描き、省略区間を閉じません。描画は従来の極形式de Boorによる区間ベジェ化、分母検査、SVG折れ線化です。ノット追加で標本位置が変わるため、数学的な形状が同じでもSVGのパス文字列や折れ線長は完全一致しません。
