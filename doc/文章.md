# vector の最小演算と、それを使う最小機能

## 概要

円を作るとき、距離を測るところで一度、仕事が完結します。中心が `(0, 0)`、円周上の点が `(3, 4)` なら、距離の答えは `5` です。この値は寸法の計算にも使えます。中心と半径を組にして円を一つ返せば、今度は作図として仕事が完結します。その円を描くか、保存するか、次の演算に渡すかは、呼び出し側が決めます。

この文書では、**一つの幾何学的な問いに答えたところ**を「最小演算」、**呼び出し側が頼んだ一件の作図・計測・編集に答えたところ**を「最小機能」と呼びます。たとえば距離の式は引き算や平方根に分解できますが、途中で得た横方向の差だけでは、2点の隔たりは確定しません。一方、曲線から1点を求める演算と、曲線全体を点列にする機能は、どちらも単独で使い道があり、必要な入力も異なります。ここは分けます。

以下の関数名と戻り値は現行実装に合わせています。外部から直接呼べる関数と、現状は関数内にある計算を区別して記します。

## 1. 入出力を読むための約束

- **点とベクトル**はどちらも `{x, y}` です。点は位置、ベクトルは移動量や向きを表します。同じ演算に渡す点と境界は同じ座標系にそろえます。長さはその座標系の単位、角度は原則ラジアンです。
- **線分・直線・半直線**は、同じ2点から決まっても、答えを探す範囲が違います。線分は両端の間、直線は両方向に無限、半直線は起点から指定方向にだけ進みます。ツール名 `line` が返す図形は両端を持つ `segment` です。
- **点列上の位置** `position` は「辺の番号＋その辺を進んだ割合」です。番号は0始まりです。`1.25` は2本目の辺の始点から4分の1進んだ位置で、全長の25%という意味ではありません。`points` は一つの点列、`boundaries` は境界ごとに分けた点列の配列です。
- **結果の形**も機能によって異なります。作図は種類を示す `kind` と幾何データ、寸法は測定値、選択はIDの配列を返します。分割・トリム・延長の `[]` は「適用する編集がない」、選択の `[]` は「選択結果が空」です。この2つは書き戻すときの意味が違います。

数式では点を $A,B,P$、ベクトルを $u,v$ と書きます。$P_i$ の添字は0始まりです。$\lVert v\rVert$ はユークリッド長、$\operatorname{clip}(z,l,h)=\min(h,\max(l,z))$ は範囲への切り詰めです。以下は標準演算の式です。たとえば距離を差し替えたときは、距離を参照する機能の値も変わります。

## 2. 最小演算と途中から使える計算

### 点・向き・長さ

- `distance(a, b) → 数値` は2点間のユークリッド距離、`vectorLength(v) → 数値` は一つのベクトルの長さです。`midpoint(a, b) → 点` は両端のちょうど中間を返します。円の半径には距離が、線形寸法の中央位置には中点が使われます。
- `normalizeVector(v) → ベクトル` は向きを保って長さを1にします。ゼロベクトルには `{x: 0, y: 0}` を返します。面取りでは方向をここで決め、どこまで進むかを別の入力で指定します。
- `dotProduct(u, v) → 数値` は内積、`crossProduct(u, v) → 数値` は2次元外積の符号付き成分です。内積はある方向に沿った成分を求めるのに使え、外積は平行判定や交差の向きを求めるのに使えます。`angleBetweenVectors(u, v) → 角度` は向きを区別しない0からπの角度を返し、片方がゼロなら0を返します。
- `pointSide(p, line) → 数値` は始点から終点へ向いた直線に対する点の側を符号で返します。0は同一直線上です。`pointToLineDistance(p, line) → 数値` は**線分**までの最短距離で、垂線の足が線分の外なら近い端点までを測ります。両関数の `line` は `{x1, y1, x2, y2}` です。
- `rotate(p, center, angle) → 点` は点を中心のまわりに回転します。`normalizeAngle(angle) → 角度` は同じ向きの角を `0 ≤ angle < 2π` にそろえます。元の角が何周したかは出力に含まれません。

**距離・向き・回転の式。** $v=B-A=(b_x-a_x,b_y-a_y)$ とすると、長さ・距離・中点はそれぞれ次の値です。

$$
\lVert v\rVert=\sqrt{v_x^2+v_y^2},\qquad d(A,B)=\lVert B-A\rVert,\qquad M=\tfrac12(A+B).
$$

単位ベクトルは $v/\lVert v\rVert$ です。ゼロのときは実装の規約に従って $(0,0)$ を返します。内積と2次元外積、それらから得る角度は次のとおりです。

$$
u\cdot v=u_xv_x+u_yv_y,\qquad u\times v=u_xv_y-u_yv_x,\qquad
\theta=\arccos\!\left(\operatorname{clip}\!\left(\frac{u\cdot v}{\lVert u\rVert\lVert v\rVert},-1,1\right)\right).
$$

角度式を使うのは両方が非ゼロのときです。$P$ が有向直線 $AB$ のどちら側にあるかは $(B-A)\times(P-A)$ の符号で決まります。中心 $C$ のまわりの回転と、角度を一周に収める写像 $w$ は次の式です。

$$
P'=C+
\begin{pmatrix}\cos\theta&-\sin\theta\\ \sin\theta&\cos\theta\end{pmatrix}
(P-C),\qquad
w(\theta)=\theta-2\pi\left\lfloor\frac{\theta}{2\pi}\right\rfloor.
$$

次の3つは座標を組み立てる公開演算です。角加工や曲線評価からも直接使います。

- **2点から変位を得る。** 入力は始点 `a` と終点 `b`、出力はベクトル `b − a` です。`displacement(a, b)` がこれを返します。長さも角度も求めずに、向きと移動量を次に渡せます。
- **点を指定量だけ進める。** 入力は点 `p`、ベクトル `v`、倍率 `d`、出力は点 `p + d × v` です。`advancePoint(p, v, d)` がこれを返します。`v` が単位ベクトルなら、`d` はその向きへの符号付き距離になります。
- **2点間を割合で補間する。** 入力は2点 `a, b` と割合 `t`、出力は点 `(1 − t) × a + t × b` です。点列上の位置を座標に戻す処理と、ベジェを評価する処理がともに使う計算です。共通の公開関数は `interpolatePoint(a, b, t)` です。以下、この点を $L(A,B,t)=(1-t)A+tB$ と書きます。

### 交点・最近位置・切り出し

- `lineIntersection(line1, line2) → 点 | null` は、2本の**有限線分**の両方に乗る交点を返します。端点での交差も含みます。平行・同一直線、または延長して初めて交わる場合は `null` です。入力は2組の `{x1, y1, x2, y2}` です。
- `infiniteIntersection(a, b, c, d) → 点 | null` は、点の組 `a, b` と `c, d` を通る**直線**の交点を返します。たとえば横線分 `(0,0)–(4,0)` と縦線分 `(6,-2)–(6,2)` では、線分の交点は `null`、直線の交点は `(6,0)` です。前者をトリムに、後者を角加工の基準点に使います。
- `circleCenter(a, b, c) → 点 | null` は3点を通る円の中心を返します。点が重なる、または実装の許容差で一直線と判定されると中心が一意に定まらず `null` になります。半径や円弧の進行方向は別に求めます。
- `nearestPosition(points, point, measure?) → {distance, position}` は、各辺への射影を辺内に収め、指定点に最も近い位置とそこまでの距離を返します。長さゼロの辺は飛ばし、有効な辺がなければ `{distance: Infinity, position: 0}` です。これだけで、どの辺のどこを指したかを問い合わせられます。
- `splitAt(points, position) → 点列の配列` は、既知の位置で一つの点列を前後に分けます。両片は切断点を共有し、もとの折れ点の順序を保ちます。位置が両端・範囲外・両端の許容差内なら `[]` です。内部では `at` が位置から座標を求め、`part` が指定区間の端点とその間の頂点を取り出します。
- `extendEnd(tip, neighbor, edges, cross?) → 点` は片端だけを延長します。`neighbor` から `tip` へ向かい、その先で最初に当たる境界点を返します。`edges` は有限線分 `[a, b]` の配列です。前方で当たらなければ入力の `tip` 自体を返します。

**2直線・線分・半直線の交点。** $A+tU=C+sV$、$U=B-A,\ V=D-C$ と置きます。$\Delta=U\times V$ が非ゼロなら両方の進行量が一意に決まります。

$$
t=\frac{(C-A)\times V}{\Delta},\qquad s=\frac{(C-A)\times U}{\Delta},\qquad I=A+tU.
$$

直線同士は範囲制限なし、線分同士は $0\le t,s\le1$ の解だけを採用します。端点延長では $A$ を延長したい先端、$U$ を隣の頂点から先端への変位とし、$t>0$ かつ $0\le s\le1$ の候補のうち $t$ が最小の点を選びます。実装は平行判定と端点に許容差を使います。

**3点から円の中心。** $u=B-A,\ v=C-A,\ D=2(u\times v)$ とすると、外心 $O$ は次の点です。コードでは $|D|<10^{-4}$ を退化として扱います。

$$
O=A+\frac{1}{D}
\begin{pmatrix}
v_y\lVert u\rVert^2-u_y\lVert v\rVert^2\\
u_x\lVert v\rVert^2-v_x\lVert u\rVert^2
\end{pmatrix}.
$$

**最近位置と切断位置。** 辺 $P_iP_{i+1}$ の方向を $U_i=P_{i+1}-P_i$ とし、長さゼロの辺を飛ばします。指定点 $X$ を各辺へ射影して端点間に収め、最も近い辺 $k$ を選びます。同距離では先の辺が残ります。

$$
t_i=\operatorname{clip}\!\left(\frac{(X-P_i)\cdot U_i}{U_i\cdot U_i},0,1\right),\quad
H_i=P_i+t_iU_i,\quad k=\arg\min_i d(X,H_i),\quad
\mathrm{position}=k+t_k.
$$

既知の位置 $q=i+t$ に対して `splitAt` が使う切断点は $L(P_i,P_{i+1},t)$ です。整数位置ならその頂点自体が切断点になります。

### 曲線上の点と座標の拘束

- `deCasteljau(points, t) → 点` はベジェ制御点を隣同士で繰り返し補間し、指定パラメータの1点を返します。`t = 0` は始点、`t = 1` は終点です。`sampleBezierPoints(points, sampleCount?, degreeOverride?) → 点列` はこの演算を複数の `t` で呼びます。既定は60分割・61点、制御点が2個未満なら `[]` です。等間隔なのは `t` で、曲線に沿った距離は一定とは限りません。[ベジェ評価](../src/model/bezier.js)
- `snapToOrtho(start, point) → 点` は変位の絶対値が大きい軸を残し、他方の座標を始点に合わせます。同値なら縦方向です。`snapToGrid(point, gridSize) → 点` は各座標を最寄りの格子に丸めます。`clampToBounds(point, bounds) → 点` は各座標を矩形の範囲内に収めます。
- `snapAngle(angle, snapDegrees = 15) → 角度` はラジアンの角度を指定した**度数刻み**に丸め、ラジアンで返します。`constrainToAngle(start, point, angleDegrees) → 点` は始点からの距離を保って指定角度へ向けます。`snapTo45Degrees(start, point) → 点` は現在の向きから最寄りの45度を選んで同じ距離の点を返します。[座標の拘束](../src/utils/coordinates.js)・[直交拘束](../src/utils/geometry.js)

**ベジェ曲線上の点。** 制御点 $P_0,\ldots,P_n$ から補間を一段ずつ行います。各段で点が一つ減り、最後の1点が $B(t)$ です。

$$
Q_i^{(0)}=P_i,\qquad Q_i^{(j)}=L(Q_i^{(j-1)},Q_{i+1}^{(j-1)},t),\qquad B(t)=Q_0^{(n)}.
$$

サンプル数の引数を $m$ とすると `sampleBezierPoints` の分割数は $N=\max(2,\lfloor m\rfloor)$、返る点は $B(j/N)$、$j=0,\ldots,N$ です。

**座標の拘束。** 始点 $A=(a_x,a_y)$、入力点 $P=(x,y)$ とします。直交拘束は $|x-a_x|>|y-a_y|$ なら $(x,a_y)$、それ以外なら $(a_x,y)$ です。格子幅 $g>0$ のとき、格子点は $g(\operatorname{round}(x/g),\operatorname{round}(y/g))$ です。$g\le0$ なら元の座標を返します。矩形への拘束は $x,y$ をそれぞれの最小・最大値で $\operatorname{clip}$ します。

正の角度刻みを $h$ 度とすると $\delta=h\pi/180$、丸めた角度は $\theta'=\delta\operatorname{round}(\theta/\delta)$ です。実装の丸めは JavaScript の `Math.round` です。指定角 $\alpha$ に点を拘束した結果は $A+d(A,P)(\cos\alpha,\sin\alpha)$。45度拘束では $\delta=\pi/4$ とし、現在の向きを丸めた $\theta'$ を $\alpha$ に使います。

### 垂線の足・線分の最近点・円の接点

- **無限直線への正射影** `projectOnLine(point, start, end) → {point, t} | null`。$P$ から直線 $AB$ へ垂線を下ろすとき、$U=B-A$ に対して $t=((P-A)\cdot U)/(U\cdot U)$、足は $H=A+tU$ です。$t<0$ や $t>1$ も有効です。$A=B$ では直線を定められず `null` を返します。
- **有限線分の最近点** `closestOnSegment(point, start, end) → {point, t}`。上の $t$ を $[0,1]$ に収めた値を使い、$A=B$ なら $A$ と $t=0$ を返します。`pointToLineDistance` が返すのは最近点 $H_s$ までの距離 $\lVert P-H_s\rVert$ です。一方、エディタの垂線スナップが採用するのは、**元の射影**が $0\le t\le1$ を満たすときだけです。
- **指定点から円に引ける接線の接点** `circleTangentPoints(point, center, radius) → 点の配列`。中心 $C$、半径 $r>0$、基準点 $P$ とします。$d=\lVert P-C\rVert>r$ なら、接点で半径と接線が直交することから次の2点が得られます。

$$
\phi=\operatorname{atan2}(P_y-C_y,P_x-C_x),\qquad \beta=\arccos(r/d),\qquad
T_\pm=C+r\bigl(\cos(\phi\pm\beta),\sin(\phi\pm\beta)\bigr).
$$

戻り順は $T_-,T_+$ です。$d=r$ なら $P$ 自身の1点、$d<r$ または $r\le0$ なら空配列です。たとえば $C=(0,0),r=3,P=(5,0)$ では接点は $(1.8,-2.4)$ と $(1.8,2.4)$ になります。ブラウザの接線スナップは外部点から得た2候補を図面座標に変換し、ポインタに近く許容距離内の方を採用します。

## 3. 最小機能の入出力

本節ではエディタの22ツールと基礎の3機能を、呼び出し側が受け取る仕事の結果で分類します。以下の `{…}` は一つの入力オブジェクトです。座標・ID・数値は、マウス操作、別の演算、保存データのどこから渡しても同じ意味を持ちます。

### 図形を一つ作る

- **線分** `line({start, end, ortho?})` は `{kind: "segment", start, end}` を返します。通常は両端をそのまま使い、`ortho` が有効なときだけ直交拘束を経た終点を使います。
- **矩形** `rectangle({start, end})` は対角の2点から `{kind: "rectangle", x, y, width, height}` を返します。`x, y` は各軸の最小値なので、2点をどの順番で指定しても同じ矩形になります。
- **円** `circle({center, point})` は中心と円周上の1点から距離を測り、`{kind: "circle", center, radius}` を返します。同一点を渡すとモデル上の半径は0です。
- **3点円弧** `arc({start, through, end})` は中心、半径、回転の順に求め、`{kind: "arc", center, start, end, radius, turn}` を返します。`turn` は中間点 `through` を通る符号付き回転角で、半周を超える弧も表せます。中心が定まらなければ `null` です。
- **折れ線** `polyline({points, closed?})` は `{kind: "polyline", points, closed}` を返します。**多角形** `polygon({points})` は `{kind: "polygon", points}` を返します。折れ線を閉じた輪郭と、多角形として扱う頂点列を区別できます。どちらも配列の順序を保ち、モデル単体では最小頂点数を検査しません。
- **文字** `text({point, content})` は位置と本文を持つ `{kind: "text", point, content}` を返します。空文字や空白だけなら `null` です。本文の前後の空白は、有効な文字がある場合はそのまま保持します。

**作図データを決める式。** 線分の位置は $L(A,B,t)$、$0\le t\le1$ です。対角点 $A,B$ の矩形は $(x,y)=(\min(a_x,b_x),\min(a_y,b_y))$、幅と高さは $(|b_x-a_x|,|b_y-a_y|)$。中心 $O$、円周上の点 $P$ で作る円は $r=\lVert P-O\rVert$、円周は $O+r(\cos\theta,\sin\theta)$ です。

3点円弧では、上で求めた外心から見た始点・中間点・終点の偏角を $\alpha,\beta,\gamma$ とします。$h=w(\gamma-\alpha)$ と置くと、中間点を通る符号付き回転角は次の値です。

$$
\mathrm{turn}=
\begin{cases}
h & w(\beta-\alpha)\le h,\\
h-2\pi & w(\beta-\alpha)>h.
\end{cases}
$$

### 制御点または通過点から曲線を作る

- **2次・3次・任意次数のベジェ**には `quadraticBezier({points})`、`cubicBezier({points})`、`nthBezier({points, degree?})` の3つの入口があります。共通の出力は `{kind: "bezier", points}` で、点列は先頭から必要数だけの**制御点**です。次数を `n` とすると必要数は `n + 1`。任意次数で省略した場合は入力点数から1を引きます。次数が正の整数でない場合や点が足りない場合は `null` です。曲線上の実座標が欲しいときは、得た制御点を前節の評価関数に渡せます。
- **パス** `path({points, mode?})` は `{kind: "path", start, segments}` を返します。既定の `line` モードは後続点を順に線分の終点にします。`bezier` モードは後続の3点を制御点1・制御点2・終点として三次曲線にし、余った1～2点は線分でつなぎます。先頭1点だけなら区間が空のパス、0点なら `null` です。
- **スプライン** `spline({points, tension?})` は**通過点**を受け取り、隣接点から区間ごとの三次ベジェ制御点を作り、同じパス形式を返します。張力の既定は `0.5` です。2点なら直線区間、2点未満なら `null` です。指定した点を曲線が通る必要があるとき、制御点を指定するベジェとの違いが生じます。

2次・3次ベジェの式を展開すると、パスに渡す点の役割が読み取れます。$u=1-t$ とすると、$P_0$ と末尾の点が両端、間の点が制御点です。

$$
B_2(t)=u^2P_0+2utP_1+t^2P_2,\qquad
B_3(t)=u^3P_0+3u^2tP_1+3ut^2P_2+t^3P_3.
$$

スプラインの区間 $P_i\to P_{i+1}$ は、張力の引数を $k$ として次の制御点を持つ3次ベジェになります。最初と最後で欠ける隣接点には、その側の端点を使います。

$$
C_1=P_i+\tfrac{k}{6}(P_{i+1}-P_{i-1}),\qquad
C_2=P_{i+1}-\tfrac{k}{6}(P_{i+2}-P_i).
$$

### 既存の形から編集結果を一つ求める

- **分割** `split({points, point, tolerance?, endMargin?}) → 点列の配列`。指定座標の最近位置を求め、距離と端点からの余白を確認して `splitAt` に渡します。成功時は2片、対象外なら `[]` です。モデルの既定は許容距離が無限、端点余白が0。ブラウザの標準操作は両方に図面座標の5単位を渡します。
- **トリム** `trim({points, boundaries, point}) → 点列の配列`。有限線分同士の交点を点列上の位置に換算し、指定位置を含む区間を取り除きます。有効な交点が指定位置の片側だけにあれば、指定位置を含まない1片が残ります。両側にあれば2交点の外側の2片が残ります。内部に有効な交点がなければ `[]` です。返るのは残す側です。
- **延長** `extend({points, boundaries}) → 点列の配列`。境界を有限線分に展開し、最初と最後の端点でそれぞれ `extendEnd` を呼びます。途中の頂点を保った更新候補1本を `[更新後の点列]` で返します。両端とも当たらなければ `[]` です。
- **結合** `join({segments, tolerance?}) → 一つの点列`。入力は点列の配列です。最初の点列を起点に、鎖のどちらかの端につながる点列を、必要なら逆順にして継ぎます。接合部では片方の端点だけを残します。端点間距離が許容値**未満**なら接続し、既定値は `0.1` です。すべてを一本につなげなければ `[]` です。
- **オフセット** `offset({shape, point, amount}) → 新しい図形 | null`。線分・折れ線・矩形・円を対象に、指定点で側または内外を決めます。円では半径、矩形では4辺、線分では両端を更新した同種の図形を返します。折れ線の現行方式は各辺の法線で点をずらし、最初の有効辺の側を指定点で選び、後続辺は自身の法線の正方向を使います。隣り合う平行線の交点を取り直す方式とは結果が異なります。半径や幅・高さが0以下になる場合などは `null` です。
- **面取り** `chamfer({first, second, distance1, distance2})` と **角丸め** `fillet({first, second, radius})` は、ともに端点ペア2組から `{segments, bridge}` を返します。`segments` は置換後の2線分、`bridge` は間をつなぐ新しい図形です。面取りでは2直線の交点から各方向へ指定距離だけ進め、その2点を線分で結びます。角丸めでは半径と角度から接点と中心を求め、2接点を円弧で結びます。両方とも交点が定まらなければ `null`、角丸めでは半径が正でない場合も `null` です。橋だけでは元の線端が残るため、置換する2線分までが一件の編集結果です。

**切断と結合の判定。** `split` は指定点 $X$ と最近点 $H$ に対して $d(X,H)\le\mathrm{tolerance}$、かつ $H$ から両端までの距離がともに $\mathrm{endMargin}$ 以上のとき、位置指定の分割に進みます。`trim` では内部の交差位置を集合 $K$、指定位置を $q$、末端位置を $e$ とすると、除去する区間の両端は次の位置です。

$$
l=\max(\{0\}\cup\{k\in K:k\le q\}),\qquad
h=\min(\{e\}\cup\{k\in K:k>q\}).
$$

$K$ が空なら編集を返しません。交差があれば $[0,l]$ と $[h,e]$ の長さのある側を残します。`join` が端点 $A,B$ を同一の接合箇所として扱う条件は $d(A,B)<\mathrm{tolerance}$ です。

**オフセット。** 長さのある辺 $U=B-A$ の単位法線を $n=(-U_y,U_x)/\lVert U\rVert$、指定距離を $m$ とします。線分では $(P-A)\cdot n>0$ なら $s=m$、それ以外なら $s=-m$ として、両端を $A+sn,B+sn$ に移します。折れ線の後続辺は各辺の $n$ と $s=m$ を使います。矩形と円では、指定点が外なら $s=m$、内側または境界上なら $s=-m$ です。円の新しい半径は $r+s$、矩形は $(x-s,y-s,w+2s,h+2s)$ になります。

**面取りと角丸め。** 2直線の交点を $I$、交点側の端から残す側へ向かう単位ベクトルを $u,v$ とします。面取りの橋の両端は $I+d_1u,\ I+d_2v$。角丸めでは、2方向のなす角 $\theta$ と半径 $r$ から接点までの距離 $a$ と円の中心 $O$ を決めます。

$$
\theta=\operatorname{atan2}(|u\times v|,u\cdot v),\qquad
a=\frac{r}{\tan(\theta/2)},\qquad
O=I+\frac{r}{\sin(\theta/2)}\frac{u+v}{\lVert u+v\rVert}.
$$

両接点は $I+au,\ I+av$、第1接点から第2接点への回転角は $\operatorname{sgn}(v\times u)(\pi-\theta)$ です。

### 測る・選ぶ・別のツールに渡す

- **寸法** `dimension({points, mode?})`。既定の `linear` は2点を受け取り、`{start, end, angle, middle, length}` を返します。長さだけ欲しい場合は `distance`、寸法の向きや中央位置も必要ならこの機能を使えます。`angular` は `[第1の点, 頂点, 第2の点]` から `{vertex, startAngle, endAngle, turn}` を返します。`turn` は第1の向きから第2の向きまでの正方向の回転量で、180度を超える値もあります。呼び出し側で各モードに必要な点数をそろえます。
- **選択** `select(input) → IDの配列`。一件指定なら `{target}` から `[target]` を返します。`{selected, target, toggle: true}` なら既存IDの有無に応じて除去または追加します。範囲指定なら `{bounds, candidates}` を渡します。候補は `{id, box}`、矩形は `{x, y, width, height}` で、候補の矩形全体が範囲に入るIDを入力順に返します。境界との一致も含みます。どの画面要素をそのIDとして扱うかは呼び出し側の仕事です。
- **頂点インデックスからの作図** `vertices({vectors, indices, method, params?}) → 指定した作図の結果 | null`。`vectors` は共有する頂点座標の配列、`indices` はその参照順です。たとえば `indices: [2, 0]` と `method: "line"` なら、第3頂点から第1頂点への線分を返します。順序を保って座標を取り出し、選ばれた線分・折れ線・多角形・ベジェのツールに渡します。存在しない頂点は飛ばし、必要な頂点が足りなければ `null` です。ここに線の計算式を持たせていないので、線ツールを交換すればこの経路にも反映されます。

線形寸法の向きは $\alpha=\operatorname{atan2}(B_y-A_y,B_x-A_x)$ です。角度寸法は頂点 $V$ から両端を見た偏角 $\alpha,\beta$ に対し $w(\beta-\alpha)$ を返します。範囲選択では各軸で候補区間 $[a,b]$ と選択区間 $[l,h]$ を比較し、$l\le a\le b\le h$ が両軸で成り立つIDを残します。頂点参照の作図に渡る順序は、有効なインデックス $j_k$ ごとの $P_k=\mathrm{vectors}[j_k]$ です。

### 追加した機能と数値例

**点の鏡映** `reflectPoint({point, start, end}) → 点 | null`。直線 $AB$ を鏡の軸として、点 $P$ を反対側に写します。正射影 $H$ が $P$ と像の中点になるため、答えは $P'=H+(H-P)=2H-P$ です。$A=B$ なら `null` です。例として $P=(6,3)$、軸が $(0,0),(4,0)$ を通る場合、$H=(6,0)$、$P'=(6,-3)$。足が軸の定義に使った2点の外でも有効です。

**折れ線の全長・閉じた輪郭の周長** `polylineLength({points, closed?}) → 数値`。点列が $P_0,\ldots,P_{n-1}$ なら、開いた長さと閉じた長さは次の値です。2点未満ではどちらも0です。

$$
L_{\mathrm{open}}=\sum_{i=0}^{n-2} d(P_i,P_{i+1}),\qquad
L_{\mathrm{closed}}=L_{\mathrm{open}}+d(P_{n-1},P_0).
$$

**多角形の符号付き面積** `signedArea({points}) → 数値`。頂点を入力順に結び、終点から始点に戻って囲む面積を座標単位の二乗で返します。最初の頂点を原点にして三角形の符号付き面積を足すので、図形全体の平行移動量を積に含めずに済みます。

$$
S=\tfrac12\sum_{i=1}^{n-2}(P_i-P_0)\times(P_{i+1}-P_0).
$$

3点未満なら0、順序を逆にすれば符号が反転します。単純多角形の面積は $|S|$。自己交差する輪郭では逆向きの領域が相殺されます。$y$ が上向きの座標では反時計回りが正、下向きの画面座標では見た目の時計回りが正です。

点列 $(0,0),(3,0),(3,4)$ では全長は $3+4=7$、周長は $3+4+5=12$、符号付き面積は $6$ です。ブラウザでは折れ線のプロパティに全長、多角形のプロパティに周長と符号付き面積を表示します。測定する頂点は、要素と図面をそれぞれ画面へ写す行列 $M_e,M_c$ を用いて、同次座標 $\tilde P_{\mathrm{draw}}=M_c^{-1}M_e\tilde P_{\mathrm{local}}$ でそろえます。図形の拡縮や鏡映は数値に反映され、画面のズーム率は測定値に入りません。

## 4. 一つの分割を、異なる段階から呼ぶ

折れ線 `(0,0) → (8,0) → (8,12)` を `(8,3)` で分けます。呼び出し元がすでに知っている値によって、使う入口が変わります。次の例はリポジトリ直下を基準にしています。

```js
import {nearestPosition, splitAt, split} from "./src/model/linear.js";

const points = [{x: 0, y: 0}, {x: 8, y: 0}, {x: 8, y: 12}];
const point = {x: 9, y: 3};

const hit = nearestPosition(points, point);    // {distance: 1, position: 1.25}
const byPosition = splitAt(points, 1.25);      // 切断位置を別の演算で得た場合
const byPoint = split({points, point, tolerance: 2}); // 近くの座標を渡す場合
```

`hit` を得た時点では点列は一本のままです。`byPosition` と `byPoint` はともに、前半の `[(0,0), (8,0), (8,3)]` と後半の `[(8,3), (8,12)]` を返します。呼び出し側が残したいのは「指した場所」だけなら `nearestPosition` で終えられます。すでに辺と割合が分かっていれば `splitAt` から始められます。切断が入力座標から何単位離れていてよいかまで判断する仕事が `split` です。

## 5. どこを差し替えると何が変わるか

- **演算を換える。** `circle(input, {distance: 自分の距離関数})` はその一回の半径計算に効きます。`createToolset({operations: {distance: 自分の距離関数}})` で実行関数を作れば、その組み合わせで `distance` を参照する円や線形寸法などに共通して効きます。第3節のモデルが名前で受け取る演算は `distance`、`midpoint`、`snapToOrtho`、`circleCenter`、`normalizeVector`、`infiniteIntersection`、`lineIntersection`、`crossProduct`、`nearestPosition`、`splitAt`、`extendEnd`、`projectOnLine` です。ブラウザの垂線・接線スナップは `projectOnLine` と `circleTangentPoints` を個別に差し替えられます。これと、直接 import して使える関数の一覧は範囲が異なります。
- **機能を換える。** `createToolset({tools: {line: 自分の線ツール}})` は、その組み合わせの `run("line", input)` と、そこへ委譲する `vertices` の両方に効きます。既存の呼び出し元から使うには、戻り値に始点・終点を持つ線分という約束を保ちます。
- **呼び出し役を換える。** 各モデル関数は直接 import できます。名前で実行したい側だけが `createToolset()` の戻り値 `run(name, input)` を使います。ブラウザ側も `execute(name, input)` を受け取れるため、APIのリクエスト形式や操作手順は呼び出し側で変換できます。
- **入出力先を換える。** 既存エディタには、イベントを点にする `readPoint`、点を拘束する `snap`、オフセット対象を図形データとして読む `readShape`、図形を描画する `render`、輪郭の編集結果を書き戻す `editOutline`、履歴を記録する `save` があります。SVGの要素やパス文字列を扱うのはブラウザ側です。画面のない呼び出し元は第3節の戻り値を直接利用できます。

## 6. 平面幾何の演算集

以下の88件は各ファイルから直接 import できます。エディタを HTTP で開き、ツールパネルの「演算室を開く」を選ぶと、第3節と合わせた113件を JSON で試せます。用途別に入口を分けます。例えば、円上の一点を得る処理は極座標からの変換だけで完結します。円弧を近似したいときには制御点が、紙や画面へ出すときには別の描画先が加わります。

**共通の約束。** 点は `{x,y}`、矩形は `{x,y,width,height}`、円は `{center,radius}`、角度はラジアンです。有限の座標、非負の矩形寸法、各署名で指定する個数の要素を渡します。例の `?` は省略可能を表します。交点がない場合、入力から一意に決まらない場合、丸めの影響で判別できない場合は、それぞれの機能の戻り値で区別します。向きと面積の符号は入力座標系に従います。

### 6.1 点・方向・基準座標を移す

点のアフィン変換を $P'=LP+q$ と置きます。行列オブジェクト `{a,b,c,d,e,f}` は $L=\bigl(\begin{smallmatrix}a&c\\b&d\end{smallmatrix}\bigr)$、$q=(e,f)$ を表します。中心 $C$ を固定する変換では $q=C-LC$ です。

- `translationMatrix({dx,dy})` は平行移動行列を返します。$L=I,\ q=(dx,dy)$。`rotationMatrix({angle,center?})` は $L$ の列を $(\cos\theta,\sin\theta),(-\sin\theta,\cos\theta)$ とした行列を返します。
- `scaleMatrix({sx,sy?,center?})` は $L=\operatorname{diag}(s_x,s_y)$。省略時は $s_y=s_x$。`shearMatrix({kx?,ky?,center?})` は $L(x,y)=(x+k_xy,k_yx+y)$。中心の既定値は原点です。
- `reflectionMatrix({start,end})` は2点を通る直線を軸とした鏡映行列を返します。単位方向 $u$ に対し $L=2uu^\mathsf{T}-I$。2点が等しければ `null` です。
- `applyToPoint({matrix,point})` は $LP+q$、`applyToVector({matrix,vector})` は $Lv$、`transformPoints({matrix,points})` は各点を写した同順の配列を返します。平行移動は方向や速度に影響しません。
- `composeAffine({first,then})` は先に $F$、次に $G$ を掛ける行列 $GF$。`invertAffine({matrix})` は $P=L^{-1}(P'-q)$ の行列で、$ad-bc=0$ なら `null` です。
- `affineFromTriangles({source,target})` は対応する3点ずつから行列を返します。$F_T$ を基点 $T_0$、基底 $T_1-T_0,T_2-T_0$ の座標枠とすると $F_{\mathrm{target}}F_{\mathrm{source}}^{-1}$。元の三角形が潰れていれば `null`、移した先が潰れていれば縮退した行列が得られます。
- `barycentricCoordinates({point,triangle})` は $P=A+v(B-A)+w(C-A)$ を解いた `[1-v-w,v,w]`。負の値は三角形の外でも有効です。基底が潰れると `null`。`fromBarycentric({triangle,weights})` は係数どおり $uA+vB+wC$ を返し、正規化は呼び出し側が行います。
- `pointFromPolar({center?,radius,angle})` は $C+r(\cos\theta,\sin\theta)$。`polarCoordinates({center?,point})` は `{radius,angle}` で、$r=\|P-C\|$、$\theta=\operatorname{atan2}(P_y-C_y,P_x-C_x)$。中心そのものでは角度が `null` です。

[アフィン変換と座標の実装](../src/model/affine.js)

### 6.2 四点対応と射影

- `projectPoint({matrix,point})` は行優先の数9個からなる $3\times3$ 行列 $H$ を受け取ります。$(X,Y,W)^\mathsf{T}=H(x,y,1)^\mathsf{T}$ とし、$(X/W,Y/W)$ を返します。$W=0$ は無限遠に当たり `null` です。
- `composeProjective({first,then})` は $H_2H_1$。`invertProjective({matrix})` は $\operatorname{adj}(H)/\det H$ を返し、行列式が0なら `null` です。零でない定数倍の行列は同じ射影を表します。
- `homographyFromQuads({source,target})` は同じ順序で対応する4点ずつから $H$ を求めます。第4点の重心座標 $\lambda_i$ で最初の3点の同次座標を重み付けし、列 $\lambda_i\tilde P_i$ を持つ行列 $F$ を各側に作ります。答えは $F_{\mathrm{target}}F_{\mathrm{source}}^{-1}$。いずれかの側で3点が同一直線上に並べば対応は一意に決まらず `null` です。長方形から台形への対応にも使えます。

[射影変換の実装](../src/model/projective.js)

### 6.3 交差・接触・切り取り

- `segmentContact({first:[A,B],second:[C,D]})` は `{kind:"none"}`、`{kind:"point",point}`、`{kind:"overlap",start,end}` のいずれかです。$u=B-A,\ v=D-C,\ w=C-A$ と置き、非平行なら $t=(w\times v)/(u\times v),\ s=(w\times u)/(u\times v)$ がともに $[0,1]$ のとき $A+tu$ が交点です。同一直線では第1線分の向きに沿った共通区間を返します。長さ0の線分も点として扱います。
- `segmentDistance({first,second})` は接していれば0、それ以外は4通りの「端点から相手の線分への距離」の最小値です。足のパラメータを $[0,1]$ に切り詰めるので、端点同士が最短でも測れます。
- `lineCircleIntersections({start,end,center,radius,domain?})` は交点を始点からのパラメータ順で返します。`domain` は `line`（既定）・`ray`・`segment`。単位方向 $u$、$w=C-A$、$h=u\times w$ とすると、解は $A+(w\cdot u\pm\sqrt{r^2-h^2})u$。接線は1点、交差なしは `[]`。判別式が相対丸め幅内なら接線として扱います。
- `circleIntersections({first,second})` は離れていれば `none`、接すれば `point`、2交点は `{kind:"pair",points}`、同じ正半径の円は `coincident`。半径0の同一点は `point` です。中心間距離 $d>0$、中心間の単位方向 $u$、$n=(-u_y,u_x)$ に対し、$x=(d^2+r^2-s^2)/(2d)$、交点は $A+xu\pm\sqrt{r^2-x^2}\,n$ です。
- `commonCircleTangents({first,second})` は正半径の2円から `{kind:"finite",tangents}` または `{kind:"coincident"}` を返します。各接線に `family,normal,first,second`（族・単位法線・両接点）が入ります。外接線 $\sigma=1$、内接線 $\sigma=-1$ とすると、単位法線 $n$ は $n\cdot(B-A)=r-\sigma s$ を満たし、接点は $A+rn,B+\sigma sn$ です。両接点が一致しても法線が残ります。半径が正でない入力は `null` です。
- `clipSegmentToBox({start,end,box})` は各軸の不等式 $l_j\le A_j+t(B_j-A_j)\le h_j$ と $0\le t\le1$ の共通区間を求め、`{kind:"segment",start,end}` を返します。触れるだけなら両端が一致し、共通部分なしは `null` です。

### 6.4 三角形・円・円弧・楕円

- `circleFromDiameter({start,end})` は中心 $(A+B)/2$、半径 $\|B-A\|/2$ の円。`circumcircle({triangle})` は $\|O-A\|=\|O-B\|=\|O-C\|$ を解いた外接円です。既定の外心演算は $|2(B-A)\times(C-A)|<10^{-4}$ で `null` を返し、この絶対しきい値は入力の縮尺に依存します。
- `triangleIncircle({triangle})` は辺長 $a=|BC|,b=|CA|,c=|AB|$、面積 $S$ に対し $I=(aA+bB+cC)/(a+b+c),\ r=2|S|/(a+b+c)$ の内接円。面積0は `null`。`triangleOrthocenter({triangle})` は外心 $O$ から $A+B+C-2O$ を返し、外心を求められなければ `null` です。
- `perpendicularBisector({start,end})` は `{kind:"line",point,direction}`。中点を通り、方向は $B-A$ を90度回した単位ベクトルです。`angleBisectors({vertex,first,second})` は `{point,internal,external}`。2本の単位方向 $u,v$ から内側を $(u+v)/\|u+v\|$、外側をその左法線とします。反対向きなら内側に $u$ の左法線を採り、向きを定義する辺が長さ0なら `null` です。
- `regularPolygon({center,radius,sides,angle?})` は `{kind:"polygon",points}`。第 $i$ 頂点の偏角は $\theta_0+2\pi i/n$、距離は $r$。$3\le n\le100000$ の整数と正半径を受け取ります。
- `arcPoint({arc,t})` は中心・半径・円周上の始点・符号付き角 `turn` から $C+r(\cos(\alpha+t\theta),\sin(\alpha+t\theta))$ を返します。$0\le t\le1$。`arcBounds({arc})` は両端と通過した $k\pi/2$ 方向の円周上の点を使い、軸に平行な外接矩形を返します。負方向の弧と一周以上の弧にも対応します。
- `arcLength({radius,turn})` は $r|\theta|$、`chordLength({radius,turn})` は $2r|\sin(\theta/2)|$、`sectorArea({radius,turn})` は $r^2\theta/2$、`circularSegmentArea({radius,turn})` は $r^2(\theta-\sin\theta)/2$。後の2つは向き付きの面積です。負の半径は `null` です。
- 楕円は `{center,rx,ry,angle?}` です。軸の回転角を $\phi$ とし、$u=r_x(\cos\phi,\sin\phi),\,v=r_y(-\sin\phi,\cos\phi)$ と置きます。`ellipsePoint({ellipse,angle})` は $C+u\cos t+v\sin t$、`ellipseTangent({ellipse,angle})` は $-u\sin t+v\cos t$ を正規化した単位接線です。入力の `angle` は楕円のパラメータ角です。
- `ellipseArea({ellipse})` は $\pi r_xr_y$。`ellipseBounds({ellipse})` の半幅と半高は $\sqrt{u_x^2+v_x^2},\sqrt{u_y^2+v_y^2}$。`lineEllipseIntersections({start,end,ellipse,domain?})` は直線を楕円の局所座標に戻して単位円と交差させ、結果を元の座標に戻します。軸半径が正でなければ交点は `[]`、他の楕円演算は `null` です。

### 6.5 箱・輪郭・三角形分割

- `pointBounds({points})` は軸ごとの最小値と最大値を使った外接矩形で、空なら `null`。`boxUnion({first,second})` は2矩形を囲む最小の軸平行矩形です。`boxIntersection({first,second})` は各軸の区間 $[\max(l_1,l_2),\min(h_1,h_2)]$ を組み合わせた矩形。離れていれば `null`、辺や点で接すれば幅または高さが0の矩形です。
- `polygonCentroid({points})` は一様な面の重心を返します。$w_i=P_i\times P_{i+1}$ とすると $G=\sum_i(P_i+P_{i+1})w_i/(3\sum_iw_i)$。穴のない一つの輪郭で、頂点間隔が不均一でも面積で重み付けされます。符号付き面積が0なら `null` です。
- `classifyPointInPolygon({point,points,rule?})` は `inside`・`outside`・`boundary`。辺の上を先に判定し、水平半直線を横断する向きを足した巻き数 $w$ を使います。`evenOdd` は $w\bmod2\ne0$、`nonzero` は $w\ne0$ が内側です。二重に回る輪郭では結果が異なります。
- `convexHull({points})` は重複座標をまとめ、凸包の極点だけを順に返します。辞書順に点をたどり、上側・下側の列それぞれで外積による向きを保ちます。一直線上では両端だけです。
- `polygonCrossings({points})` は `{edges:[i,j],hit}` の配列です。連続重複点と閉じ点を除いた輪郭の辺番号を使い、隣接辺の共有端点を除外し、折り返して重なる辺は報告します。`isSimplePolygon({points})` は3頂点以上・非零面積・自己交差なしの真偽。`isConvexPolygon({points})` はその上で局所外積の符号に逆転がないかを返します。
- `triangulatePolygon({points})` は単純な凹・凸多角形を、入力と同じ向きの三角形の配列に分けます。向きの合う連続3点で、その三角形内と辺上に他の頂点がないものを切り離します。一直線上の余分な頂点は落とし、自己交差や面積0は `null` です。
- `intersectConvexPolygons({first,second})` は凸輪郭どうしの共通領域を一つの点列で返します。各辺の内側半平面で順に切り、境界をまたぐ辺の交点を $A+t(B-A),\ t=f(A)/(f(A)-f(B))$ として挿入します。内部に面積がなければ `[]`、入力が凸輪郭でなければ `null` です。

### 6.6 領域演算・ボロノイ・ドロネー

- `polygonBoolean({first,second,operation})` は単純な輪郭2本を三角形に分け、`intersection` ($A\cap B$)、`union` ($A\cup B$)、`difference` ($A\setminus B$)、`xor` ($(A\setminus B)\cup(B\setminus A)$) を計算します。**戻り値は内部が重ならない凸多角形の配列**です。穴はセルで覆われない空間、分離した島は別々のセルとして残ります。面積を求めるには各セルの面積の絶対値を足します。辺・点だけの共通部分は `[]`、入力が単純輪郭でなければ `null`。内部の半平面クリップはセルの広がりに対して丸め誤差程度の極細片を面積0と扱います。
- `voronoiCells({sites,box})` は `{index,site,points}` の配列です。母点 $S_i$ のセルでは全ての $j$ について $\|P-S_i\|^2\le\|P-S_j\|^2$。これを $(P-(S_i+S_j)/2)\cdot(S_j-S_i)\le0$ として矩形を切ります。同じ座標は初出の番号にまとめます。矩形に達しないセルの `points` は空です。幅または高さが正でない矩形は `null` です。
- `delaunayTriangles({points})` は反時計回りの元頂点番号3個を一組にした配列です。凸包内に点を挿入し、隣接三角形の対角線を交換します。三角形 $ABC$ を反時計回りとし、$u=A-P,\ v=B-P,\ w=C-P$ と置くと、下の値が正なら $P$ は外接円内です。丸め幅内の同円判定では既存の対角線を保ちます。重複は初出、全点共線なら `[]`、反転が上限内に収束しなければ `null` です。

$$
D=\|u\|^2(v\times w)+\|v\|^2(w\times u)+\|w\|^2(u\times v).
$$

例えば4辺の正方形 $A=[0,4]\times[0,4]$ と $B=[2,6]\times[0,4]$ では、積の面積8、和24、差8、排他的論理和16です。中央の小さな正方形を引くテストでは、面積に加え、穴の中央がどのセルにも属さないことを確かめています。

### 6.7 折れ線を距離で扱う

- `cumulativeLengths({points})` は頂点ごとの累積長 $s_i=\sum_{j=1}^i\|P_j-P_{j-1}\|$ の配列です。空列は `[]`、重複頂点では同じ値が続きます。`pointAtLength({points,length})` は $s_i\le l\le s_{i+1}$ の辺を探し、$P_i+(P_{i+1}-P_i)(l-s_i)/(s_{i+1}-s_i)$ を返します。範囲外は端点、空列は `null` です。
- `resamplePolyline({points,intervals})` は $l=kL/n$ で等間隔に拾った $n+1$ 点。$1\le n\le100000$ で、全長0なら最初の1点です。`slicePolyline({points,from,to})` は始終の距離を全長範囲に収め、途中の元頂点を含む部分点列を返します。距離の指定が逆順なら出力も逆順です。
- `simplifyPolyline({points,tolerance})` は両端を結ぶ線分からの最大距離 $d_{\max}$ が許容差を超えたとき、その最遠頂点で区間を分けます。残った頂点を入力順で返します。許容差0では直線上の中間頂点を落とせます。負の許容差は `null` です。
- `dashPolyline({points,pattern,phase?})` は長さで指定した描画・空白区間を交互にたどり、描く部分ごとの点列を返します。奇数個のパターンは2回連結し、位相を周期 $T=\sum l_j$ で折り返します。長さは正、位相は有限です。無効なパターン、数値的に先へ進めない場合、出力量の上限超過は `null` です。
- `offsetMiter({points,amount,closed?,miterLimit?})` は辺の向きに沿って左を正とした距離 $d$ の平行線を `{kind:"polyline",points,closed}` で返します。隣接2辺の左単位法線が $n_1,n_2$ なら、角の移動は $2d(n_1+n_2)/\|n_1+n_2\|^2$。端点はその辺の法線方向に移します。折り返しやマイター比の上限超過は `null`。凹角や大きな移動で生じる自己交差は点列に残るので、輪郭を検査する側が `polygonCrossings` を使えます。

### 6.8 ベジェを分ける・測る・別表現に移す

制御点 $P_0,\ldots,P_n$ と $0\le t\le1$ に対し、$P_i^{(0)}=P_i$、$P_i^{(k)}=(1-t)P_i^{(k-1)}+tP_{i+1}^{(k-1)}$ とします。最後に残る一点は $B(t)=P_0^{(n)}$ です。

- `splitBezier({points,t})` は補間過程の左端と右端から `{left,right}` の制御点列を返します。同じ曲線を $[0,t]$ と $[t,1]$ に分けられます。`subBezier({points,from,to})` はさらに分割して $B(a+u(b-a))$ を表す制御点列を返します。逆順も使え、同位置を指定すれば全制御点がその一点になります。
- `bezierDerivative({points,t,order?})` は導関数の値をベクトルで返します。一次微分の制御点は $D_i=n(P_{i+1}-P_i)$。繰り返せば高階導関数になり、次数を超えれば零です。`bezierTangent({points,t})` は $B'/\|B'\|$、`bezierCurvature({points,t})` は符号付き曲率 $(B'\times B'')/\|B'\|^3$。速度0では後の2つは `null` です。
- `elevateBezier({points})` は形を保って1次上げた制御点列です。両端を固定し、内部は $Q_i=\frac{i}{n+1}P_{i-1}+(1-\frac{i}{n+1})P_i$。制御点を増やしながら他の曲線と次数を合わせられます。
- `hermiteToBezier({start,end,startTangent,endTangent})` は端点 $A,B$ と端点微分 $U,V$ から `{kind:"bezier",points:[A,A+U/3,B-V/3,B]}` を返します。`bezierToHermite({points})` は3次の4点から始終端と $3(P_1-P_0),\,3(P_3-P_2)$ を復元します。単位接線に正規化すると微分の大きさが失われます。
- `rationalBezierPoint({points,weights,t})` は同次座標 $(w_ix_i,w_iy_i,w_i)$ を補間し、最後の重みで割った点を返します。バーンスタイン基底を $b_i^n$ とすると $R(t)=\sum_i b_i^n(t)w_iP_i/\sum_i b_i^n(t)w_i$。重み数の不一致、分母0は `null` です。
- `bezierBounds({points})` は0〜3次の軸平行外接矩形です。両端と $B_x'(t)=0,\ B_y'(t)=0$ の区間内の実根で評価するため、制御点が図形より外にあっても曲線の範囲を返します。4次以上と空列は `null` です。
- `flattenBezier({points,tolerance?,maxDepth?})` は `{points,withinTolerance}`。各部分曲線の全制御点が端点を結ぶ線分から距離 $\varepsilon$ 以内なら、曲線の凸包も同じ距離内なのでその弦を採用します。超えれば二等分します。
- `bezierLengthBounds({points,tolerance?,maxDepth?})` は `{lower,upper,withinTolerance}`。部分曲線ごとの弦長 $c$ と制御多角線長 $p$ で $\sum c\le L\le\sum p$ をはさみます。分割時に誤差予算を半分ずつ渡し、最後に全体の上下幅を返します。両演算の `maxDepth` は既定12、最大18。上限に達して許容差を満たさなければフラグは `false` です。
- `arcToCubics({arc})` は円弧を最大90度の小弧に分け、3次ベジェのパス `{kind:"path",start,segments}` を返します。各小弧の符号付き角 $\delta$ から $k=\frac43\tan(\delta/4)$。増角方向の単位接線 $T_0,T_1$ を用いて両制御点を $A+krT_0,\ B-krT_1$ に置きます。多項式ベジェによる円弧の近似です。厳密な四分円が要るときは次節の有理曲線を使えます。

[ベジェ解析の実装](../src/model/curveAnalysis.js)・[分割法の解説（Michigan Technological University）](https://pages.mtu.edu/~shene/COURSES/cs3621/NOTES/spline/Bezier/bezier-sub.html)

### 6.9 Bスプライン・NURBS・形を保つ編集

次数 $p$、制御点数 $N$、非減少ノット列 $U$ に対し、ノット数は $N+p+1$、有効なパラメータ区間は $[U_p,U_N]$ です。端点を除くノット位置は右側の区間を採ります。

- `clampedKnots({count,degree})` は両端を $p+1$ 回重ねた等間隔のノット列を返します。$U_i=\operatorname{clip}((i-p)/(N-p),0,1)$。$0\le p<N\le100000$ の整数が対象です。
- `bSplinePoint({points,knots,degree,t})` は指定区間に影響する $p+1$ 制御点だけを de Boor 法で補間します。段 $r$ の係数 $\alpha_i=(t-U_i)/(U_{i+p-r+1}-U_i)$ で、隣同士を $(1-\alpha_i)D_{i-1}+\alpha_iD_i$ に更新します。`nurbsPoint({points,knots,degree,t,weights})` は同じ計算を同次座標に適用し、最後に重みで割ります。範囲外、配列長の不一致、最後の重み0は `null` です。
- `insertSplineKnot({points,knots,degree,t,weights?})` は形とパラメータを保ちながら内部ノットを一つ追加し、`{points,knots,degree,weights?}` を返します。影響区間の点を $Q_i=(1-\alpha_i)P_{i-1}+\alpha_iP_i,\ \alpha_i=(t-U_i)/(U_{i+p}-U_i)$ で置き換えます。有理の場合は同次座標で行います。端点・既存の重複度が次数以上・新制御点の重み0は `null`。
- `bSplineDerivative({points,knots,degree,t})` は次数 $p-1$、制御点 $D_i=p(P_{i+1}-P_i)/(U_{i+p+1}-U_{i+1})$ の曲線で一次微分を評価します。次数0、または内部ノットで重複度が $p$ 以上なら、一つの両側微分を返せないケースを含むため `null` です。

四分円の検算には制御点 $(1,0),(1,1),(0,1)$、重み $(1,1/\sqrt2,1)$、次数2、ノット $(0,0,0,1,1,1)$ を使えます。$t=1/2$ の点は $(1/\sqrt2,1/\sqrt2)$。たとえば $t=0.4$ にノットを追加してから同じパラメータで評価しても点は一致します。

### 6.10 点群から測る・当てはめる

- `meanPoint({points})` は算術平均 $\mu=\sum_iP_i/N$ で、空なら `null`。`principalAxes({points})` は `{center,variance:[大,小],major,minor}` を返します。母共分散 $C=\sum_i(P_i-\mu)(P_i-\mu)^\mathsf{T}/N$ の固有値は $(C_{xx}+C_{yy}\pm\sqrt{(C_{xx}-C_{yy})^2+4C_{xy}^2})/2$。方向は単位ベクトルで、固有値が等しければ両方向とも `null` です。
- `fitLine({points})` は直交距離の二乗和を最小にする `{kind:"line",point,direction,rms}` を返します。平均を通り、方向は第1主軸、RMS誤差は $\sqrt{\lambda_{\min}}$。垂直線にも適用でき、方向が一意でなければ `null` です。
- `fitCircle({points})` は `{kind:"circle",center,radius,rms}`。$q_i=P_i-\mu$、$z_i=\|q_i\|^2$ とし、$(\sum q_iq_i^\mathsf{T})h=\frac12\sum q_iz_i$ を解きます。中心は $\mu+h$、半径は $\sqrt{\operatorname{mean}(z)+\|h\|^2}$。これは代数残差の最小二乗解です。戻り値の RMS は距離単位で $\sqrt{\sum_i(\|P_i-C\|-r)^2/N}$ を別途計算します。3点未満、共線、数値的に特異な配置は `null`。
- `closestPair({points})` は全ての $i<j$ の $\|P_i-P_j\|$ の最小値と元の番号を `{indices:[i,j],distance}` で返します。同距離なら走査で最初の組、2点未満なら `null`。重複座標は距離0の有効な組です。
- `minimumEnclosingCircle({points})` は $\min_C\max_i\|P_i-C\|$ を半径とする包含円です。一点、直径を定める二点、外接円を定める三点を境界候補として更新します。空列は `null`、1点は半径0、一直線なら両端を直径とした円です。これは点群の外側を囲う用途で、測定点に円を当てはめる `fitCircle` とは目的が異なります。

### 6.11 段階ごとの再利用例

例えば、切断点を求めて外部に返す呼び出し側は、線や円を描画する必要がありません。既知の距離から折れ線を切り出す側も、点を指す操作やスナップを経由せず開始できます。次は名前による実行役を介さず、弧長・位置・別座標への変換をつなぐ例です。

```js
import {cumulativeLengths, pointAtLength} from "./src/model/polyline.js";
import {applyToPoint, rotationMatrix} from "./src/model/affine.js";

const points = [{x:0,y:0}, {x:3,y:0}, {x:3,y:4}];
const length = cumulativeLengths({points}).at(-1);          // 7
const point = pointAtLength({points, length:length / 2});   // (3, 0.5)
const matrix = rotationMatrix({angle:Math.PI / 2});
const rotated = applyToPoint({matrix, point});              // 約 (-0.5, 3)
```

向きの判定 `orientation(A,B,C)` は $(B-A)\times(C-A)$ を返します。`insideCircle(A,B,C,P)` は反時計回りの3点について第6.6節の $D$ を丸め幅と比較した真偽です。どちらも独立して import できます。凸包・多角形分割・ドロネー分割は `operations.orientation` を使え、ドロネー分割はさらに `operations.insideCircle` を受け取ります。[向き・外接円の判定](../src/model/predicates.js)

もう一つの例が `clipCell(points, signedSide)` です。凸点列と符号付き関数 $f(P)$ を渡し、$f(P)\ge0$ の半平面に残る凸点列を受け取ります。多角形の辺を境界とするか、母点間の垂直二等分線を境界とするかは呼び出し側が決めます。領域の和差とボロノイはともに `operations.clipCell` を受け取ります。同様に曲線を分ける `splitBezier` は区間抽出・折れ線化・長さの上下限で共用します。公開関数の一覧と画面の入力例も独立しています。

### 6.12 さらに組み合わせると何が作れるか

ここまでの実装に続く候補です。入出力を先に決めておくと、新しい解法を同じ仕事に接続できます。以下の4件は未実装です。

- **穴を持つ境界の復元。** 入力は凸セル群と頂点を同一とみなす許容差、出力は外周・穴・包含関係です。共有辺を同じ区間に分割して逆向きの対を消し、残った有向辺から閉路を作ります。面積の照合にはセルの面積和をそのまま使えます。
- **ベジェ同士の全交点。** 入力は2組の制御点と座標・パラメータ許容差、出力は交点ごとの $(t,u,P)$ と重複区間です。$B_1(t)=B_2(u)$ を解き、接するだけの場合と区間全体が重なる場合を区別します。外接矩形と部分曲線の分割を絞り込みに使えます。
- **制約付き三角形分割。** 入力は点群・必ず残す辺・穴の内部点、出力は元頂点番号の三角形と辺の隣接関係です。交換禁止の辺を保ったまま、他の辺に第6.6節の外接円判定を適用します。現行の点群分割に輪郭の辺を入力するだけではこの契約を満たしません。
- **寸法拘束を解く。** 入力は移動可能な頂点・固定頂点・距離や直交の条件、出力は解いた頂点と拘束ごとの残差です。距離拘束 $f=\|A-B\|^2-d^2$ と直交拘束 $g=(B-A)\cdot(D-C)$ を別々に評価し、ソルバーが残差と収束状態を集約します。
