# スプライン再編集でのノット挿入

2026-11-17に、既存の `insertSplineKnot` 計算を保存曲線の再編集へ接続しました。非周期のB-spline・NURBSで、曲線の数学的な形状を保ちながら内部ノットと制御点を1個追加できます。計算119機能・GUI31ツールは変わりません。新しい計算関数を重複して作らず、従来のBoehm系単一ノット挿入を使用しています。

## 操作

選択ツールで曲線を選び、「曲線を再編集」を開きます。曲線の「再計算の実装」は標準を使用します。「挿入するノット値」へ有効パラメータ範囲の内部の値を入力し、「形状を保ってノットを挿入」を押します。たとえば既定の端を固定した曲線では範囲が0〜1なので、0.3や0.5を指定できます。両端と範囲外の値は拒否します。

座標、ノット、NURBSの重み、番号付きハンドルとプレビューが更新されます。複数回挿入し、新しい制御点をドラッグして形状を編集することもできます。元図形は「適用」まで変えず、挿入と続く編集をまとめて1回のUndo/Redoにします。「取消」は元図形を保持します。未適用の下書きやプレビューはSVGの確定図形へ保存しません。

既存のノットと同じ値も挿入できますが、挿入後の重複度は次数以下です。元の曲線に次数+1重の不連続がある場合、そのノット以外の有効な内部位置へ挿入できます。制御点は挿入後も1000個以下です。手作業でノット列だけを変更する操作とは異なり、挿入では制御点と重みを同時に更新します。

周期曲線への挿入も[周期展開と中央周期抽出](periodic-knot-insertion.md)で実装済みです。上記の内部範囲限定は非周期曲線の規則で、周期曲線では両端を同じ継ぎ目として受け付けます。標準と異なる曲線計算・外部ホストによる曲線定義についても、この操作では形状保持を保証できないため拒否します。通常の数値再編集と方式切替は引き続き利用できます。

## 計算・描画と換装

標準の計算は [splines.js](../src/model/splines.js) の `insertSplineKnot`、入力・出力の検証は [splineRefinement.js](../src/adapters/splineRefinement.js) の `insertEditableSplineKnot`、UIは [SplineEditor.js](../src/ui/SplineEditor.js)です。

挿入値を含むノット区間を求め、影響する局所制御点だけを隣接点の重み付き補間で置き換えます。NURBSでは同次座標の補間に相当する計算で新しい重みも求めます。影響しない制御点を保持し、ノット列と制御点数を各1個増やします。次数は変更しません。

描画は従来の極形式de Boorによる区間ベジェ化、分母検査、SVG折れ線出力を使います。数学的な曲線が同じでも、ノット区間が増えると折れ線の標本位置が変わるため、SVGの `d` 文字列や描画上の近似誤差は挿入前と完全一致するとは限りません。

再編集欄に「ノット挿入の実装」とそのアルゴリズムを表示します。`host.registerImplementation('insertSplineKnot', ...)` で登録した実装を選択でき、呼出し単位の指定で実行するため、次の作図や演算室用の選択を変更しません。曲線計算の実装と挿入操作の実装は別です。

換装実装は、入力された非周期の点列・次数・ノット・任意の重み・挿入値 `t` を受け取り、同じ次数、指定位置へ1個追加したノット列、1個増えた制御点、NURBSでは対応する重みを返してください。数学的な曲線を保持することも実装側の契約です。標準実装は数値検証で照合していますが、任意の外部コードの形状保持を入出力の構造検査だけで証明するものではありません。

結果の形、個数、次数、ノット列、有限座標・重みを検査し、全て有効な場合だけ下書きを置き換えます。計算失敗や例外は元図形・元下書き・既存プレビューを保持します。零・負の重みも入力できますが、補間後の重みが零になって有限制御点へ戻せない場合や、演算がオーバーフローする場合は拒否します。既存計算は零重みの新制御点を作る挿入を保守的に拒否します。

## 保存される記録

適用後の制御点・ノット・重みを従来のSVG元モデルへ保存し、後から再編集できます。図形のID、外観、変換、レイヤーを保持します。最後に成功したノット挿入の実装ID・アルゴリズム・ソース・挿入値を `data-vector-implementation.refinement` へ追加し、選択図形のプロパティにも表示します。この記録はSVG往復と、後の元モデル再編集でも引き継ぎます。これは最後の挿入操作の記録であり、全編集操作の履歴ではありません。

## 参照履歴と検証

2026-11-17に C.-K. Shene の [B-spline Curves: Knot Insertion](https://pages.mtu.edu/~shene/COURSES/cs3621/NOTES/spline/B-spline/single-insertion.html) と [B-spline/NURBS Curves: Knot Insertion](https://pages.mtu.edu/~shene/COURSES/cs3621/NOTES/spline/NURBS-knot-insert.html) を照合し、単一ノット挿入の局所更新と有理曲線の同次座標補間を確認しました。既存関数との対応確認で、外部コードの転用はありません。名前の付いた方式としてBoehm系と表示する既存の記録は [algorithms.md](algorithms.md) にあります。

[splineRefinement.test.mjs](../tests/splineRefinement.test.mjs)は次数1〜12、非一様ノット、重複挿入、零・正・負の重み、形状の数値一致、非破壊性、境界・上限・非有限結果、換装実装の出力検査、SVG元モデルの往復を検証します。[editor.html](../tests/editor.html)は複数回挿入、適用前の保持、Undo/Redo、保存と再編集、実装選択・記録、失敗・取消、新制御点のドラッグを確認します。

非周期B-spline・NURBSの[許容差付きノット削除](spline-knot-removal.md)は実装済みです。周期曲線の[内部ノット・継ぎ目の削除と区間移動](periodic-knot-removal.md)も実装済みです。極から離れた[枝に限定するノット削除](spline-branch-removal.md)にも対応しました。無限遠の同次制御点の編集、厳密算術は残る範囲です。

零・正負混在の重みの削除は[全区間の分母を検証できる範囲](signed-knot-removal.md)で対応済みです。

区間ベジェ化・同次Bernstein式・再接続による[形状を保つ次数上げ](spline-degree-elevation.md)は実装済みです。制御点とノットが増える表現を返します。

元の内部・周期ノットの重複度を1つ増やす[連続性保持の次数上げ](spline-continuity-elevation.md)も選択できます。

端点を固定した同次係数最小二乗による[許容差付き次数下げ](spline-degree-reduction.md)は実装済みです。区間ベジェ接続を返し、高次連続性や最少制御点は保証しません。

元のノット列が定める[連続性を保つ次数下げ](spline-continuity-reduction.md)も選択できます。通常の接続点と周期継ぎ目は許容差内で移動し、単純周期継ぎ目が消える場合の[始端移動](periodic-degree-reduction.md)にも対応しています。
