# 別SVGからプリセットと作図セットを選んで取り込む

更新日: 2026-11-17（日本時間）。別の図面に保存した入力・方式・作図セットを、現在の図面へ選んで追加できます。「ファイル」欄の「別SVGから記録を取り込む」を使用します。

## 操作と追加先

取込元のSVGを選ぶと、従来の図面方式1件、従来のツール別入力、名前付き方式、名前付き入力、作図セットを一覧に表示します。取り込む項目へチェックを付け、必要なら記録名を変更して「選択した記録を追加」を押します。初期状態では全項目が未選択です。「全件選択」「選択解除」も使用できます。

従来の方式は名前付き方式へ、従来の入力は名前付き入力へ変換して追加します。名前付き方式・入力・作図セットはそれぞれ同種の領域へ追加します。現在の図面の従来記録を上書きしません。元SVGのIDは引き継がず、追加する全記録に新しいIDを割り当てます。

同名があれば、末尾へ ` (2)`、` (3)` のような番号を付けます。入力とセットの名前はツールごと、方式名は図面全体で重複を判定します。名前は前後の空白を除いた1〜100 UTF-16単位で、末尾番号も上限に含めます。改行・制御文字・空の名前は拒否します。長い名前は番号の分だけ末尾を短くします。

追加完了後に実際の追加名を表示します。記録の値は独立したコピーで、元のSVGや元の記録を後から変更しても影響しません。複数種類の記録を同時に追加しても、1回のUndo/Redoで全追加を戻せます。追加後に使う入力・方式・セットをそれぞれ選んで、通常の明示復元・適用操作を行います。

## 現在の作業と失敗時

取込元の図形、レイヤー、スタイル、プレビュー、スクリプトは取り込みません。SVGは画面に挿入・描画せず、切り離したXML文書から記録メタデータだけを読みます。現在の完成図形・下書き・対象選択・ツール・使用方式・ブラウザー設定は維持します。現在選択中の記録IDと入力中の記録名も維持します。取込画面のキー入力は作図ツールへ伝えません。

取込元の5領域を全て検証してから一覧化します。未選択の領域でも既知形式が不正なら、そのSVG全体の記録読み込みを拒否します。未知の入力版・ツール・実装IDは既存の各形式の契約に従って保持し、取り込み時には実行しません。未知の集合版・方式設定版は拒否します。

選択した全記録の追加後データを検証してから保存します。1領域でも件数・大きさ等の上限を超える場合は全追加を拒否し、現在の各記録・選択・下書き・履歴を維持します。個々の領域の上限は変更していません。重複した選択や存在しない記録も拒否します。

非同期読込中に別ファイルを選ぶと、以前の読込結果を破棄します。取込画面を閉じた後の読込結果も破棄します。SVG全体の読込やUndo/Redoで図面が切り替わった場合、開いていた取込画面からの追加は拒否します。閉じて開き直し、取込元を選び直してください。現在の図面内の通常編集や、既存記録の更新を行った場合は、追加ボタンを押した時点の保存内容を基準に重複と上限を再検証します。

記録を持たない旧SVGは0件として表示します。読込対象は32MiB以下、文字列は16000000 UTF-16単位以下、メタデータは10000000単位以下です。SVG以外、壊れたXML、DOCTYPE、複数の図面メタデータ、未知の図面メタデータ版は拒否します。図形やレイヤーの編集内容は取り込み対象外なので、その内容を図面として復元する検証は行いません。

## 実装と検証

[presetImport.js](../src/adapters/presetImport.js) の `readPresetSVG(text)` がXMLから記録を抽出し、`presetImportRecords(state)` が5種類の保存形式を名前付きの候補へ変換します。`planPresetImport(records,selection,current,{createId})` はコピー先の全データ、追加名とIDを計画し、全領域を事前検証します。`commitPresetImport(plan,stores)` が対象管理器の `replaceRecords(value)` で保存内容だけを置き換えます。`replaceRecords` は選択・入力中の名前をリセットしません。履歴保存はGUIが全追加の後に1回行います。

[PresetImportDialog.js](../src/ui/PresetImportDialog.js) がファイル選択・候補表示・選択・追加・非同期読込の世代管理を担当し、[FileManager.js](../src/ui/FileManager.js) から開きます。[DrawingDocument.js](../src/core/DrawingDocument.js) の `revision` は図面読込・Undo/Redoで増加し、古い取込画面からの追加を防ぎます。この値はSVGへ保存しません。

[presetImport.test.mjs](../tests/presetImport.test.mjs) は5形式、選択追加、独立コピー、新ID・重複名、既存選択の維持、保存失敗時の巻戻し、不正選択・上限超過、未知版・未登録方式、長い名前の番号付けを検証します。[editor.html](../tests/editor.html) は実際の取込画面、現在の下書きと図形の維持、全種類の1段階Undo/Redo、選択したセットによる実作図、SVGノードの非挿入、不正XML・メタデータ・名前、古い読込の破棄、図面切替、未知版・名前の文字列表示、上限超過時の非追加を検証します。

幾何計算・描画アルゴリズムは追加していません。各方式の文献と実装元は [algorithms.md](algorithms.md)、換装条件は [implementation-options.md](implementation-options.md) を参照してください。記録の検索・並べ替え、既存記録への上書き、図形そのものの部分取り込み、外部実装コードの読込、クラウド同期は未導入です。
